**若璃（Nyak-li）**是神圣赫特维拉联邦帝国的尚华大公、[皇家议政会](/wiki/皇家议政会)成员，六位共同重生的永恒存在者之一。她出身东华官宦家庭，离家后弃用原姓，与文斯利亚等五人共同旅行并建立家庭。她温润端庄、心思细致，具有独立而坚定的意志，爱好文学、写作、裁缝、花草和市场生活；其关怀常表现为具体的生活安排，同时也拥有自己的创作与公共判断。

## 身份与姓名

“若璃”为目前使用的完整姓名和常用名，外文写作 Nyak-li。她离家后弃用原姓，以表示与原生家庭决裂，原姓未明确。现代公共场合可称“殿下”或“若璃殿下”；文斯利亚在家中也可称她“璃儿”。

| 项目 | 内容 |
| --- | --- |
| 原生家庭 | 东华文官家庭，自幼接受官宦小姐教育 |
| 地方公职 | 尚华大公 |
| 中央身份 | 皇家议政会成员，曾任十二届议长 |
| 主要兴趣与技艺 | 文学、历史、小说与文学批评、裁缝、衣饰制作、料理 |
| 与五人相遇时年龄 | 15岁 |
| 重生后身体状态 | 固定为20岁；161厘米，48千克 |
| 通常住所 | 首都皇宫私人居住区，与其余五位家人共同生活 |

东华与扶桑位于同一原生世界，均与现居世界独立。现代尚华的东华文化根源来自重生后的主动保存、教学与传播，不来自若璃的后裔。身体年龄不能用于反推其出生纪年。

## 性格与价值观

若璃举止优雅，声音轻柔平稳，说话舒缓，容易使人安心。她不急于表达意见，常先从对方立场思考，再逐步说明理由。她表达感情较节制，内心却多愁善感，常把情绪寄托在文学中。

她宽厚细致，记得许多别人已经忘记的小事，习惯把抽象关心落实为能改善生活的行动。受到对手艺、料理或作品的肯定会很高兴，害羞时可能以衣袖遮脸、避开目光。失败时往往先道歉，再慢慢调整、想办法补救。遇到冲突，她寻找各方能够接受的办法，并非只求尽快停止争吵。

传统女性教育没有消除她的主体性。原生家庭中身份与家世的束缚，使她格外珍惜不以地位交换的真心关系。照顾家人是她主动选择的幸福来源，同时她仍有独立、深刻的观点与投入个人兴趣的时间。

她容易把自己的愿望排在最后，希望别人都安排好后才轮到自己；为了尽量照顾每个人，她也可能不断改善方案，错过已经足够好的时机。这并非完全无法判断，而是难以停止追求更周全的结果。

## 兴趣与日常

若璃喜欢做衣服和饰品，常亲手为家人制作，也享受细致手工本身。她爱读文学与历史，能长时间投入较艰深的作品，具有很高的文学素养。她写小说，也写文学批评，文字可以严肃、锋利，与日常温柔的表达形成区别。

现代写作主要使用电脑，她仍经常手写，以此静下心来；字迹潇洒有力。她喜欢赏花、照料植物，也喜欢超市与集市中的生活气息，留意商品品质、物价和真实需求，买东西很识货。

她擅长料理，偏好清淡、营养与搭配，认真记住家人的口味，做饭时有时不自觉地哼歌，被听到会害羞。这些能力不意味着她固定承担全部家务，六人的共同劳动随当时兴趣、需要和时间安排。

六人以皇宫私人住宅为常规住所，各有卧室、物品和私人时间；无名岛最初之家仍是秘密度假空间，首都郊区另有不接待公务的私宅。她的创作和家庭生活并不持续围绕公职展开。

## 家庭与重要关系

| 家人 | 关系与相互影响 |
| --- | --- |
| [文斯利亚](/wiki/文斯利亚) | 称其为哥哥。她知道他不善照顾自己，以日常细节帮助他放松；他在她面前能够显露脆弱，也注意她默默的付出，主动感谢与赞许。 |
| [诺菲莉亚·薇尔希·伊拉奈德](/wiki/诺菲莉亚·薇尔希·伊拉奈德) | 两人都善于倾听，默契安静。诺菲莉亚喜欢她的文学作品，她欣赏诺菲莉亚对人心的理解，常交流文学与思想。 |
| [艾洛希亚·优莉耶·伊诺莱卡](/wiki/艾洛希亚·优莉耶·伊诺莱卡) | 衣服设计与制作的常见合作伙伴。艾洛希亚提供设计稿，她从实现与舒适度讨论并制作；两人也交流甜品外观和制作方法。 |
| [神奈千咲](/wiki/神奈千咲) | 她帮助千咲处理细致工作，千咲分担体力事务。千咲向她请教文化与生活细节，她也以自然的照顾帮助千咲放松。 |
| [神奈千樱](/wiki/神奈千樱) | 千樱喜欢欣赏和试穿她的新衣，以直接赞许给予鼓励；她记住千樱的偏好，也愿意帮助其新点子找到实际实现方式。 |

这个家庭不以共同血缘维系。若璃加入其中，使她能够从受身份限制的原生环境转向自己选择的亲密关系；这种关系并不取消她本人和其他家人的独立生活。

## 外貌与衣着

若璃有深绿色眼睛与黑色长直发，头发垂至腰际，柔顺有光泽。常将部分头发在后头顶结成发髻，以发簪固定，其余自然垂落，也会根据衣着更换发型。

她偏好纯净、协调的配色，衣服宽松柔软、露肤较少，端庄优美而不过分华丽。使用力量时呈现接近翡翠或森林的安静绿色光，平时不自然发光；代表色不等于治疗能力的元素来源。

## 能力与存在状态

若璃相对擅长治愈，以及对单人或一定范围对象的恢复与强化，也能够在一定程度上增强他人的能力。治疗和强化都有实际负担，不能无限持续；她的治愈无法消除诺菲莉亚重生后献祭产生的特殊损伤。

她原本身体能力一般，直接战斗时更倾向远距离行动，不特别擅长近战，但有足够强的独立作战能力，也可攻击、防御、移动和强化自身。她能具现由力量构成的“圣剑”，并不固定站在其他人身后承担治疗岗位。六人的综合能力没有稳定通用的排名。

她自重生起才成为不自然衰老、没有通常寿命上限且不育的永恒存在。身体死亡通常触发重构，在真正开始时化为光粒子，本人与服装恢复至潜意识中的受伤前完整状态。致死前短时间确定的重构延迟无法分析、解除或准确预知，等待期间仍保持死亡状态。永久使重构失效的机制尚未证实。

现代正常公共[禁制](/wiki/禁制)限制外部能力，不能通过提高输出突破。她与家人长期研究后掌握主动跨世界旅行，通常在中央管理的专用设施出发，跨越依靠自身能力，并预设返回联系；自主旅行不自动构成国家外交任务。

## 生平

### 东华的官宦家庭

若璃出身富裕却疏离的东华文官家庭，接受琴棋书画等教育，尤其擅长写作与裁缝。父亲并不清廉，少有关心，也不主动向她说明官场事务；她已经察觉家产来源的问题，却没有阻止的地位。

家中缺乏可以真心相待的同龄人，与佣人的交往又受上下身份限制。她预见自己可能成为政治婚姻的筹码，才华与愿望难以自主施展，因而通过阅读向往外面的世界。

### 马车相遇、月下茶会与离家

十五岁时，若璃随父亲乘马车外出，文斯利亚等五人因未及时避让而险些被捕。她意外听懂他们的话，命下人将五人带回宅邸。当地相遇中，她是唯一能够同时与五人交流、理解东华语言文字和身份规则的人。

回到宅邸后，她正式介绍身份，邀请五人参加庭院月下茶会。谈话从日常进入经历和私人秘密，使她第一次向同龄人坦白孤独与心事。五人讲述外面的生活，却尚未披露特殊力量和讨伐使命；她随后邀请他们暂住。

父亲后来在政治斗争中被处刑，其他家人受牵连，五人救下若璃。她先决定离开原有生活、随行，再获知力量与使命，开始学习主动运用能力。她离家后弃用原姓，以表示决裂。政治斗争、牵连和救援的具体过程仍未确定。

### 六人旅途、决战与重生

若璃加入后，六人持续练习、交流与讨伐，世界转移自动发生。他们知道眼前任务和诺菲莉亚特殊作用的危险，却不了解讨伐会推动混乱力量聚合的完整机制。

最终决战中，千咲、千樱先后战死，若璃继续掩护家人，成为第三位死者。其具体死亡方式尚未确定。艾洛希亚、诺菲莉亚随后死亡，文斯利亚失去意识。经过无法统一换算的漫长时间，六人在现居世界同一丘陵陆续醒来，若璃的身体年龄固定为二十岁；此后共同升空、游览，选择另一座小岛建造最初之家。

### 尚华的文化与地区形成

建国后，若璃选择性保存东华的书写、教育、礼俗与市场交流知识，并随现居世界的材料和生活条件修改。旧有家世等级与官宦关系没有被整体移植。她的传播通过教学、共同生活与迁居发生，与生物学后裔无关。

前2064年的粮食调运记录说明她已参与公共事务，后来逐渐形成河港、农业和沿海聚落之间的持续协调。前1324年，她参与战后账目清理；前1214年主要港市取得市场自治，政治中心仍留原址，成为尚华多中心结构的一段历史。

827年尚华公国与大公职位正式确认。若璃原本较强的任用、供给、收费和争议处理权，随后受到中央军事统辖、独立司法和地方组织发展的限制。1308年跨城公共财政协商、1496年城乡费用清册改革，使受益地区、出资和维护责任更可公开比较，但当时参与仍偏向有地位者。

### 金融危机与责任政府

1687—1691年金融危机中，若璃支持有限公共保证以维持必要运输，担忧骤然收缩伤及工人与农户。后来的审查发现部分保证过度保护既有经营者、风险披露不足，她参与补救和修订。1694年的担保公开制度要求分别列出对象、金额、期限和责任，私人失败不能自动变成无限公共赔偿。

1732年扩大城乡预算代表参与，1846年行政首席须取得代表机构信任，1854年地方选举改革取消商号、土地和旧职位对普通议席的支配。1884年形成现代邦务协调院前身，1910年进一步以民选地方机关授权替代旧有身份代表。

### 战争、重建与地方治理

航路战争冲击尚华运输、港口和就业。若璃在1932—1937年任中央议长，地方首席与政府仍承担本邦日常行政。运输征用、仓储和劳动力动员引发补偿与分配争议，她参与协调和战后清理，具体决定仍接受审计，不由个人公信力免除责任。

1948年恢复地方选举，1953年整理公共特许与采购中的政府保证、私人风险及服务义务。1978年污染治理使港口工业、上游农业和居民健康的矛盾更加突出；1986年后六个自治协商区代表参与邦务协调院的制度逐步稳定。她的公共事务涵盖照护、教育、生态与成员资格，商业并非唯一职责。

若璃曾十二度隔届当选议长。各任期从起始年9月1日至结束年9月1日前。

### 2026年现状

2026年中央议长选举中，若璃得到法政党、田园合作党及联邦自治联盟全国层面的推荐，在第二轮与千樱竞争，最终未胜出。法政党选后转与千樱形成施政协作，不等于若璃失去地方职务或所属政府必须辞职。她没有党籍，也不是这些政党的领导人。

尚华地方事务中，她推动公共货运场站收费、安全责任与劳动服务转介形成跨市共同规则，通过政府和自治地区协商，促成公开收费、保留合理地方差异及统一基本服务入口的安排。

她另支持扩大中小运输设施更新的有限担保。财政部门和部分自治代表质疑风险集中，原方案仅获88票，未达91票门槛；缩小规模、引入共同出资、信息披露与年度风险上限后，修订方案获96票。她接受缩减，同时继续讨论是否足以帮助小经营者。

## 公共职权与影响

若璃主持十三人邦务协调院并有一票，可提出重点政策、取得材料、组织组阁协商，对列明的长期事项提出有限复议。180席邦民议会掌握立法、预算和政府信任；若璃不能自行批准担保、征税、任命全部人员或决定法院裁判，地区代表也不由她个人任命。

她对市场、商品、生活条件与主体性的重视，与尚华的流通文化和地区协调有长期联系。其政治记录既包括改善供给与公共服务，也包括担保风险、海外利益和重建分配受到批评的经历。她的影响来自持续参与和协商，尚华的制度仍由城市、乡村、劳动者、经营者、政府及民选政治共同塑造。
