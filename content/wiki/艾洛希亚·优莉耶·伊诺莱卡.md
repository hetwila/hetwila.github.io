**艾洛希亚·优莉耶·伊诺莱卡（Elocia Yulie Inolaika）**，常用名**艾洛希亚**，是神圣赫特维拉联邦帝国的伊诺莱卡大公、[皇家议政会](/wiki/皇家议政会)成员，六位共同重生的永恒存在者之一。她腼腆温和，热爱绘画、衣饰设计和可爱的事物，重视真实感受、人格平等与不纵容伤害的原则。她与诺菲莉亚共同保存故乡伊拉奈德的文化，长期参与伊诺莱卡公共生活，并曾多次当选中央议长。

## 身份与姓名

全名由正式名“艾洛希亚”、幼名“优莉耶”和家族名“伊诺莱卡”组成，幼名永久保留。现代公共场合可称“殿下”或“艾洛希亚殿下”。她与诺菲莉亚同出伊拉奈德原生文明；现代伊诺莱卡公国继承其较偏世俗的生活文化与艺术传统，并非另一原生文明的直接延续。

| 项目 | 内容 |
| --- | --- |
| 原生家庭 | 伊拉奈德东部沿海手艺人家庭的独生女 |
| 地方公职 | 伊诺莱卡大公 |
| 中央身份 | 皇家议政会成员，曾任十一届议长 |
| 主要兴趣与创作 | 绘画、插画、漫画、服装设计 |
| 初遇文斯利亚时年龄 | 13岁 |
| 重生后身体状态 | 固定为18岁；156厘米，40.5千克 |
| 通常住所 | 首都皇宫私人居住区，与其余五位家人共同生活 |

“大公”是邦国领导公职，不能据此认定她私人拥有土地、居民或公共财产。她的身体年龄不等于实际经历，也不能用于推算出生纪年。

## 性格与价值观

艾洛希亚平时有些怕生，声音柔软，容易害羞。她愿意温和交流，不常主动命令别人；讨论熟悉的绘画、动画和设计时，表达会变得直接，评价也更精准。她对喜悦、委屈和感兴趣之事的反应自然鲜明，不欺骗自己的感受，也不把情绪随意发泄给别人。

她容易专注到忘记时间。作画时可能忘记吃饭，逛街遇到喜欢的东西会停留很久。对作品的认真评价会让她记住很久，失败时会沮丧于仍能做得更好，通常先整理心情，再重新尝试。

她重视自己的价值判断，不轻易因身份、利益或多数意见而改变底线。她能理解软弱与迷茫，却不把理解当作放任伤害的理由；对他人快乐和痛苦的敏感，使她尤其珍惜美好生活。遇到原则冲突时，她可以不提高音量却十分坚定。

这种坚持也有现实局限：她可能低估复杂条件，知道希望保护什么，却未必立即找到成本合适、能够实施的路径。她有时会为信念把自己放在最后。日常的她仍是喜欢创作和分享的家人，不会持续评判别人，也不以自己的审美要求所有人。

## 兴趣与日常

绘画是艾洛希亚最主要的爱好和特长。现代她既从事传统绘画，也用电脑和平板创作插画与漫画，拥有发布作品、与其他画师交流的社交账号。她愿意接受委托，但会选择自己认同的内容；创作身份与公职、公共资助决定分别处理。

她喜欢服装本身的设计，尤其偏爱少女风、洛丽塔风和童话风，较少追逐流行，也不喜欢过度暴露或强调身体曲线。她会认真整理衣柜、维持衣物状态，自己画设计稿，与若璃讨论制作。她喜欢逛熟悉的店，避开过于喧闹的环境和主动推销。

她爱干净，房间与衣着通常保持整洁，也比较介意弄脏。甜品会少量、慢慢品尝。她常把新作品分享给家人，愿意撒娇和依赖，也会因玩笑鼓起脸。共同家庭没有固定家务分工；她可以与家人相处，也可以独自投入创作。皇宫是常规住所，最初之家仍供秘密度假，首都郊区另有私宅。

## 家庭与重要关系

| 家人 | 关系与相互影响 |
| --- | --- |
| [诺菲莉亚·薇尔希·伊拉奈德](/wiki/诺菲莉亚·薇尔希·伊拉奈德) | 幼年结识的挚友，亲密如姐妹，称其为“诺菲莉亚姐姐”。她在诺菲莉亚面前可以毫无保留地表达，害羞时也会躲到其身后。两人都相信善良，却可能在理解与原则之间作出不同判断。 |
| [文斯利亚](/wiki/文斯利亚) | 称其为哥哥，是她能够放心亲近和依赖的男性家人。他尤其宠爱她，提供安全感；她则提醒他，不要为了现实和风险放弃重要价值。 |
| [神奈千咲](/wiki/神奈千咲) | 称其为“千咲姐姐”。两人互相尊重，也会就现实条件与代价争论；她理解千咲承担后果的认真，千咲理解她并非任性，并帮助寻找实际解决办法。 |
| [神奈千樱](/wiki/神奈千樱) | 称其为“千樱姐姐”。共同喜欢可爱事物、逛街与分享作品；千樱发现新鲜事物，她认真欣赏、帮助选择，也会为千樱绘画和设计。 |
| [若璃](/wiki/若璃) | 称其为“若璃姐姐”。两人常合作设计和制作衣服：她提出美感与灵感，若璃考虑实现、穿着与舒适度；甜品外观和制作方法也是交流内容。 |

她是六人中身体年龄最小者。照顾和依赖不是单向关系；决战中保护诺菲莉亚，也体现了她愿意主动承担的另一面。

## 外貌与衣着

艾洛希亚有天蓝色眼睛与极浅蓝色长直发，整体身形娇小。传统发型与诺菲莉亚相近，但更经常随衣着改变细节、饰品和发式。喜欢某件事时，目光会明显明亮，情绪较易从表情中看出。

她的伊拉奈德传统衣着以浅蓝、白色为主，日常偏爱冷色和浅色，重视设计与整体协调。使用力量时呈现接近黎明天际的极淡蓝光，平时不自然发光；这一光色不是水或冰的元素标记。

## 能力与存在状态

艾洛希亚相对擅长远距离、小范围的精密干涉，常见表现是水与冰。她对单个或少数对象能集中很强的作用，控制精度极高；当范围扩大，单位范围内可以维持的强度会明显下降。

她原本身体能力较弱，却能以力量精确控制和强化自身动作。超过身体承受范围仍会造成实际损伤，不能把精密控制等同于没有负担。她也能攻击、防御、治疗、移动与飞行，并能具现由力量形成的“圣剑”，不承担固定不变的战斗岗位。六人没有通用的强弱排名。

她从重生起成为不自然衰老、没有通常寿命上限且不育的永恒存在。身体死亡通常引发重构，真正开始时才出现光粒子；本人和服装恢复至潜意识中的受伤前完整状态。较强能力者能在致死前短时间确定延迟，但时长不能被准确知晓，也不能分析、解除。永久阻止重构的机制尚未证实。

现代公共[禁制](/wiki/禁制)限制外部能力作用，不能靠提高输出突破。六人长期研究后掌握主动跨世界旅行，通常依靠专用设施提供安全环境，跨越仍由本人能力完成；这不同于重生前自动发生的世界转移。

## 生平

### 沿海童年与离乡

艾洛希亚出生于伊拉奈德东部沿海，是独生女，父亲以绘画与手工为生。家庭对她较为宽松，她在自由成长中接触绘画、手作和日常美感。幼年偶遇诺菲莉亚后，两人成为最初也是最亲近的朋友，视彼此为姐妹。

十三岁时，故乡世界遭到结构性毁灭。她与诺菲莉亚重伤昏迷于神殿外墙，醒来时已在一间有石床的房间，伤势痊愈。面对陌生环境和文斯利亚，她起初紧张；确认亲人与故乡已经失去后，和诺菲莉亚一起在他怀中痛哭。

### 三人、五人与六人的旅途

文斯利亚引导两人首次主动学习能力。旅行、讨伐与共同生活使艾洛希亚逐渐建立新的信任和依靠。三人自动转移到扶桑，在樱花林与神奈姐妹相遇；她鼓起勇气解释处境，与诺菲莉亚的交涉一起促成最初信任。

姐妹起初不知三人的力量，后来在途中事件后才开始学习。五人赴东华，与若璃相识、暂住其宅邸，在她的家庭变故后救下她。若璃选择同行并知情后，六人持续练习、交流和讨伐，形成共同家庭。

### 决战中的死亡与重生

最终决战发生在完整混乱意志所在的世界夹缝，三日内结束。千咲、千樱和若璃先后战死；诺菲莉亚遭受攻击前，艾洛希亚将她推开，自己受伤而死，成为第四位死者。这一行动直接保护了自幼相伴的姐姐，也成为诺菲莉亚精神崩溃和随后献祭的关键情感触发。

此后经过无法统一纪年的漫长时间，六人在现居世界同一丘陵相继醒来，重生后艾洛希亚的身体固定为十八岁。六人先确认彼此、升空感知来自其他世界与时代的思念，再游览并选择小岛建家。其重生前装备没有随重生进入现居世界。

### 伊拉奈德文化保存与伊诺莱卡形成

艾洛希亚与诺菲莉亚主动整理故乡语言、故事、衣饰、纹样和工艺，将亲历经验通过教学、共同制作与生活往来传给居民。现居世界并无原生伊拉奈德的后裔或直接遗产；文化重建依靠重生后的主动传播，也结合当地材料作出调整。

约前2785年，北部海岸形成较稳定的手艺人与同住家庭互助圈。约前2748年，三轮面谈成为接纳惯例，早期其中一轮须由艾洛希亚参与，使她对成员接纳有强个人影响。熟人引介和表达能力也可能使某些申请者更易被理解，面谈传统从一开始便有局限。

随着人口与公共事务增长，她逐渐承担持续地方责任。827年，伊诺莱卡公国与大公公职获正式确认；1136年，常设接纳人员的职责成文，大公不再是每位申请者必须见到的人。现代的接纳、记录和复核由正式机构承担，她可以讨论制度，却不能以私人好恶撤销已取得的资格。

### 公共服务与地方权力转型

1042年政教分离、1064年司法独立使公共机构与个人裁判分开。1462年工坊和学校账目区分大公个人支持、私人捐赠与公共拨款。1659—1666年建立常年公共服务预算，艾洛希亚推动将服务使用与人的尊严联系起来，也面对财力、人手和设施不足。

1696年的长期承诺与收入说明制度，要求善意同时具有财政依据。1809年扩大地方平等直选，1816年责任政府章程规定行政首席由议会选出；她不能因不喜欢某位首席而阻止合法就职。1878年公共文化资助与独立专业评审进一步分开，她自己的艺术活动也不构成干预评奖和合同的理由。1904年重要施政程序修订，为现代联席施政会议奠定基础。

### 中央议长任期

她曾十一度隔届当选议长。各完整任期均从起始年9月1日至结束年9月1日前。

| 届次 | 任期 | 主要工作与争议 |
| --- | --- | --- |
| 4 | 1762—1767年 | 推动必要救助不被身份门槛阻挡；提高标准所需经费引起自治派争论。 |
| 8 | 1782—1787年 | 在1783年权利争讼后推动行政整改与财政补救；地方设施缺口仍需逐步解决。 |
| 15 | 1817—1822年 | 要求公共资助学校与救济机构不得按信仰排斥，引发慈善自主与公共责任之争。 |
| 22 | 1852—1857年 | 扩大城市服务和劳动保护预算，回应电力应用安全；地区执行差距仍在。 |
| 27 | 1877—1882年 | 推动必要服务与劳动预算，面对新增支出的资金来源争执。 |
| 30 | 1892—1897年 | 600民选席加六皇族席结构稳定，代表资格趋于平等；议长候选范围仍封闭。 |
| 35 | 1917—1922年 | 推动安置、劳动与服务保障，面临对外扩张威胁和防卫支出压力。 |
| 39 | 1937—1942年 | 战时推进配给申诉、救济与征用核对；1942年届满仍卸任。 |
| 42 | 1956—1961年 | 推动1958年九年最低义务教育及公共服务，继续协商地方课程与财政。 |
| 47 | 1981—1986年 | 推进环境治理成本公开和居民参与；1984年跨海公路引起土地、环境与交通方式争议。 |
| 51 | 2001—2006年 | 推进跨邦记录互认、到达者后续支持，同时限制无限共享个人资料。 |

1942年全国公平选举无法完成后，中央议长职位空缺至1946年，采用有限看守行政。艾洛希亚没有自动延任，卸任后仍保有地方大公与议政会成员身份，继续参与地方照护和重建。战后对临时迁入者受到的不平等待遇进行审查，1956年、1968年又先后加强公共服务申诉与居民参与。

### 2026年现状

2026年，她参加议长选举，首轮获生态共同党支持，但未进入第二轮；生态共同党随后改荐千樱。她与其他参选皇族均不登记党籍，地方公职不因中央竞选结果改变。

地方施政中，她推动成人学习、无障碍工作室与公共工具借用成为稳定服务，与市镇和劳动组织促使方案增加地方网点及夜间安排，最终预算同时限制高成本新建。

在地区医疗网络调整中，她认为交通和照护成本被低估，启动正式复议。政府经公开协商保留地方急诊、日间照护与交通支持，缩小集中规模，但没有完全保留她希望维持的两处住院部。公民议会以89票超过86票特别门槛通过修订方案；她保留部分意见，仍履行公布责任，并继续监督服务可达性。

## 公共职权与影响

艾洛希亚主持十人联席施政会议，在其中有一票。128席公民议会掌握立法、预算和政府信任，她没有地方议员表决票。她可主动提案、要求评估替代方案，并对列明的长期事项有限复议；民选政府和议会能够坚持不同路线，法院独立处理争议。

她对艺术、真实感受、平等和公共责任的坚持，与伊诺莱卡的创作文化和高福利制度有长期联系。具体制度经过居民、劳动组织、教育医疗人员及政府的反复协商，她既是重要推动者，也受到现实条件与公众批评的约束。其创作、私人审美和公职影响分别存在，不能将她的个人艺术评价当作官方标准。
