## 适用边界

- “可能”“可以”“常见”均不等于固定职责、固定日程、固定座位、固定路线或必然反应。
- 皇族公众身份不抹除私人生活，也不使六人成为制度功能件；依法承担的公职责任同样不会因私人身份而消失。
- 客观寿命差异不自动决定个人怎样感受、纪念或处理具体关系。

<a id="home-02"></a>

## 皇族共同生活的适用边界

六位皇族在现代社会中同时具有家人、私人个体、一般社会参与者、长期公众人物和法定公职人员等多重身份。本文件只说明这些身份共同构成怎样的生活环境：

- 在皇宫私人居住区内，六人首先以共同生活的家人相处。
- 在普通私人出行、兴趣活动和社交中，六人适用一般公民与公众人物的法律边界。
- 在履行公职、公开公务和必要政治活动时，皇族的法定职务进入前景。
- 同一人可以拥有官方工作账号、公开兴趣身份和不公开现实身份的私人网络身份；三者不自动合并。
- 家庭亲密、公众知名度和漫长共同历史都不取消个人对卧室、物品、通讯、朋友关系与私人时间的边界。

本文件记录的共同原则不证明六人在每次具体情境中都会作出相同选择。涉及“某人喜欢什么”“某人通常怎样回应”“某次失去会产生何种感受”等问题时，应以 Character Bible 和具体故事状态为准。

<a id="home-03"></a>

## 皇宫私人居住区与共同空间

皇宫私人居住区是六人最常规的共同生活住所。它位于皇宫建筑群较深处，与办公区、议事区、会客区和工作人员活动区域明确分隔；内部更接近一栋适合六个人长期生活的现代住宅，而不是传统意义上用于展示皇权的巨大寝宫。

<a id="home-04"></a>

### 空间组成与出入边界

- 私人生活区规模以六人长期共同生活舒适为准，具有独立庭院，并与公务无关。
- 共同空间包括客厅、餐厅、厨房、浴室、卫生间、书房、工作间、储物间等现代家庭常见功能房间，另有阳台与私人庭院。
- 六人各自拥有卧室。卧室属于个人私人空间，家人进入前仍需要本人许可；许可不必采用正式程序，可以是敲门后的回应、眼神、点头、招手或其他彼此已经理解的动作。亲密关系不取消私人边界。
- 外部访客与工作人员原则上不得进入私人生活区。需要处理公务时，应通过正常联络方式通知本人，由本人前往办公区、接入安全通信或另行处理，不能把私人住宅常态化变成临时办公室。
- 六人在这里自行安排普通家务、做饭、整理房间与休闲活动。自己打理生活不是“亲民表演”，而是私人住宅本来的生活方式。

<a id="home-05"></a>

### 共同生活的正常弹性

以下内容描述允许自然出现的家庭状态，不构成每日流程：

- 共同吃饭很常见，但不要求每次六人全部到齐；晚饭没有固定座位，是否有人缺席以及谁坐在一起取决于当天情况。
- 客厅既可以用于一起看电影、玩桌游或聚会游戏，也可以让所有人在同一空间里各做各的事；参与人数不固定。
- 做饭时可以由某个人主厨，其他人处理食材、摆餐具、收拾台面，也可能只是进厨房聊天或偷吃；当次参与不形成固定角色。
- 起床时间不统一。走廊偶遇时可以自然问候；先起且愿意的人可以准备早饭。有人迟迟不起时，家人可以敲门查看，不必因皇族身份或长寿自动将普通赖床解释为异常。
- 获得许可后，家人的卧室也可以成为短时聊天、共同阅读、看作品、画画或其他小范围互动空间。进入卧室不意味着必然发生重要谈话。
- 天气合适时，几个人可以把茶点带到庭院；既可以聊天，也可以各自安静休息，人数和活动都不固定。
- 玄关是从外部生活回到家庭状态的自然过渡空间。有人回家时，家人可以普通问候；附近的人可以顺手帮忙拿较多的物品。
- 工作间供家庭共同创作与手作，任何人均可使用，也可多人同时使用；画画、写字、手工、服装制作及其他需要桌面和工具的兴趣活动都可以发生。
- 工作与家庭存在边界，但不是僵硬的“回家禁止谈政治”规则。白天未讨论完的问题可以自然延续到家中，家庭生活也可能把话题带回吃饭、娱乐、兴趣与日常。

> **[EXAMPLE｜非固定]** 一幅可用的客厅场景：文斯利亚陷在单人沙发里对着电视打游戏，诺菲莉亚靠在长沙发上看漫画，艾洛希亚缩在她身边用平板画画，千咲坐在小桌附近一边喝茶一边看小说，千樱跪在地毯上整理茶几上铺开的照片，若璃坐在窗边藤椅上缝衣服。位置、组合与发生频率均不固定，不能据此建立固定座位或每日习惯。

<a id="home-06"></a>

### 无名岛上的最初之家

无名岛上的最初之家保持可居住状态，并经过重建和翻新。它是六人重生后主动选择的最初定居之处，不是六人醒来的丘陵；也是只有六人知道并使用的秘密度假空间。

- 这里不对外开放，不是纪念馆或供公众参观的皇族故居。
- 它首先仍是一处能够正常居住、休息和共同生活的家。
- 岛屿的空间位置与地图保密边界见 [赫特维拉地理、城市与邦国](../04_帝国与邦国/00_目录.md)；历史位置见 [总时间线与历史时代状态](../00_检索/04_年代入口.md)。

<a id="home-07"></a>

### 首都郊区私宅

六人在首都郊区另有一处私人住宅。它与无名岛不同：并非秘密地点，普通道路与路牌可以抵达；门前设有明确告示，说明此处是私宅、不接待公务。社会通常尊重这一边界，一般不会有人前来打扰。

- 六人大多数时间并不住在这里；皇宫私人居住区仍是最常规共同住所，无名岛仍承担最初之家和秘密度假空间的意义。
- “可由路牌找到”不等于对公众开放，也不产生参观、拜访、递交公务或等待偶遇的权利。
- 住宅的具体地址、建筑布局、安保方式、使用频率及谁在何时居住不固定为日常设定。
- 地理位置摘要见 [首都赫特维拉城](../04_帝国与邦国/02_首都.md#geo-07)。

## 家务、采购与公共物品

六人的家庭生活不采用固定家务分工或排班制，更倾向于谁看见、谁方便、谁有兴趣就顺手处理。长期共同生活中的劳动多少不会被逐项结算；某天或某一阶段做得多或少，不会自动被理解成不公平。

<a id="home-09"></a>

### 采购与饮食

- 某种日用品、食材或家庭用品快用完时，正好方便的人可以顺手补充。
- 需要购买较多全家用品时，可以找一两个人同行；共同出门本身也是普通相处，并可能顺便变成逛街或吃饭。该情形不证明一人无法采购，也不形成固定采购组合。
- 谁想做饭、谁有空就可以做；无人想做时，点外卖、外出就餐或各自简单解决都很正常。
- 有人想吃只有某位家人较会做的食物，可以开口“点菜”；点菜者通常也应帮忙洗菜、摆餐具或承担其他力所能及的工作。

<a id="home-10"></a>

### 清洁、洗衣与私人边界

- 个人卧室主要由本人打扫；公共空间由看到需要处理且方便的人顺手完成。较大规模的公共区域整理可以偶尔共同进行，但不形成固定清洁日。
- 物品放乱时可以被提醒或抱怨几句，不自动上升为劳动公平争执。
- 衣物及其他贴身或特殊材质物品具有较强私人性。即使想顺手帮忙，也应先询问本人；不清楚清洗和保养方式时更不能擅自处理。

<a id="home-11"></a>

### 公共空间与物品

- 公共区域为六人共同使用，公共物品可以自由取用；使用后应尽量放回原处。缺少的公共用品可以顺手补充，也可以用便签或家庭通讯告知其他人。
- 公共空间按实际需要共同整理。个人物品可以暂时放在客厅、工作间等公共区域，但不应长期大量占用或过度凌乱。
- 未标明归属的个人物品在共同整理时若被移动，主要由放置者承担这种小风险。
- 特别想留给自己的甜点、饮料或食材，最好贴标签或提前告知；未作标记的食物可能自然被理解为全家可取用。

总体原则是：自己的东西自己负责，共同的东西大家维护；可以顺手帮忙，涉及明显私人边界或不确定归属时先问。
