## 皇族公务、私人生活与紧急联络

六位皇族的公共职务真实存在，但不持续占据私人生活。皇族身份主要在履行法定职责、公开公务和必要政治活动时进入前景；成熟行政体系使国家与邦国的日常运转不依赖六人随时亲自介入。

- 公务频率随实际需要变化。某天可以连续处理多项重大事务，也可能数日没有必须由本人完成的公务。
- 正常事务应在工作安排中处理；重要但不紧急、确需本人确认的事项可以设合理期限，不要求为形式上的“及时”占用当日非工作时间。
- 是否接受非工作必需的采访、节目邀请、公益或文化活动，由本人自行决定；皇族身份不形成持续曝光义务。

共同人物倾向的待定范围见 [C-01](../90_维护/03_共同人物候选.md#c-01)；具体反应按人物文档与当时情境判断。

<a id="home-13"></a>

### 皇宫中的工作与私人生活

办公、议事、接待和工作人员活动位于皇宫公务区域；私人住宅位于建筑群更深处。即使公务需要本人处理，也应先通过正常联络渠道，而不是让工作人员直接进入住宅。

六人在家中可以谈论工作，也可以完全进行普通家庭活动。界线的功能是阻止公务系统无条件侵入私人住宅与时间，不是禁止家人自愿讨论政治。

### 邦国往返、公众偶遇与私人身份

邦国首府的交通尺度见 [四邦首府与多中心城市网络](../04_帝国与邦国/03_四邦格局.md#geo-12)。现场、远程与通信方式按下文[公务时间与紧急联络](06_皇族公务与社交.md#home-16)决定，具体交通选择见[首都与邦国空间的私人使用原则](06_皇族公务与社交.md#home-17)。

- 私人场合不承担以公职身份即时回应政治问题的义务。公众可以通过正常政治、媒体或公务渠道询问，不能借街头偶遇迫使本人表态。
- 围堵、尾随、持续纠缠和其他越过私人边界的行为，适用普通隐私、骚扰、跟踪及相关法律。六人可以像其他公民一样依法处理，是否违法由正常执法和司法程序判断。
- 私人购物、排队、交通与服务不因皇族身份产生额外资格。依法设置的公务安保、活动秩序及工作需要属于公共职责安排，不等同于私人特权。

共同人物倾向的待定范围见 [C-01](../90_维护/03_共同人物候选.md#c-01)；具体反应按人物文档与当时情境判断。

### 公开账号、创作账号与私人账号

皇族的网络身份可以按用途自然分层：

| 账号类型 | 定位与边界 |
|---|---|
| 官方工作账号 | 属于公共职务的一部分，可以由秘书、新闻或相关工作人员共同运营，用于发布公务信息、活动和政策说明。可以适量出现私人化内容，但须考虑公共传播影响。 |
| 公开专业或兴趣账号 | 可以不以皇族身份为内容中心。公众即使知道账号归属，也不能把每项创作或兴趣活动自动解释为公职行为。 |
| 真正私人账号 | 通常不公开皇族身份，与普通人的网络使用相同。只要不利用匿名身份欺骗或牟取不当利益，便没有向所有网友披露现实身份的义务。 |

> **人物接口：** [艾洛希亚·优莉耶·伊诺莱卡（Elocia Yulie Inolaika）](../02_人物与创作/03_艾洛希亚.md#doc-char-elocia) 将公开作品、选择性接受委托并与其他画师交流定义为艾洛希亚的个体行为倾向，可用于公开专业／兴趣账号场景。六人是否必然知道彼此的私人账号属于 `[OPEN C-02]`，不得由家庭亲密自动推导。

### 公务时间与紧急联络

现代政府应有成熟的事务分流标准，不把所有公共事务直接送到皇族本人。是否联系本人，取决于事项是否涉及其法定权限、政治责任、不可替代的确认或重大决策；行政体系能够处理的事务留在正常流程。

- “重要”与“紧急”分开判断：重要性决定最终责任层级，紧急性决定是否需要在非工作时间立即处理。重要但不紧急的事项等待正常工作时间。
- 真正紧急的事项通过预先确定的渠道联系本人。秘书、值班机构或政府负责人具有明确判断标准；满足条件时不因担心打扰私人生活而延误。
- 若不立即行动会明显影响国家立场、公共安全或大量国民，例如突发外交事件、重大灾害、战争响应、严重国家安全事件或需要最高层及时确认的突发事件，公职责任优先进入处理。
- 紧急联络不自动要求本人前往现场。安全远程办公、视频会议、电子文件或授权能够解决的事务可以原地处理；只有现场协调、外交礼仪、重大政治沟通或其他确需本人到场的情形才出行。
- 非工作时间不要求六人主动维持持续工作状态，但真正必要的事务始终有可靠渠道联系到相应责任人。私人生活受到尊重，与承担公共责任并不矛盾。

法定公职、正常中央决策与国家存亡级危机权限的主定义，见 [政府、法律、公民身份与公共安全](../05_国家制度/00_目录.md)。

## 首都与邦国空间的私人使用原则

首都与四邦的客观位置、交通和城市结构由 [赫特维拉地理、城市与邦国](../04_帝国与邦国/00_目录.md) 主定义。本文件只规定六人的使用边界：

- 私人时间可以像普通居民一样步行、使用公共交通、购物、就餐、看电影、参观展览及处理其他私人事务。
- 公务出行是否使用公务车辆、安保或其他安排，由具体工作与真实安全需要决定。
- 前往四邦处理工作时，可根据事项选择高速铁路等现代交通、远程办公或安全通信；不因具备超自然能力而默认用能力通勤。
- 城市商业区、大学区、公园、海岸和各邦文化地点均是可使用的公共空间，但客观可达不等于任何人的固定路线或固定偏好。
- 皇族私人使用公共空间时适用一般公众人物边界；公务活动则可以依法安排安保和秩序措施。

## 家庭外兴趣身份与朋友关系

六人在家庭以外可以拥有真实的兴趣身份和社会关系。长期线下相处者通常必然知道其皇族或政治身份；关系能否长期保持普通人格位置，关键不在对方永远“不知道身份”，而在知道后仍不把身份变成索取内幕、炫耀关系或寻求特权的工具。

<a id="home-19"></a>

### 熟人与朋友

- 店员、摊主、经常合作的工作人员或因某项事务反复接触的人，即使熟悉多年，若交往一直具有明确目的，默认仍是熟面孔或熟人，不自动成为朋友。
- 朋友关系通常在目的性之外的相处中自然形成：因某件事认识，后来分享私人话题、共同兴趣或单纯想见对方。认识时长本身不决定关系深度。
- 家庭外社交不是六条固定的人际支线，不要求每人拥有固定地点、固定朋友圈或固定社会功能。

<a id="home-20"></a>

### 权力、利益与边界

- 长期朋友不能利用私人关系谋求政治、行政或经济特权；六人也不能利用公权力为朋友提供不当便利。
- 私人关系与本人正在处理的公共事务发生直接利益冲突时，由正常制度判断是否需要披露、回避或采取其他程序。
- 朋友关系不自动赋予干涉其他人际关系的资格。朋友不能因亲近要求对方减少与家人或其他朋友往来；家人也不因亲密而当然掌握对方全部朋友圈。
- 成为其中一人的朋友，不等于自动成为六人的共同朋友。
- 隐私、私人空间与许可边界在朋友关系中依然成立。
- 邀请朋友参加吃饭、电影、展览、旅行等非政治私人活动是允许的。活动若进入六人共同居住的私人空间或原本属于家人的共同安排，会自然征求其他家人意见；明显只属于家人的纪念、度假或聚会，不需要为表现友好而邀请外人。
- 关系终止与后代的边界见 [寿命差异、关系结束与关系不继承](06_皇族公务与社交.md#home-22)。

<a id="home-21"></a>

### 网络朋友与兴趣圈

网络朋友若从一开始知道真实身份，或后来得知后仍能恢复普通互动，可以自然发展为线下朋友。朋友互相介绍进入新的兴趣圈是普通社交现象，但是否长期参与取决于本人真实兴趣。

朋友关系可以带来新的创作者、玩家、文学爱好者、运动爱好者或其他社群接触；这只确认环境允许，不为任何人指定固定圈层、朋友数量或参与倾向。

## 寿命差异、关系结束与关系不继承

赫特维拉社会长期存在不同寿命、身体年龄和经验年龄的人共同生活。寿命差异不自动构成人际隔阂，也不能把“活得更久”理解为在人格关系中天然更高、更有权威或必然更成熟。

- 六人可以与身体年龄、实际生活年数和寿命预期不同的人建立普通友情。外表年轻的永恒存在可以与年长普通人直接以朋友相处；活过漫长岁月的人也可以认真向年轻专业人士学习陌生领域。
- 关系可以因死亡、迁居、生活轨迹变化、价值观变化或自然疏远而结束。结束不等于关系失败；曾经真实存在的相处本身可以具有意义。
- 私人关系只属于具体个人，不会自动扩展到家族、子女或后代。朋友的子女不能凭上一代关系自动取得私人联系、进入家庭空间、获得政治照顾或继承特殊资格。
- 六人可以因朋友认识其家庭成员，也可能在数百年后与同一家族的后代重新成为朋友；那是彼此独立的新旧关系。“世交”最多是社会描述，不构成关系继承。

共同人物倾向的待定范围见 [C-03](../90_维护/03_共同人物候选.md#c-03)；具体反应按人物文档与当时情境判断。

永恒存在、身体状态与寿命机制见 [宇宙论与超自然机制](../01_世界原理/00_目录.md)。本节不由客观机制反推人物心理。
