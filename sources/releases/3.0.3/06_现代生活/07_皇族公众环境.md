## 兴趣公众形象、粉丝与同人文化

六位皇族既是真实政治人物，也是长期处于大众视野中的大型公众人物。公众对其兴趣、作品、生活习惯、外貌和性格的关注可以脱离政治支持。正式公职形象、兴趣活动中的个人形象、公众根据碎片信息形成的想象，以及家人和私人朋友所了解的状态，不会完全重合。

<a id="home-24"></a>

### 粉丝、同人与公众想象

- 每个人都可能拥有从兴趣、作品、生活方式或外貌切入的粉丝群体；这种关注不等于政治追随。
- 现代网络存在活跃的皇族粉丝与同人社群。同人文、CP、友情向、梦向、AU、同人图、漫画、手书、Q 版、动物塑和表情包等创作可以普遍存在。
- 皇族兼具政治人物与一般公众人物身份，不因此成为不可戏仿、不可幻想或不可二创的神圣对象。
- 六人不能完全控制自己的公众形象。采访、活动与作品能够影响公众理解，但公众仍会考据、误解、想象、投射和二次创作。
- 大量跨时代资料可以形成“人物考据”文化；网友比较各时代留下的公开记录，以及相应技术出现后的采访录音、影像和照片，可能形成准确或离谱的私人形象推测。资料形式须符合产生年代，不能凭空引用早期现场照片。本人没有义务逐条纠正。

表达自由、虚构与伪造现实声明的区分，适用 [现代社会与普通日常生活](00_目录.md) 的一般规则。写作此类帖子与作品时，发言者位置、用词和信息来源统一遵守 [论坛与同人作者的位置](../02_人物与创作/09_写作规则.md#core-13)。

## 商业、网络与隐私边界

皇族身份引起的日常问题原则上仍按一般公众人物标准处理，不另建“皇族专属”的私人保护或特殊宽容。六人拥有与其他公众人物同性质的隐私、名誉和人身边界，同时在公职、公款、利益冲突和公共行为方面承担合理范围内更高的监督。

<a id="home-26"></a>

### 商业边界

- 六人具有真实政治人物身份，因此不接受普通商业代言、付费品牌广告，或以皇族身份进行私人商业背书，以避免政治权力与企业利益混合。
- 公益广告、公共健康、防灾、文化遗产保护等明确非商业性质的公益宣传，可以根据本人意愿参加。
- 分享私人照片和动态时，应避免明显暴露具体店名、品牌名与商品名，以降低无意中形成官方推荐或商业带货的风险。
- 公众可以依据装修、包装和街景自行考据，但民间推测不等于本人确认。

<a id="home-27"></a>

### 行程、匿名身份与一般隐私

- 帝国政府不会为满足公众兴趣而公开皇族私人行程。
- 皇族本人没有为纠正网友考据而证实某次私人消费、位置或匿名账号的义务；无害传闻可以长期处于“普遍猜测、没有正式确认”的状态。
- 私人消费、匿名账号和非公务活动不因皇族身份自动转化为公职声明；是否公开由本人决定，但不得利用匿名身份实施欺诈、规避法定利益冲突或牟取不当利益。

公开场合偶然拍摄、长期追踪、私人空间、公共利益调查及虚构内容的判断标准，直接适用 [媒体、网络与一般公众人物](03_媒体与公众知识.md#soc-16)。本文件不另设更宽或更窄的一套皇族隐私门槛。

<a id="home-28"></a>

### 平台与内容规则

正常报道、讨论、考据、讽刺、虚构、同人、现实声明伪造、冒充账号、骚扰、人肉搜索与位置泄露的区分，统一适用 [虚构内容、平台规则与跨国接触](03_媒体与公众知识.md#soc-19)。皇族场景只增加一项边界：六人不能因身份要求平台删除所有本人不喜欢的内容，也不要求建立专门的皇族审查待遇；法律责任仍由普通法律和正常程序判断。

## 私人海外旅行与外交身份边界

正式外交访问由 [现代国际世界与跨国流动](../09_国际与战争/00_目录.md) 主定义。本节只规定私人海外旅行中的公私边界：

- 六人海外旅行的目的可以完全私人。目的地要求赫特维拉公民申请旅游签证时，原则上也依对方规定办理；存在免签或其他一般便利时，按相同规则使用。皇族身份不产生当然入境权。
- 东道国可以依据自身法律、安全惯例与外交文化，要求提前通知、安排保护、采用特殊入境程序或限制进入敏感区域。赫特维拉原则上尊重对方主权决定。
- 若上述安排使私人旅行失去意义，六人可以选择不前往，不能要求外国采用赫特维拉国内的公私边界标准。
- 私人旅行没有外交目的，不保证没有外交后果。在国外的公开言论、与敏感政治人物接触、参与争议性活动或评价当地政治制度，都可能被外国媒体、政府或公众理解为具有国家意义。
- 其他国家不必然共享赫特维拉关于皇族私人生活、宗教、寿命差异或社会边界的价值观。六人在海外须遵守当地合法规则，并认识到公共身份在国外更难被完全搁置。

共同人物倾向的待定范围见 [C-01](../90_维护/03_共同人物候选.md#c-01)；具体反应按人物文档与当时情境判断。
