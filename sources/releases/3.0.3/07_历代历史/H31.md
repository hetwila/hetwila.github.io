# H31｜0—99年：公共空间第一次长期获得保护

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

<a id="hist-h31"></a>

## 历史概述

0年，瑟芮纳南港公共禁制系统正式启用，持续覆盖港口、市集及相邻居住街区，运行不再依赖某个能力者一直维持。这是后世纪年采用的事件；当时参与者首先关心工程能否可靠运行、维护费用如何承担，而非宣布世界进入新的时代。

公共禁制让居民第一次能够较长期地相信，市场交易、公共议事和家庭生活不必随时屈从于某个强能力者。普通暴力、财富差距和政治压迫没有随之消失，但其中一种极难约束的威胁受到环境本身限制。

赫特维拉及其他国家陆续建设自己的公共系统。费用与维护人才限制覆盖，首都和重要港口优先获得保护，许多乡村仍按旧方式生活。禁制区内外的生活差异成为本世纪新的政治问题。

## 重大事件

| 编号 | 年代 | 重大事件 | 主要结果 |
|---|---|---|---|
| <a id="h31-01"></a>H31-01 | 0年 | **瑟芮纳南港首套大型公共禁制系统正式启用。** 系统长期覆盖港口、市集和相邻居住街区，运行不依赖某个能力者持续维持。 | 首次满足现行纪元锚点的全部条件，普通公共生活获得较稳定的能力干涉防护。 |
| <a id="h31-02"></a>H31-02 | 6年 | **南港受保护街区出现租金与迁居争议。** 商户和居民向覆盖区集中，部分原住家庭难以承担上涨的成本。 | 保护带来新的机会，也使土地、住房与共同出资的受益分配成为现实矛盾。 |
| <a id="h31-03"></a>H31-03 | 13年 | **赫特维拉首都首期公共系统启用。** 部分港湾、市场与相邻住区获得持续保护。 | 帝国开始拥有合乎公共用途的长期设施，覆盖仍限于首都的部分区域。 |
| <a id="h31-04"></a>H31-04 | 21年 | **尚华主要港区的公共系统投入运行。** 运输经营者、地方管理者与中央协同承担维护。 | 商贸和仓储获得更稳定环境，邻近未覆盖聚落要求分享保护或减轻分担。 |
| <a id="h31-05"></a>H31-05 | 29年 | **瑟芮纳数港协作提供材料与维护人员。** 南港经验经共同培训和相互协助向其他港口传播。 | 建设与维修开始形成港际网络，费用和人员调配推动更多持续协商。 |
| <a id="h31-06"></a>H31-06 | 38年 | **塔维恩首批核心城市公共设施启用。** 中央以集中征收与人员调配支持重要港市和内陆驻地。 | 公共保护扩大，同时加强中央对关键城市的财政与行政影响。 |
| <a id="h31-07"></a>H31-07 | 47年 | **赫特维拉受保护城镇发生工坊迁移与改业。** 部分依赖外部能力的生产转到区外，部分经营者改用普通工艺。 | 工匠需要重新学习或承担搬迁成本，区内外的职业分布开始变化。 |
| <a id="h31-08"></a>H31-08 | 56年 | **安瑟兰与弥岚的部分城镇合作培养维护人员。** 双方通过既有贸易网络互换公开经验与所需物资。 | 较小城镇取得建设机会，弥岚继续独立发展自己的公共事务安排。 |
| <a id="h31-09"></a>H31-09 | 64年 | **洛岑未覆盖地区提出维护费用分担申诉。** 一些聚落需为受保护市场供粮、供工，却仍承担本地能力威胁。 | 中央给予部分调整，谁应出资、谁先得到保护成为持续争端。 |
| <a id="h31-10"></a>H31-10 | 73年 | **纳哈尔重订核心河盆城市的建设次序。** 水利中心、市场和宗教公共场所分别要求优先保护。 | 资源配置反映不同地区与机构的影响力，公共防护继续依附当地既有政治结构。 |
| <a id="h31-11"></a>H31-11 | 84年 | **赫特维拉部分城市减少临时调集能力者护市。** 普通守备、工务和文书人员承担更多连续事务。 | 对少数强者日常介入的依赖开始下降，教会及旧有能力管理仍承担大量职责。 |
| <a id="h31-12"></a>H31-12 | 96年 | **受保护市场的债务、强占和普通暴力纠纷集中上报。** 居民要求管理者持续处理日常侵害。 | 禁制无法替代裁判与公共治理，安全改善后显露出的事务逐渐超出旧有处理方式。 |
