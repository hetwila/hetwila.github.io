# H48｜1700—1799年：现代政治框架与共同保障

## 历史概述

皇家议政会逐步成为公开审议法律、预算和重大政策的平台，现代行政与独立司法的主要框架形成。议长由帝国公民在皇帝之外的五位皇族中直选、任期五年且不得连续任职的制度在本阶段确立，皇族身份与公共问责并存。1747年诺菲莉亚成为首届民选议长，1752年若璃接任。民间政治团体开始围绕全国性竞选、预算与地方治理形成持续组织，普通代表的资格平等仍需后续改革。

全国共同权利、地方自治和最低保障得到更完整的法律表达。非自愿跨世界到达者的共同体接纳传统转为自动取得帝国国籍的明确制度，地方成员资格则另行处理；皇权危机权限被收束到国家存亡级危机。

大国政治也在变化。塔维恩形成总统制共和国，瓦雷斯推翻旧王权后建立共和国，奥瑞斯保留由永恒存在阿维兰长期担任君主的结构，同时扩大议事与专业行政。共和国、君主制和宗教传统国家都可能工业化，没有一种政体天然保证和平。

## 重大事件

| 编号 | 年代 | 重大事件 | 主要结果 |
|---|---|---|---|
| <a id="h48-01"></a>H48-01 | 1704年 | **塔维恩共和章程生效，确立总统与代表机构。** 港口和内陆政治力量在征税、财政及行政权争议后重组共同政府。 | 总统制共和国的主要结构形成，选举资格和地区代表仍继续调整，并未终止对外利益竞争。 |
| <a id="h48-02"></a>H48-02 | 1711年 | **赫特维拉把多项既有保障编入全国共同权利文本。** 人格平等、人身自由、信仰与表达、劳动及司法保护获得更完整的共同依据。 | 基本权利原则上保障帝国管辖范围内所有人；中央政治权利与地方政治成员资格仍另行区分。 |
| <a id="h48-03"></a>H48-03 | 1719年 | **非自愿跨世界到达者自动取得帝国国籍的原则被明确确认。** 确认其到达性质后，国籍效力原则上自到达帝国领土时成立。 | 接纳不再依赖地方领袖特许或入籍申请，也不要求放弃原有身份；邦国国籍仍需另行取得，接应能力继续分阶段建设。 |
| <a id="h48-04"></a>H48-04 | 1726年 | **帝国与邦国议定最低公共保障及相应财政分担。** 基础教育、必要医疗、最低生活救助与基本司法和劳动保护逐步纳入共同底线。 | 邦国可选择提供更多保障，财政薄弱地区获得支援；最低标准的实际落实仍需人员、设施和监督。 |
| <a id="h48-05"></a>H48-05 | 1734年 | **中央日常决策的主要职责获得成文划分。** 行政准备、议政会公开审议表决、依法由皇帝确认和政府执行分别承担责任。 | 皇帝确认权被限定为制度性关口，拒绝确认须提出公开且可审查的理由；独立法院继续处理具体法律争议。 |
| <a id="h48-06"></a>H48-06 | 1741年 | **新一轮宪制谈判中的废除君主制提案再次被文斯利亚否决。** 改革参与者继续讨论议长选举、议政会权力与皇权边界。 | 保留君主制成为这一轮妥协的前提，未被采纳的共和主张仍可公开表达；本次否决不扩展为普通政策或司法案件上的任意权力。 |
| <a id="h48-07"></a>H48-07 | 1746年 | **现代议长选举制度确立。** 帝国公民从皇帝之外的五位皇族中直接选举议长，任期五年，不得连续任职。 | 日常中央政治领导获得定期民意授权，候选范围保留皇族长期责任的特殊结构；议长不能取代集体决策。 |
| <a id="h48-08"></a>H48-08 | 1747年 | **首次依新制度举行的全国议长直选完成。** 各地核对帝国公民资格，以文书和纸面投票组织选举，诺菲莉亚成为首届民选议长。 | 全国性政治选择开始实际运行，不能以缺少本邦国籍排除帝国公民；外籍居民不参加中央选举。 |
| <a id="h48-09"></a>H48-09 | 1752年 | **首次按五年任期完成议长轮替。** 若璃接替诺菲莉亚，卸任议长不接续担任下一届，行政档案、预算和日常职责依程序交接。 | 不连续任职从条文转为实践，中央协调工作的延续逐渐依靠公共机构而非某一人的长期在位。 |
| <a id="h48-10"></a>H48-10 | 1758年 | **司法独立的人员与履职保障进一步制度化。** 最高层级法官不由皇权直接任命，各级行政机关不得指示具体裁判。 | 既有独立裁判原则获得更稳定的组织保障，中央与邦国的法律争议继续交由专业司法处理。 |
| <a id="h48-11"></a>H48-11 | 1764—1768年 | **瓦雷斯在财政危机、城市抗争和军队分裂中推翻旧王权，建立共和国。** 不同地区和政治力量争论新政府的代表与军政安排。 | 共和国取得制度起点，旧有社会冲突和军队政治影响并未消失，后来仍可能走向军政化与扩张。 |
| <a id="h48-12"></a>H48-12 | 1771年 | **奥瑞斯扩大公共议事和专业行政的职责。** 阿维兰保留君主身份，更多预算、地方事务和行政工作由常设机构办理。 | 长寿君主与制度改革并存，奥瑞斯没有采用赫特维拉的五位皇族议长选举结构。 |
| <a id="h48-13"></a>H48-13 | 1778年 | **皇权危机权限的适用范围与退出义务获得明确限定。** 只有常规制度不足以应对国家存亡级危机时，才可在必要范围内集中战略协调。 | 经济困难、社会抗议和普通政治僵局不能成为启动理由；危机措施须受监督并在条件恢复后退出，不能永久取消基本权利或邦国自治。 |
| <a id="h48-14"></a>H48-14 | 1783年 | **工业地区迁居家庭围绕学校和必要医疗提起的共同权利争讼获得裁判。** 地方曾以缺少本邦成员资格为由拒绝部分服务。 | 法院确认邦国资格不能排除帝国保障底线，权利主张与财政补救开始更直接地结合。 |
| <a id="h48-15"></a>H48-15 | 1787年 | **补煤港、航运服务与海军采购竞争扩大。** 多国重新争取海外据点，德拉维亚部分成员提出把商业协作进一步扩展到共同防务。 | 工业运输利益与国家战略联系加深，社会改革没有消除海外不平等或国家间冲突。 |
| <a id="h48-16"></a>H48-16 | 1792年 | **共同保障的报告、监察与财政支援开始稳定衔接。** 中央依据地方报告、居民申诉和实地调查要求改正最低服务缺口。 | 保障执行逐步超出地方自行承诺；中央监督针对共同底线，各邦较高福利和文化制度仍可不同。 |
| <a id="h48-17"></a>H48-17 | 1798年 | **帝国修订军需采购与交通动员安排。** 工厂、铁路、港口和专业人员被纳入较持续的国防规划。 | 战争准备更依赖普通工业、组织与后勤，为H49的工业国家竞争奠定条件，尚未进入最后一次世界战争。 |
