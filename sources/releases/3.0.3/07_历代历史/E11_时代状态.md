# Era 11：改革与工业化

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

人物所知与尚不可用的条件；具体历史事件另查H年表。

<a id="hist-68"></a>

## 起止标志

- 起点：禁制普及开始持续削弱个人能力、教会行政和地方私人武力三种旧权力基础。
- 终点：国家政治接近现行体制，工业化战争结构与近现代制度已经形成。

<a id="hist-69"></a>

## 世界与社会状态

- 禁制普及削弱三种旧权力基础：能力者不能仅凭个人力量凌驾公共秩序；教会管理能力者的行政必要性下降；地方领主依靠直属能力者和私人军事力量维持独立的能力下降。国家也越来越不需要六位建国者亲自处理每一次危机。
- 改革的主轴是三种“去特殊化”：政治去宗教化，使国家法律获得独立于戒律的正当性；政治去个人化，以官僚、司法、议政和地方制度替代对少数永恒强者的日常依赖；社会去能力化，使公共安全不再要求每个人服从更强能力者。
- 政教分离是长期制度分化，而非突然的反宗教革命：戒律先作为法律，随后出现补充规则，国家法逐渐形成独立体系，教会行政职能转交世俗政府，最终宗教保留信仰、伦理、文化与历史传统，而国家法律不再需要宗教理由才能成立。
- 地方制度从领主自治逐渐转向现代邦国自治。个人权力被成文制度、地方代表机构和公共行政吸收，地方自治由“个人特许”转为地区居民与邦国制度的宪制权利；中央与地方的长期战争和妥协成为现代联邦结构的历史来源。
- 禁制促进可测量、复制、标准化和大规模生产的普通技术。机械、工程、化学、医学、电力与信息技术逐步取代依赖特殊能力者解决问题的方式，工业体系发展。

<a id="hist-70"></a>

## 六人所处状态

- 国家对六位建国者逐次处理日常危机的依赖下降，六人的公共角色开始从直接处理转向制度性、连续性和最高层责任。
- 文斯利亚接受帝国的部分民主化与皇家议政会制度，但出于守护家人的目的，以一票否决权否决所有废除君主制的提案。此为已确认的历史行动；已记载的改革节点按中央政治史；全部提案、次数与逐人过程尚不完备，不能外推普通政策上的任意否决权。
- 诺菲莉亚在联邦化后担任伊拉奈德教国大祭司，重新修订教义并逐步推动政教分离；她与艾洛希亚主动保存和传承伊拉奈德文化。
- 联邦化后艾洛希亚领导伊诺莱卡，千咲与千樱共同治理千世，若璃治理尚华并对商业与贸易发展产生重要影响。827年确认四邦及五人的邦国领导公职，1042年起教国执政与大祭司分立；职权的后续变化按各邦政治史。五人至2026年仍实际影响重要决策，并受民选议会、政府、法院与社会力量约束。

<a id="hist-71"></a>

## 已知信息

- 社会逐渐确认禁制可以长期压低个人能力对公共秩序的支配，普通可复制技术能形成比个人能力更稳定的公共能力。
- 政教、中央—地方和皇权—制度之间的转变是长期过程；不能假定某一单独法案瞬间完成全部改革。

## 尚不存在

- Era 初期尚未同时具备完整世俗法治、成熟联邦行政、现代社会保障和 2026 年级别的工业信息体系；这些结构在本 Era 中逐步形成。
- 现代战争结束后的长期和平秩序尚未开始。
