## 长期冲突的四条线

赫特维拉的政治史并非中央不断退让、地方不断获得自由的单线过程。中央曾保护地方居民免受领主和教会强制，也曾以战争与公共工程为由长期征收。地方组织既保存语言、共同土地和互助制度，也可能排斥新住户、雇工和没有组织资格的人。居民要求自治时，有时是在反对中央，有时是在反对声称代表地方的少数人。

| 冲突 | 中央或统一规则的理由 | 自治与限制权力的理由 | 最终形成的主要制度 |
|---|---|---|---|
| 谁决定共同负担 | 防卫、禁制、交通和救灾不能由一地独力承担 | 地方必须知道征收用途、期限及承受能力 | 预算审议、财政公式、减免和独立审计 |
| 谁能代表地方 | 中央需要能够签约、供给、执行的人 | 领主、行会或旧住户未必代表全体居民 | 邦国议事机构、地方选举、全国公民直选 |
| 何种生活应当共同 | 基本人身权利、迁居和共同市场需要一致底线 | 语言、教育特色、文化及增量福利需要不同选择 | 权限列举、共同保障、司法审查与地方实施 |
| 谁有权领导中央 | 六位建国者提供持续责任和危机经验 | 日常政策应能被公众改变，普通人应能进入决策 | 五位皇族议长直选、民选议政代表、专业政府与法院 |

现代制度保留了一个持续争点：公民能选择中央政治方向、民选代表和大量实际行政负责人，却不能成为议长候选人。支持者将它理解为对建国者长期责任的限定使用；反对者认为公职资格仍不完全平等。这一分歧没有在1746年或战后消失。

## 前2953—前1501年：共同生活先于层级政府

早期人口稀少、增长缓慢，维持一条航路或一个共同仓舍本身就需要长期合作。建国之初只有在场的人、可信赖的见证和实际保护，没有覆盖所有聚落的常设中央官署。后来转移者和本地出生居民逐渐进入共同体，通常寿命居民不能等候永恒存在经过数十年观察才承认其土地、婚姻或生活选择，决定应在多长时间内作出，开始成为实际政治问题。

不同文化获得传习资源是六人的主动选择，也形成了不同的公共事务网络。诺菲莉亚、艾洛希亚、千咲、千樱与若璃逐渐承担地方责任，文斯利亚希望她们能够独立治理、做自己不能代替的事。这里已经存在不同判断，但尚不存在现代“中央—邦国诉讼”。有分歧时，通常重新会面、交换见证、调整共同劳动，严重时有人离开或拒绝继续提供物资。

前1580年的协议整理仍属于形成国家的准备。它不设议长，不产生公民选举，也不能追认所有此前的家人谈话都是皇家议政会会议。

## 前1500—前1001年：战争使会商成为常设统治

前1500年前后，《海陆约章》把各地保护、供给和持续行政相连；前1494年固定帝国称号。前1386—前1336年的洛岑粮道战争暴露了临时征调的困难：同一批粮食可能被重复承诺，远方地方人员不知道命令是否已被修改，地方损失又常晚于军需上报。

前1382年开始持续军需会商。六人、相关领地负责人、仓储和运输人员围绕当期战争反复议事。前1341年，文书、召集和议决记录获得较稳定的延续安排，战争结束后仍处理征用结算、供给争议及地方承认。这是皇家议政会逐步成为常设制度的关键节点。

此时成员来自身份、实际统治与承担供给的能力，并不代表居民平等。文斯利亚可以直接作出最终决定，地方代表主要是在解释能交出多少粮食、需要保留什么。会议留下账目与前例，限制了部分任意命令，却仍是直接统治的一部分。前1324年若璃参与的战后清账，说明“同意征发”与“承认征发已经结清”逐渐成为两件需要记录的事。

## 前1000—前201年：集权的效率与累积代价

<a id="t04-section-005"></a>

### 仓税叛乱：同一面自治旗帜下的不同利益

前794年临时征收被继续保留，前788年又追加负担。农户反对重复收取，运输者反对多个机关索要同一批物资，地方领导则不愿中央查验自己实际留存多少。前783—前742年的仓税叛乱因此不是一个立场整齐的自治运动。

前779年部分领主宣布脱离中央，同时继续向居民征收，甚至拒绝解释去向。一些原本支持减税的村社转而向中央求助；另一些仍认为中央征发才是首要问题。战争压制叛乱后，前735年的调查和前719年的减免、归还承认了征收中的实际错误，但没有建立普遍选举或完整救济权。

这场冲突留下两种相反记忆：中央强调共同防卫不能被地方挟持；居民强调临时征收必须能够结束。后来的自治派与共同保障派都能从中寻找依据。

<a id="t04-section-006"></a>

### 西南通道战争：议政会成为动员中枢

前591—前516年的战争使交通、粮储和能力者调度更集中。前538年文斯利亚与议政会直接核定重点领地军需，确实减少了各自留存造成的缺口，却也使遭受歉收的地区难以及时调整义务。部分四邦前身同样承受征发，不因皇族领导而处于统一制度之外。

会商中出现了长期的行政倾向：先完成中央总额，再让地方自行分配代价。地方则倾向于少报可用资源，要求每次危机单独协商。双方对彼此的不信任加强，文书更多，却未必更能反映普通家庭的实际处境。

<a id="t04-section-007"></a>

### 商路封锁与城市发言

前286—前267年的东部贸易封锁使港市证明自己不仅是收入来源，也掌握仓储、航运和供给知识。前259年的供给协商为城市组织留下较稳定的发言惯例。然而有资格到场的人多是经营者和公共事务负责人，码头劳动者与迁入住户的利益仍被间接代言。帝国更集权的同时，参与集权运作的社会力量也在增多。

<a id="t04-chapter-05"></a>

## 前200—599年：禁制改变统治的基础，自治战争改变谈判对象

公共禁制从0年以后逐步扩散，供水、维修、筹资和技术岗位成为公共安全的必要条件。保护不再主要依赖某位强者愿意亲自出面，居民也开始追问：承担维修费用的人为什么没有查账和决定用途的资格？这种变化没有立即终结旧权势；掌握工程、土地和收费的人还可能形成新的垄断。

327—374年的沿河自治战争来自长期收费、征发和账目争执。部分领主把维护旧权作为自治，城镇代表要求地方查账，工匠、农户与无组织居民又要求进入地方决定。中央同样存在坚持军事压制和主张重新分担的不同意见。374年和议保留共同国防与供给义务，同时确认城市查账、地方议事和较固定负担，381年后的私兵整编削弱了个人以武力排斥地方居民的能力。

461年西境和议以后，弥岚多数地区进入帝国。其原有城镇联合、土地债务和议事传统不能简单归入四邦制度。469年的防卫与对外职责转移、477年的关系承认、485年的中央发言，意味着加入帝国的条件必须成为中央机构能够持续遵守的承诺。皇家议政会于是越来越需要面对“有自己制度的共同体”，而不仅是承诺服从的地方首领。

<a id="t04-chapter-06"></a>

## 600—999年：从地方特许到联邦地位

642年教义修订、674年前后的宗教与市场裁判争执，使公共规则能否脱离某一宗教解释进入更广讨论。761年洛岑重新议定防卫义务与地方保留收入，说明长期安排已经不能只依靠统治者当次宽免。

794—824年的联邦谈判围绕三项困难展开：旧协议有的互相矛盾，有的只有领主保存副本，有的只承认城市而忽略其腹地。804年整理旧约，812年扩大参议，819年形成草案，824年重组生效。它没有抹去强弱差别，却使中央和地方必须在同一套成文结构中说明权限。

827年确认四邦及五位领导，832年明确首都直辖，839年起继续确认其他邦国。863年议政会扩大地域和政治力量参与，预算、共同规则不再只由皇族内部商定。代表资格仍有财产、组织与身份限制，居民尚不能平等选择中央领导。

872年军队整合防止邦国以独立军队作为常规谈判工具；884年对恢复个人特权的抵制，又表明自治已不能完全等同于地方领导本人的权力。统一货币于931—972年间逐步推行以后，收费、债务和跨邦经济关系进一步需要共同规则，但地方财政与文化事务仍有自己的决定空间。

<a id="t04-chapter-07"></a>

## 1000—1499年：公共权力开始具有不同的责任主体

1042年的政教分离和1064年的司法分工，使“这个决定是否合乎法律”逐渐不再只是向皇族请求重新考虑。1075年后的专业法院可以处理中央、邦国及跨地区争端；1091年的费用和翻译支持，决定普通居民是否真的能够使用这些权利。

对议政会而言，这是一种实质失权，也是一种工作转变。它不必继续为所有地方争执亲自判输赢，而应制定能够重复适用的规则、核准共同支出、追问行政结果。诺菲莉亚的宗教解释、五人的地方领导和皇族作为议政成员的发言，逐渐需要说明自己使用的是哪一种公职权限。

1124—1263年的西部整合又带入山地公地、旧王国与河港共和传统。中央不能假定只有四邦的地方模式才有合法历史；原有共和国也不能因为“从来如此”，永久把雇工和新住户排除在外。公共职位的续任、账册移交和地方代表更换逐步增加，但这些规则不适用于把永恒皇族的身份改成普通官员任期。

出版、学校和工艺交流扩大之后，一项议政决定开始被从未到过首都的人讨论。公开理由、定期账目和可以抄录的议决摘要，比“某位长期领袖亲自保证”更容易跨地区传播。此时已有意见网络与请愿联合，尚无后世遍布全国的成熟政党机器。

<a id="t04-chapter-08"></a>

## 1500—1698年：工业社会要求全国政治能够回应个人

工厂、铁路和港口把此前相距很远的劳动者纳入同一生产体系。跨邦铁路征地、1640年联合停工、1653年公共卫生危机表明，决定权仍分散在地方，损害和利益却已经沿生产链传播。劳动者要求全国底线；部分邦国担心中央借此接管全部学校、医疗和警务；地方既得利益也会借自治语言反对任何保护成本。

1647年的劳动条款和1659—1666年的公共服务常年预算证明，更稳定的保障可以在地方首先建立，再经全国协商扩展。1668年议政会增加预算讨论和非皇族代表参与，但代表的进入仍不平等。1673年废除君主制提案被否决，参与者并未因此一致放弃改革：有人接受保留皇族而扩大民选权力，有人继续主张共和国，有人反对改变候选资格却支持财政监督。

1682年结社空间扩大，为跨地方政治组织提供了条件。1687—1691年金融危机又使“由哪里救助迁居家庭”成为共同问题。1693年全国保障诉求与1698年定期选择中央协调者的方案相连：人们希望能够改变政策负责人，而不必诉诸叛乱、领主谈判或期待皇族自行发现问题。
