## 历史概述

前2953年，文斯利亚在已经发生的外部接触与冲突之后提出建国，以“赫特维拉”声明家人和共同生活空间受到保护。他们此时了解的是其他重生者及其共同体，尚不知道转移者和本世界出生居民的存在。最初的声明只能指向实际生活的岛屿、往来锚地与愿意加入者；六人既没有国土全图，也无法据此支配周围所有居民。国名开始流传，国家仍主要存在于承诺与实际防卫之中。

加入者在附近岛屿及大陆海岸形成小规模聚落。食物、工具、船只与伤病照料依靠互助和交换，伊拉奈德关于伤害、承诺、自我约束的戒律成为处理纠纷最容易援引的依据。负责解释戒律、保存记录和安排公共事务的人尚无明确职业区分。

同一时期，世界其他地区也有独立形成的重生者聚落。有些欢迎陌生人，有些依附强者，有些刻意远离别人。赫特维拉并非共同人口源头；它只是许多重新开始的社会之一。

## 重大事件

| 编号 | 年代 | 重大事件 | 主要结果 |
|---|---|---|---|
| <a id="h01-01"></a>H01-01 | 前2953年 | **文斯利亚提出建立赫特维拉。** 在此前与其他重生者的接触与冲突之后，他声明保护家人、居所及愿意一同生活者；六人此时尚不了解转移者和本世界出生居民的存在。 | 建国判断来自当时所知的重生者社会；这不证明其他地区尚无两类人口。保护主张依实际联系而定，完整国界和全国制度尚未形成。 |
| <a id="h01-02"></a>H01-02 | 约前2945年 | **早期加入者议定分散定居与相互接应。** 人们在附近岛屿、可用锚地和大陆海岸选择住处，共同安排必要的食物、工具与船只。 | 形成少量彼此联系的聚落；加入者没有全部迁往最初之家，也未占据附近所有土地。 |
| <a id="h01-03"></a>H01-03 | 约前2930年 | **一支沿岸武装向往来船只强索物资，引发锚地冲突。** 文斯利亚与受影响居民介入，迫使参与强索者停止行动并退还部分物资。 | 共同保护得到实际检验，附近居民却仍可选择独立生活；一次防卫胜利没有转化为持续驻守整片海岸的能力。 |
| <a id="h01-04"></a>H01-04 | 约前2915年 | **数个聚落共同采用关于伤害、守约与救助的处事惯例。** 诺菲莉亚等人参与解释伊拉奈德基础戒律，居民以见证和调解处理争执。 | 宗教伦理、公共事务和私人信任尚未分开；这些惯例并非完整法典，也不以新的神谕作为每项决定的依据。 |
| <a id="h01-05"></a>H01-05 | 约前2905年 | **来往者带来其他独立重生者聚落的消息。** 零散交换使海岸居民得知更远处也有人重新建家、接受保护或结成武装。 | 赫特维拉对其他地区的认识逐渐扩大；外国社会的人口与发展并不都源自本地的外迁。 |
