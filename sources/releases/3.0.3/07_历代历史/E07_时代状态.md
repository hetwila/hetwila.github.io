# Era 7：建国与早期政教合一

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

人物所知与尚不可用的条件；具体历史事件另查H年表。

<a id="hist-36"></a>

## 起止标志

- 起点：文斯利亚提出建国，“赫特维拉”首先作为对外的边界、主权和防卫声明出现。
- 终点：早期岛屿—沿岸势力圈逐渐稳定，人口与自然出生世代增长，社会开始更系统地向大陆内陆开拓。

<a id="hist-37"></a>

## 世界与社会状态

- 最初的“国家”只是纸面概念：对内仍是家庭，对外则是主权与防卫声明。
- 国家名“赫特维拉”源自古典伊拉奈德语，意为“永恒的家园”。国家不是以共同血缘或民族来源建立，而是为了让一群人拥有可以长期共同生活的家。
- 一部分外来重生者决定加入并被共同体接纳后，六人的家庭开始变成真正社会。面对杀害、欺骗、财产、誓约、家庭责任、资源分配和纠纷处理，当时没有现代法学传统，最直接可用的成体系规则是伊拉奈德文明留下的宗教戒律。
- 早期国家并非主动设计神权政体。戒律从宗教伦理自然转化为共同体规范、裁决依据和公共规则；宗教、司法、行政与家庭伦理尚无清晰边界，政教合一是制度未分化的结果。现代国名中的“神圣”可追溯至此。

<a id="hist-38"></a>

## 六人所处状态

- 六人的私人家庭首次同时承担公共共同体的创始核心；对内家庭关系与对外国家身份尚未完全分化。
- 文斯利亚提出建国这一事实固定；其余五人的具体支持方式、早期职位、分工与争论未在世界观稿中固定。

<a id="hist-39"></a>

## 已知信息

- 六人与共同体已经知道其他重生者和冲突存在，需要可识别的边界、防卫与纠纷规则。
- 加入赫特维拉共同体的人并不只生活在六人的定居小岛；附近岛屿与大陆沿岸已经处于共同体的保护、接触或组织范围。世界其他地区仍存在未加入赫特维拉的重生者及独立势力。
- 伊拉奈德戒律是当时可直接调用的成体系规范，但其宗教正当性与现代世俗法律正当性不能混同。

## 尚不存在

- 独立成体系的现代世俗法律、专业行政、独立司法、成熟联邦与现代邦国自治尚未形成。
- 公共禁制与纪元 0 年体系尚不存在。
