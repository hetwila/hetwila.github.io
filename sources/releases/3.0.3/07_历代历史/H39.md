# H39｜800—899年：联邦结构正式确立

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

<a id="hist-h39"></a>

## 历史概述

长期地方冲突、财政协商与新地区加入汇合为一轮联邦重组。国家正式采用“神圣赫特维拉联邦帝国”全名，逐渐以成文共同权限和地区制度界定中央与地方关系。地方自治开始从领导者的个人特许转为能够延续的公共权利。

伊拉奈德教国、伊诺莱卡公国、千世公国与尚华公国的邦国地位及皇族领导身份在这一阶段固定。它承接早期主动文化重建、居民形成的地区组织与五人的长期责任，也使文斯利亚支持妹妹们独立参与国家管理的意见取得制度落点；四邦不是在此时才由他把私人领地分配给家人。诺菲莉亚担任教国大祭司与领导人，艾洛希亚领导伊诺莱卡，千咲与千樱共同领导千世，若璃领导尚华。其他邦国可以采用不同领导结构，四邦不是全国唯一模板。许多地区从聚落吸收、合并中形成自己的文化、传统和制度，部分前身原本是独立国家。洛岑、弥岚及港口联合等既有共同体分批成为联邦邦国，加入帝国与后来合并为一邦并非同一日期；具体沿革见邦国形成与国家整合专题。

首都岛保持中央直辖。中央对外交、共同防卫和跨地区基础秩序的责任获得更明确依据，地方负责大量日常行政。现代平等权利、选举和司法程序仍需后续建设，联邦成立并未一次完成全部改革。

## 重大事件

| 编号 | 年代 | 重大事件 | 主要结果 |
|---|---|---|---|
| <a id="h39-01"></a>H39-01 | 804年 | **中央汇集各地加入协议、财政约定与自治保障。** 文书人员整理相互重叠或冲突的承诺。 | 重组以既有关系为基础，不能只按东部四地的经验重新安排全国。 |
| <a id="h39-02"></a>H39-02 | 812年 | **联邦协商扩大参与地区。** 城市、传统领地及其他地方组织派出交涉者。 | 不同制度能够进入同一谈判，代表资格仍取决于地方权力与组织地位。 |
| <a id="h39-03"></a>H39-03 | 819年 | **联邦共同约章草案形成。** 草案分别说明国家共同责任、地方事务与争议处理的基本安排。 | 财政、防卫和地方持续自治开始取得相互关联的成文依据。 |
| <a id="h39-04"></a>H39-04 | 824年 | **联邦重组的核心安排生效。** 文斯利亚确认重组，国家正式采用“神圣赫特维拉联邦帝国”全名。 | 中央与地方关系进入新的制度阶段，地方自治开始以地区制度持续存在。 |
| <a id="h39-05"></a>H39-05 | 827年 | **四邦法定地位及皇族领导身份确认。** 伊拉奈德教国由诺菲莉亚任大祭司与领导人，伊诺莱卡公国由艾洛希亚领导，千世公国由千咲、千樱共同领导，尚华公国由若璃领导。 | 主动文化重建与地方共同体的长期演变取得联邦地位；五人的领导兼具地方发展基础、自身参与及文斯利亚支持其独立治理的意见，各邦日常机构继续发展。 |
| <a id="h39-06"></a>H39-06 | 832年 | **首都岛中央直辖及相关公共责任确认。** 首都与大陆各邦分别安排港务、交通和共同设施事务。 | 首都不归入四邦，跨海往来继续依当时可用的航运组织。 |
| <a id="h39-07"></a>H39-07 | 839年 | **其他邦国和新成员的地方制度分批确认。** 不同地区保留各自的领导、议事与日常行政形式。 | 聚落联合、旧领地和独立国家加入等不同前史形成制度多样性；联邦没有把四邦皇族领导结构复制到全国，具体案例见[邦国形成与国家整合](../04_帝国与邦国/08_国家形成_02_01.md#polity-later-entry)专题。 |
| <a id="h39-08"></a>H39-08 | 846年 | **中央共同支出与邦国财政分担取得实施安排。** 地方保留收入和上缴义务分别记录并按情形协商调整。 | 联邦财政开始较持续运行，富裕地区、边地与受灾地区仍有利益分歧。 |
| <a id="h39-09"></a>H39-09 | 854年 | **诺菲莉亚以大祭司身份推动联邦化后的教义补订。** 教会继续讨论信仰、邦国领导与公共职责的不同依据。 | H37的修订与新制度接续，政教分离仍须经更长期的人员、财产和法律调整。 |
| <a id="h39-10"></a>H39-10 | 863年 | **皇家议政会扩大地区与政治力量的持续参与。** 更多重要法律、支出和共同事务进入集体讨论。 | 议政会进一步成为国家政治平台，皇族之外的参与增加，但远未实行普遍平等选举。 |
| <a id="h39-11"></a>H39-11 | 872年 | **共同防卫与军事统辖进一步归入中央框架。** 部分地方残余私人武装解除或调整为受共同统辖的守备。 | 邦国自治逐渐与独立军事权分离，执行仍因地区条件而有先后。 |
| <a id="h39-12"></a>H39-12 | 884年 | **部分领导者试图恢复个人特许而遭地方组织反对。** 城市与邦国援引已确认的制度要求继续履约。 | 自治不随领导者个人意愿任意取消的原则得到实际检验。 |
| <a id="h39-13"></a>H39-13 | 896年 | **安瑟兰各地区扩大共同议事与内部约束。** 谷地、城镇和较大农业地区重订合作责任。 | 安瑟兰沿自身路径整合，双方交流经验而保留不同政治结构。 |
