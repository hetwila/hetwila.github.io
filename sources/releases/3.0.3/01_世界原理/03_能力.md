# 超自然能力与六人的能力边界

## 生命、意识与超自然能力

生命不需要神圣起源，可以是自然规律长期演化的产物。秩序使结构能够被保存，混乱使结构能够变化；生命恰好是在持续代谢、修复、生长、适应和繁殖中维持“自己仍然是自己”的复杂稳定结构。

> **核心结论：** 生命：能够通过持续变化，主动维持自身秩序的结构。

所有生命天然拥有内部固有力量。它不是可储存消耗的“魔力”，而是生命作为独立存在的底层性质，是其存在结构在力量层面的表现。真正稀有的不是“有没有力量”，而是这种内部性质是否能够与外部平衡力量发生耦合并干涉世界。

| 层级 | 表现 |
|---|---|
| 自身维持 | 所有生命都具备，是生命存在的基础。 |
| 感知外界力量 | 部分生命可能对异常、魔物或能力波动表现敏感。 |
| 干涉外界力量 | 真正意义上的能力者可以令自身力量与外界平衡发生耦合。 |

意识可以作为复杂生命自然演化的结果。当前体系存在三条不同意识形成路线：原初秩序凝聚为秩序意志；物质生命复杂化产生普通意识；混乱力量长期模仿生命意识后聚合为混乱意志。

<a id="cos-15"></a>

### 固有力量与能力机制

> **核心结论：** 能力表现 = 个体特征 × 认知方式 × 控制技术 × 外界状态。

超自然能力不是与自然规律并列的另一套独立规则，而是能力者暂时拆开局部平衡，使自然规律的稳定表达出现可控偏离。理论上可以产生水、火、温度、物质状态、重力、空间甚至时间干涉，不受传统元素体系限制。越接近世界底层结构，越难稳定干涉。

能力与人的内部存在结构高度相关。没有两个人的能力完全相同，也无法像标准化技术那样通过固定文本、图式或口令原样学习。能力可以表现相似，但底层过程可能完全不同；所谓复制通常只能复制结果或表象。

能力成长不是“学会新的法术”，而是不断发现自己的存在究竟能够怎样影响世界。训练可以教授感知、控制、降低负担、恢复平衡和实验方法，但不能把别人的能力直接教给另一个人。人格会影响使用方式，却不应机械决定能力类型。

<a id="cos-16"></a>

### 能力使用、战斗与表现形式

这个世界观不存在固定的“技能”或招式清单。能力者能够做什么受个体存在结构、控制水平、力量负担和外部环境限制，但每次具体怎样使用能力取决于当时目标、距离、对象、地形、风险与个人选择。同一能力者可以用不同方式实现相近目的，也可以在不同战斗中采取完全不同的做法；训练形成的是控制能力、判断和经验，不是必须按固定名称与动作发动的招式。

能力真正起作用的是无形力量对局部平衡和自然现象的干涉，战斗不要求先取得对应的外界物质。火、水、冰、风压、光或其他可观察现象只是力量造成的表现形式，不是能力的独立元素来源，也不能仅凭表现形式反推能力本质。能够主动干涉外界的能力者均可在不同程度上实现快速移动、飞行和身体强化；不同个体能够达到的速度、高度、强度、精度和持续时间各不相同。

能力发动时可以出现与个人对应的光。代表色只标识力量属于哪个人，与能力性质、元素、人格和强弱没有必然关系：红色光不等于火焰能力，蓝色光也不等于寒气或冰。具体代表色及视觉表现由 [代表色与光](../02_人物与创作/08_视觉共通规则.md#visual-06)主定义。

“擅长某种能力”只表示同等条件下更容易发挥、控制或承担相应负荷的倾向，不等于其他能力完全不会。能力倾向决定一个人较容易做到什么，个人判断决定其在特定情境中怎样做；不能从擅长领域直接推出固定武器、站位、战术、性格或团队职能。

<a id="cos-17"></a>

### 六人的学习、实力与协作边界

六人的控制、力量与判断来自持续练习、彼此交流和实战；初次接触能力不等于掌握全部用法。各人的首次学习与知情时点见 [重生前的同行与知情边界](../00_检索/03_纪年与时代.md#hist-06)。

六人各有相对擅长的方向，但都能在不同程度上完成攻击、防御、治疗、移动和身体强化。擅长战斗者也能治疗，擅长治疗者也能战斗。多人协作时，他们可能依据当时的能力优势自然分工，却不存在必须长期固定的前卫、后卫、治疗者、输出者或支援者配置。

重生后六人的综合实力在外界看来大致相当，擅长方向不同，但每个人都具有足够强的独立作战能力。通常不需要为了应付一场战斗特意凑齐六人；具体由谁参加取决于事件性质、所在位置和个人选择。六人之间没有明确、稳定或通用的实力排名，单一项目上的优势不能换算成综合强弱顺序。

六人能够把自身力量凝聚为实体武器，这种武器称为“圣剑”。圣剑不依赖外界材料，可以随能力收起和重新具现；重生前常被用作战斗武器，但不表示每个人都把它作为惯用武器。重生后，大多数战斗无需具现圣剑，通常只有使用非常强的力量时才会使其实体化。圣剑不是固定招式，也不是力量的物质来源。

### 六人的能力倾向

| 人物 | 相对擅长的能力 | 使用特点与限制 |
|---|---|---|
| 诺菲莉亚 | 火的控制；远距离、大范围干涉 | 不特别擅长需要频繁变向、范围很小的精确攻击，但并非做不到。本来的身体素质一般，能够调动的力量上限很高。重生后仍可消耗自身生命力换取远超常态的力量；这种献祭不会使她死亡，但造成的生命力损耗和身体伤害不能由治疗能力消除，只能缓慢恢复。 |
| 艾洛希亚 | 水、冰等表现形式；远距离、小范围精密干涉 | 控制精度极高，对单个或少数对象可以集中极强的作用；范围扩大时，单位范围内能够维持的强度会明显下降。本来的身体能力很弱，但能以能力高精度控制和强化自身动作，突破原有身体能力上限；超过身体承受范围会造成实际伤害。 |
| 千咲 | 身体强化与武艺结合；近距离攻防 | 原有身体能力和刀法已经很强，学会能力后把特殊力量与身体力量融合。正面迎敌时力量强、攻守兼备，能够独自对抗大量敌人。战斗时更习惯使用自己的刀，而非圣剑。 |
| 千樱 | 身体强化与武艺结合；高速、灵活的近距离战斗 | 原有身体能力和刀法已经很强。绝对力量通常弱于千咲，但机动与变化更强，擅长快速移动和出其不意的近身行动。战斗时更习惯使用自己的刀，而非圣剑。 |
| 若璃 | 治愈；作用于单人或一定范围的恢复与强化 | 能够迅速治疗单个或范围内的对象，并可在一定程度上强化他人的能力。治疗和强化都消耗自身力量，不能无限持续。本来的身体能力一般，直接战斗时更倾向远距离，不特别擅长近距离作战，但仍具有独立战斗能力。 |
| 文斯利亚 | 没有单一明确专长；广泛能力与高阶结构干涉 | 几乎所有常见方向都能做到一定程度，但特定项目不一定超过更擅长的人。能够研究和干涉空间、时间等接近世界本质的结构；实际能力上限不为外界所知。 |

<a id="cos-19"></a>

### 能力负担、残余失衡与风险

能力的主要负担来自维持失衡并对抗世界自动恢复平衡的倾向。偏离越深、范围越大、持续越久，负担与失控风险越高。理想过程是“平衡 → 失衡 → 超自然现象 → 再平衡”；残余失衡可能形成异常环境、特殊器物，偏向混乱时甚至促进魔物形成。

力量失衡时代，世界本身容易被扰动，因此超自然能力普遍。秩序重构后，绝大多数世界的平衡恢复能力很强，即使生命仍有固有力量，也难以干涉外界；因此大部分现代世界已经没有可观察的超自然能力。主角团等继承秩序力量的特殊存在能够主动拆分平衡，属于例外。

<a id="cos-20"></a>

### 能力人口与可观测性

现代赫特维拉不存在可靠的“能力者总人口”官方数字。所有生命都具有固有力量，真正形成连续差异的是与外部平衡发生耦合的可能性、实际表现程度以及个人是否主动探索自身能力。大多数人不会接受专门训练或在无禁制环境中测试自己；即使具有较弱外部干涉潜力，也可能终身没有任何可观察表现，本人同样未必知情。

现代研究通常只能估计潜在比例，而不能进行完整人口普查。具有不同程度外部耦合潜力的人约占总人口两至三成，弱潜力并不罕见；真正曾明确认识到自己具有异常能力的人只占其中一小部分，能够经过训练稳定制造明显超自然现象者进一步减少，具有重大公共安全或军事意义的强能力者则极为罕见。这些比例只表示数量级，不是精确、统一或不可争议的人口统计。

现代制度原则上监管能力相关活动而不是潜在身份。一个从未使用、也无法在正常公共禁制环境中产生有效外部干涉的人，没有仅因“可能具有能力”而被登记的必要。进入无禁制研究区、接受特殊训练、从事超自然专业工作或使用合法局部解除权限时，才会产生相应资格、安全和活动记录。

<a id="cos-21"></a>

### 前禁制时代的能力强度与社会影响

前禁制时代世界更容易被局部失衡扰动，因此能力更容易被发现、训练和实际使用。能力者在人口中的可见比例、政治影响和战争价值都显著高于现代；永恒存在普遍具有较强能力，并在早期国家、武装团体和能力者组织中拥有远高于现代的存在感。

能力者总体呈明显的金字塔式分布：弱能力者数量最多，能够稳定主动使用能力者较少，足以显著改变战斗、生产或公共事务的强能力者进一步减少，而能够直接影响军队行动、城市安全乃至局部世界结构的个体极为罕见。强者稀少并不意味着弱能力没有价值；大量能力只适合治疗、感知、生产、工艺、航海、农业或生活辅助，并不直接适合战斗。

能力不采用统一的单轴“战斗力”等级。判断一个能力者实际作用时，至少需要同时考虑能力性质、最大作用规模、控制精度、使用负担以及发动条件。作用范围大不必然意味着战争价值更高；只能作用单一目标的治疗、感知或精密干涉能力，也可能在特定情境中比大范围破坏能力更重要。不同能力之间还可能存在明显克制、协作和环境依赖，因此个人强弱无法脱离具体任务和对手简单排序。

为了描述故事尺度，可以把实际影响粗略理解为个体级、建筑级、局部街区级、战场级、城市级和世界结构级，但这些只描述一次能力能够影响的范围与后果，不是正式等级，也不意味着城市级能力必须能够直接摧毁整座城市。扭曲大范围空间、瘫痪城市关键区域或制造覆盖城区的异常，都可能属于城市级影响。

六人属于前禁制时代已知能力者中的最高层级。其能力能够直接影响大规模战斗，对完整军队构成重大威胁，在特定条件下可以产生城市级影响，部分能力能够触及空间等世界底层结构。六人的优势来自力量规模、控制精度、特殊存在结构和长期实际经验的综合作用，而非单纯破坏力。综合比较仍遵守[六人的学习、实力与协作边界](03_能力.md#cos-17)。

六人并非不可战胜。永恒存在和其他特殊能力者中存在极少数实力接近者，某些人还可能在单一能力领域超过六人中的个体。多人协作、能力性质、环境条件、对方未知能力以及保护非战斗人员等现实约束，都可能显著改变结果。前禁制时代真正有组织的能力战争因此依赖侦察、治疗、防御、移动、压制、精密干涉等不同能力之间的组合，而不是由单一最强者自动决定胜负。
