## 重构后世界与禁制机制

主角团重生并长期生活的世界在重构后仍保留较高的可干涉性，因此少数能力者一直存在。现代社会之所以仍能与普通现代社会高度相似，关键在于“禁制”已经在现代国际社会中成为广泛采用的公共安全基础设施。

<a id="cos-23"></a>

### 禁制原理与作用边界

> **核心结论：** 禁制不是“消除超自然能力”，而是人为提高局部平衡的恢复倾向，使能力者试图制造的外部失衡在形成有效现象前迅速回弹。

禁制主要妨碍能力者向外界制造失衡，不会自动抹除个体内部结构，因此异常寿命、某些身体性质或被动感知未必会被普通禁制消除。禁制强度可以分级；现代工程追求足以保障公共安全的最低有效强度，而非无限提高稳定度。

现代公共禁制达到设计状态时，已经足以压制包括六人在内的已知强能力者。能力强度不能通过简单增加“输出”线性突破禁制，因为禁制改变的是区域本身恢复平衡的倾向；越强行制造失衡，只会面对更快的回弹、更高负担和更明显的异常响应。正常运行的现代公共禁制不应被任何已知个体单纯依靠自身能力强行突破。失效与解除的条件见下文[失效、解除与绕过的机制条件](04_禁制.md#cos-25)。

禁制的理论核心是：不必逐一针对不同能力，只要提高区域内力量恢复平衡的倾向，就能系统性妨碍所有依赖制造失衡的外部能力。该理论由多方长期研究累积形成；理论突破、公开、国家级扩散及纪元节点由 [Era 10：禁制革命与公共禁制纪元锚点](../07_历代历史/E10_时代状态.md#era-10)主定义。

禁制的研究史中，皇族六人与其他一些重生者提供的知识具有实际作用；理论论证、工程创新与公共支持各有贡献者。皇族支持普及，部分强能力者（包括部分重生者）则反对。知识来源本身不自动决定发明归属，详见[禁制革命史](../10_禁制革命/01_禁制革命_01.md#ban-research)。

<a id="cos-24"></a>

### 强度、覆盖与现代工程形态

现代禁制应是分布式、冗余化、可自动恢复的场稳定基础设施，而不是依赖单一塔楼、单一节点或具有仪式性质的固定阵式。城市公共区域、政府机关、学校、医院、交通枢纽、监狱与军事设施采用不同标准。

<a id="cos-25"></a>

### 失效、解除与绕过的机制条件

禁制可能因系统故障、设施破坏、合法解除、高度机密的绕过方法，或超出现有工程模型的世界结构级异常而失效。此类条件与单纯提高能力输出属于不同机制。
