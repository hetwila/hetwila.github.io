# 主动跨世界旅行与异世界生活

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

<a id="travel-01"></a>

## 适用边界

- 旅行机制的一般边界不预先决定每个目标世界的具体规则。
- 临时身份只提供必要的社会嵌入，不自动给予完美履历或无限资源。
- 可建立长期关系不等于关系必然发生，也不规定人物如何处理。
- 世界间时间关系未确定时不得自行换算。

<a id="travel-02"></a>

## 底层机制接口与术语

本文件的主动旅行体系属于重生后的长期研究成果。重生前的自动转移见 [重生前的同行与知情边界](../00_检索/03_纪年与时代.md#hist-06)；世界结构与夹缝机制见 [多世界体系与跨世界现象](01_世界结构.md#cos-03)。现代旅行中的语言转换作用于旅行者自身，不等同于原生阶段特殊个体间的意义层交流。

## 现代主动旅行的实现与限制

六人在长期关于世界本质的研究中逐步开发出主动跨越世界的方法。真正完成跨越的仍然是六人自身的特殊能力；现代设施的作用，是提供一个不受常规禁制压制、能够隔离和监测强烈世界结构干涉的安全环境。正常情况下，跨世界移动需要在中央直接管理的专用超自然研究设施中进行，而不会在住宅或普通公共空间随意发动。

- 现代研究已经能够确认不同世界的存在，并对部分目标世界形成大致轮廓，例如稳定程度、是否存在复杂生命或文明、与本世界的结构兼容程度和大致进入风险。但这种探测无法获得目标世界的完整地理、历史、政治、语言与社会资料。确认一个世界存在，不等于已经知道那个世界具体是什么样。
- 六人能够选择目标世界，却不能像输入地图坐标一样精确控制落点。长期经验可以降低危险并提高大致可控性，但到达后仍可能位于城市、乡村、荒野或与预期相距较远的地区，因此真正进入当地社会以后仍需要探索。
- 出发前会预先建立稳定的返回机制，可类比为存在结构内部的“开关”。主动触发即可沿既定联系返回原世界；若在目标世界发生肉体死亡，返回机制也会自动启动，并与重生者的重构复活过程衔接。返回机制不解除或绕过重构延迟；重构时点、延迟期间的死亡状态、光粒子出现条件及本人和服装的恢复范围，均依 [重生与存在连续性](02_生命与人口.md#cos-12)。该机制依赖六人自身的特殊存在结构，并不构成普通人的通用复活技术。
- 不同世界对特殊能力和规则偏离的承受程度并不相同。六人不会假定在赫特维拉安全的能力在其他世界也同样安全，因此陌生环境中原则上只使用对自身施加的最低限度能力。最常见的是语言理解与表达转换，使自己能够理解当地口语，并让自己的话被当地人按其语言理解；这不等于自动掌握陌生文字、历史和文化知识。
- 除非确有必要，六人不会使用能力直接干涉所在世界的物理规律、社会结构或他人意识。克制的原因既包括伦理边界，也包括对未知世界承受能力和连锁后果的不确定。

<a id="travel-04"></a>

## 出发、返回、时间、通信与携带

- 不同世界之间的时间并不同步。可以类比为同一平面上方向不同的两条线段：一段时间在另一条时间方向上的“射影”长度可能非常短。因此在另一个世界经历十年而赫特维拉只经过一分钟，在规则上完全可能。六人在建立临时世界联系时可以在一定范围内调整这种对应关系，使原世界经过的时间尽量缩短，但这种调整不是把某个世界真正暂停或加速，也不作为可无限精确设定的固定“时间汇率”。
- 必要时可以通过特殊能力进行跨世界通信，例如确认原世界是否出现必须立即处理的紧急事务或回传安全状态。但通信同样意味着维持跨世界联系，会造成额外干涉，因此不会像普通网络一样长期保持开启。
- 跨世界移动依赖旅行者本人的能力，不能让原本不具有相应能力的普通人通过“同行”直接跨越。六人可以携带物品，但携带对象越多、质量和结构越复杂，需要的力量越大，对世界结构的干涉也越强，因此跨世界能力不会自然发展成低成本的大规模物流方式。
- 前往不同世界所需的力量和风险并不相同。进入难度取决于出发世界、目标世界及两者之间的结构关系，而不是一套固定消耗。现代研究可以据此做出大致风险分类，但正式等级名称和技术参数仍保持开放。

<a id="travel-05"></a>

## 旅行的研究性质与私人意义边界

现代六人的主动跨世界旅行是自愿探索，可产生研究价值；没有持续旅行的法定义务，也不默认构成国家远征、征服或资源开发。

- 旅行可带回目标世界自然规律、生命形式、历史、社会、技术、宗教和语言等观测资料。一次旅行不保证形成突破性发现；当地关系也不自动转化为赫特维拉的外交关系，未经正式任务不得作出国家承诺。
- 跨世界旅行并非六人独有。历史早期，有能力者曾主动探索其他世界，相关知识与政治、军事和个人力量竞争联系紧密；现代禁制、科研与法治发展后，知识不再天然等于统治能力。
- 旅行之间需要能力恢复、观测资料整理与校验、跨越残留风险监测，也需为长期异世界生活后的精神恢复和生活适应保留时间。旅行不会高频连续发生，间隔不固定为统一数值。
- 对未知世界的行动须维持最低必要干涉。普通生活身份的具体选择、参与深度、职业与情感反应分别按人物与目标社会判断。

关于六人是否共享普通身份体验、研究兴趣、当地参与与离开偏好的候选方案，统一登记在 [C-04](../90_维护/03_共同人物候选.md#c-04)；本节不将其升级为六人的共同人格。

## 临时身份嵌入与初期适应

临时身份嵌入的最低必要性与解除要求是确定的机制边界；六人选择何种生活路径及愿意承受多少不便，见 [C-04](../90_维护/03_共同人物候选.md#c-04)。

不同世界、不同文明对“合法身份”的定义差异很大。六人不会预设现代身份证明是所有社会的共同规则，而会先观察当地社会究竟通过什么方式确认一个人的存在、归属和生活资格，再选择干涉最少的适应方式。

- 在身份管理较松散的前现代或地方共同体社会，陌生人往往可以通过口头说明来源、劳动关系、雇主、社区接触等方式逐渐获得生活位置。六人可以声称来自遥远地区，通过劳动换取金钱、食物或住宿，先以普通人的方式维持基本生活；这类情况下没有必要使用能力。
- 在拥有严格出生登记、身份证件、税务号码、银行、数字账户、医疗与住宿登记等制度的现代社会，六人面临的并不是“忘记带证件”，而是整个系统中原本没有其存在记录。即使如此，他们仍会优先探索是否存在无需完整身份即可暂时生活的合法或低干涉途径。
- 没有身份带来麻烦，本身不足以成为使用特殊能力的理由。只有当没有身份会直接导致拘留、持续追查、无法获得基本生活资料、无法合法居住或劳动，以至于几乎不可能作为普通人继续生活时，六人才会考虑以能力解决。
- 这种能力不是修改某个人的记忆，也不是制造一张能够欺骗行政系统的身份证件。六人会把自身的存在暂时加入目标世界的结构本身，使“他们是这个世界中天然具有合法身份的人”成为现实的一部分。若当地社会依靠数据库、纸质档案或其他身份结构，必要的下层记录会随世界结构形成一致状态。
- 为了降低干涉，能力只应建立维持普通身份成立所必需的现实连续性，而不是为六人创造大量复杂的虚假人生、权贵出身或不必要的社会关系。其目标始终是获得足以正常生活的最低限度普通身份，而不是借此取得地位或特权。
- 使用这种能力后，六人本人仍然知道真实经历，并不会把生成的身份背景当成自己的真实人生。其性质更接近临时建立一条能够被目标世界承认的现实连续性，而不是改变自身记忆。
- 离开目标世界时，必须解除这种临时嵌入，使为身份成立而额外建立的世界结构恢复原状，避免对当地社会造成不必要的长期影响。恢复的对象主要是为了身份合法性而形成的附加结构，而六人在实际停留期间真实做过的事情、与当地人真实发生的交往和已经产生的正常因果关系，不应被简单抹除。
- 因此六人在长期停留时通常也会避免主动建立难以退出、会使大量当地制度和他人长期依赖自身身份的高权力社会位置。尽量选择普通、低权力、可以自然离开的生活身份，与其“不利用能力追求社会地位”的旅行原则一致。
- 身份适应本身也是理解文明的一部分。一个社会允许怎样的人“存在”、一个没有身份记录的人还能否工作和生活、身份由国家数据库还是社区关系确认，都可以成为六人认识目标文明结构的重要观察入口。

### 非自愿到达者的适应支持

本小节只提供跨世界适应的路由，不重复帝国接应制度和教育体系：到达感知、现场安全、医疗、临时安置、帝国国籍与基础登记由 [跨世界到达者的法定接应](../05_国家制度/02_身份与接应.md#gov-08)主定义；语言、既有知识与技能评估、学校／职业衔接及成人继续教育由 [转移者、成人与继续教育](../06_现代生活/01_生活基础.md#soc-10)主定义。

共同原则是按个人实际需要提供支持，而不是按来源世界给人划定价值或“文明程度”等级；所有帮助以恢复独立生活能力为目标，不建立特殊公民等级。

<a id="travel-08"></a>

## 陌生世界中的普通生活

身份与基本生活条件允许后，旅行者可以选择工作、学习、参加社会活动，与当地人形成真实的同事、朋友或邻居关系。职业不必延续其在赫特维拉的公职；具体选择遵守个人能力、兴趣和当地条件。真实发生的生活及因果关系不因最终离开而失去真实性。共同参与倾向仍见 [C-04](../90_维护/03_共同人物候选.md#c-04)。

<a id="travel-09"></a>

## 长期生活、关系与离开

当地关系不自动变成外交关系或世代继承的私人资格。离开时解除身份附加结构，保留真实生活形成的正常因果，详见 [临时身份嵌入与初期适应](05_跨世界旅行.md#travel-06)。

是否预先告知离开、如何告别、是否留信、怎样经历依恋与恢复，都须依人物及关系判断；相关共同心理候选集中保存在 [C-03](../90_维护/03_共同人物候选.md#c-03)。
