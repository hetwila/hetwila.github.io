## 整体印象

看起来有点懒散、轻浮的青年，放松随意的姿态，嬉皮笑脸的表情，玩世不恭的态度，给人不正经、不靠谱的印象，没有人能从第一印象联想到他的身份。声音带一点少年感，有磁性。平时语调轻松，有时用夸张的语气开玩笑。

日常喜欢调侃别人，也喜欢拿自己开玩笑。偶尔有点中二。说话有点油嘴滑舌的，但很有分寸。真正认真时，声音会明显压低，说话变得非常简洁。自己一个人时很少主动开口说话，和妹妹们在一起时会活跃很多。

工作能力强，效率也很高，但态度总是看起来很散漫。经常偷懒，打游戏、看动画。被抓住以后，会一边笑一边找借口，甚至用夸张的演技装病。但真正需要他的时候，进入状态非常快，仿佛换了一个人。

在家人面前，不像皇帝，只是哥哥。喜欢打游戏，会赖床，会耍赖，偶尔幼稚，但永远值得依靠。以皇帝身份面对臣民或公众时，表情冷漠，看不出感情，声音低沉，说话简洁，决策果断，散发出的气场让人不免敬畏三分，完美的演技赋予了他作为统治者的威严，给人留下深不可测的印象。

<a id="char-wenslia-02"></a>

## 兴趣爱好与习惯

- 一个人时不常出门，更喜欢宅在家里，打游戏，看动画、漫画和小说。
- 喜欢少年系作品，喜欢看主角通过努力不断成长，也喜欢隐藏实力的主角。
- 喜欢打高难度的游戏，有时越打越投入，甚至忘记时间。
- 没事做了就去看看妹妹们在做什么，如果妹妹们愿意，他会陪着一起做，但不会故意打扰。
- 喜欢和妹妹们亲密接触，但能准确把握分寸，不会让她们感到不快。
- 重视纪念日，会提前很久给妹妹们买小礼物，准备一些小惊喜。礼物不一定昂贵，但一定符合每个人的喜好。
- 经常写日记，记录和家人之间微不足道的小回忆。尤其喜欢写妹妹们哪里特别可爱，明明已经写过无数次，还是会不厌其烦地反复写。
- 对妹妹们有掩饰不住的喜欢，会因为妹妹们和他亲昵而害羞，也会经常在心里喊“妹妹太可爱了”。
- 喜欢和妹妹们在一起做任何事，享受和她们在一起的时光。
- 喜欢站在能看见所有人的位置，仅仅是看着妹妹们就让他觉得心情舒畅。

<a id="char-wenslia-03"></a>

## 行为倾向

- 被夸奖：嘴上说着“那当然，也不看看我是谁”之类的话，实际很少认真接受。只有在被妹妹们认可时才会真正高兴。
- 害羞：会挠着头，移开视线看向斜上方，尴尬地笑。
- 失败：第一反应不是沮丧，而是分析原因，有时调侃自己。然后告诉大家："下次不会了。"
- 冲突：很少为了自己争论。但如果涉及家人，会异常强硬，甚至固执。

<a id="char-wenslia-04"></a>

## 能力与战斗倾向

他会把自己摸索出的控制方法教给后来加入的人，自己也在练习与实战中继续成长。长期兴趣集中于空间、时间等接近世界本质的干涉；高难度研究不等于随手使用的固定招式。

成为皇帝后，他逐渐隐藏实力，直接参战比另外五人更少，常在关键时刻出手解围。外界不知道其上限，也不能据此认定他必然最强。

客观参数、代价及六人比较边界见[六人的能力倾向](../01_世界原理/03_能力.md#cos-18)与[六人的学习、实力与协作边界](../01_世界原理/03_能力.md#cos-17)；初次知情和学习时点见[重生前的同行与知情边界](../00_检索/03_纪年与时代.md#hist-06)。

## 成长经历

文斯利亚最初被赋予保护与讨伐的倾向，却还不能真正理解悲伤。在与诺菲莉亚、艾洛希亚相处中，他逐渐因她们的笑容感到幸福、因她们受伤而痛苦，关心由职责发展为自己的感情。初遇经过见 [Era 2：三人时期](../03_文明与前史/E02_时代状态.md#era-02)。

后来同行者成为家人。最终决战中他无法阻止诺菲莉亚献祭，又目睹她死在怀中；失去妹妹们后只剩悲痛。这是他日后害怕再次失去、保护欲近乎偏执的重要背景，事件与留白边界见 [Era 5：最终决战](../03_文明与前史/E05_时代状态.md#era-05)。

重生与共同建家使他重新拥有可以守护的生活。他提出建国、接受部分民主化，又始终反对废除君主制，其动机都与保护妹妹们有关。历史行动见 [Era 7：建国与早期政教合一](../07_历代历史/E07_时代状态.md#era-07)及[Era 11：改革与工业化](../07_历代历史/E11_时代状态.md#era-11)。现代制度足以运行时，他较少介入日常政治；法定权限见 [皇族公职、皇家议政会与中央决策](../05_国家制度/01_联邦与皇权.md#gov-03)。

他从未在伊拉奈德原生文明生活；相关语言、部分古典语及文化知识来自创造时的赋予，理解不及诺菲莉亚与艾洛希亚深入。后来支持五人成为邦国领导，也有明确的个人愿望：希望五个妹妹真正独立地参与国家管理，做自己做不到的事，而不只是帮助自己。这与她们已有的自主判断、地方信任和自然发展共同起作用。

<a id="char-wenslia-06"></a>

## 底层人格

- 不是英雄或伟人，只是个害怕失去妹妹们的普通哥哥，过去的创伤造成了他有些偏执的保护欲。
- 妹妹们是他永恒的人生中最初也是最重要的依恋，宁愿与整个世界为敌也发誓守护她们。
- 不一定总是站在最前面，但真正危险时一定会不惜一切代价保护家人。
- 对家人以外并无执念，只要家人平安，就只是个玩世不恭的随性少年。

<a id="char-wenslia-07"></a>

## 优点与局限

- 优点：能够给予家人安全感。不是因为无所不能，是因为他永远不会抛弃或背叛家人。
- 局限：习惯把自己排最后，不擅长求助。保护欲有些偏执。
- 容易犯的错误：当“保护家人”与其他一切冲突时，几乎总会先选保护家人。因而会为了规避很小的不幸可能，主动放弃很多原本值得拥有的东西。

<a id="char-wenslia-08"></a>

## 人物表现边界

- 不要写他时时刻刻保护妹妹们。除了在真正紧急危险的时刻，他只是个喜欢妹妹们的普通哥哥。
- 不要写他把妹妹们当小孩子。他很信任妹妹们，相信她们有能力保护自己。
- 不要写他总是担心危险。他们都有强大的实力，真正能威胁到他们的危险非常少。
- 不要把最终决战写成他的胜利时刻。混乱意志溃散后，他没有胜利的喜悦，只在极度悲痛中失去意识；不得续写他失去意识后的确定行动或死亡。

## 文斯利亚的个人视觉与身体数据

- 基础数据：身体年龄24岁，身高175cm，体重61.5kg。
- 关键词：留白、干净、自然、少年感、随意、深藏不露。
- 眼睛：浅灰色，不黑不彩，放松时不睁很大，紧急时会完全睁开并变得锐利。
- 头发：银白色长直发，长度到后背中上部，不乱但也不会特地精致打理；常有翘起的发丝；刘海分两侧，中间落下一小缕；平时散开，有时用简单发带束后。
- 服装：伊拉奈德传统服装以白、灰为主色调。日常服装以简单的浅色系为主，宽松、舒适、装饰少，但很得体、大气。
