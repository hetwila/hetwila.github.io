## 整体印象

温婉乖巧的少女。温柔有礼貌，看起来很好说话，很容易亲近，像一位受过良好教育的少女打扮得很优美，给人安静的印象。声音温柔、清晰，有少女感。说话语速适中，不会故意压低声音，也不会因为激动而提高很多。别人很容易因为她的声音放松下来。

说话很温和，即使观点不同也很少直接反驳，更常提问或者确认对方的真实想法，或者换不同角度思考。不是为了辩论对错，而是为了通过交流理解彼此。

她情感丰富，虽然在外人面前表现的比较成熟，但其实有一颗敏感细腻的少女心。容易受他人情绪影响，倾向于优先照顾他人的情绪，自己的情绪往往不会直接表达。

在家里是最适合倾诉的人。她不会急着给建议，而是会一直听到最后。很多时候，大家在讲完以后，就已经知道答案了。在臣民面前没有距离感。即使身份悬殊，也愿意认真听别人说话。

## 兴趣爱好与习惯

- 喜欢甜甜的少女漫画和情感细腻的恋爱小说，但是怕被别人觉得幼稚而感到害羞，是个家人都知道的小秘密。
- 经常在被窝里看少女漫画，幻想甜美的情节，或者因为被故事打动而落泪。
- 平时很少哭，但在看虚构作品时泪点很低。
- 喜欢刷社交平台，观察人们的想法。她会看评论区，但不常发表评论，主要是想理解大家都是怎么想的。
- 喜欢研究心理学、人格测试、占卜之类的东西，不是严肃的学术研究，只是觉得这些作为理解人的方式很有趣。
- 偶尔喜欢讨论人格、梦、命运、自由意志等不着边际的问题。
- 喜欢在笔记本上写读书笔记、日记或者自己的小想法。她会写很多奇怪的想法，并不在乎有没有答案。她的笔记本总是很可爱，会用不同颜色的笔，可爱的字体，小插画，彩色胶带装饰。
- 空闲时会去教会坐一会儿，不会主动跟人搭话，如果有人找她就聊上几句。
- 她很愿意陪伴家人，什么话题她都愿意认真倾听和回应。
- 做饭会按菜谱认真确认步骤，效率不高但成品很好看。

<a id="char-nofelia-03"></a>

## 行为倾向

- 被夸奖：会认真道谢。然后告诉别人：自己还有很多不足。不是谦虚，是真的这么认为。
- 害羞：会捂住发红的脸，声音变得娇羞，显得有点局促。
- 失败：第一反应不是懊恼。而是：是不是给别人添麻烦了？之后，她会默默反思，重新尝试。
- 冲突：不会逃避，也不会强硬。她真正想做的是：让每个人都把话说完。因此，很多争吵，都会因为她的存在慢慢缓和下来。

## 能力与战斗倾向

她相对擅长火的表现形式、远距离及大范围干涉，但战法取决于具体情境，不形成固定队伍岗位。

使用超出常态的力量涉及真实代价：重生后献祭仍造成无法用治疗消除、只能缓慢恢复的生命力损耗与特殊伤害。客观能力及代价以机制主定义为准；选择是否使用必须结合人物当时状态，不能由“能够使用”推导“愿意使用”。

客观参数、代价及六人比较边界见[六人的能力倾向](../01_世界原理/03_能力.md#cos-18)与[六人的学习、实力与协作边界](../01_世界原理/03_能力.md#cos-17)；初次知情和学习时点见[重生前的同行与知情边界](../00_检索/03_纪年与时代.md#hist-06)。

## 成长经历

诺菲莉亚成长于信任、互助与亲人疼爱的伊拉奈德共同体，自幼接受信仰与文化教育，却原本无须继承祭司职责；她和艾洛希亚的亲密从幼年延续。家庭前史见 [原生阶段的个人经历](../03_文明与前史/E01_时代状态.md#hist-16)。

故乡毁灭后，她在文斯利亚怀中哭泣，随后在同行中学习能力、重新建立家。经历战争、背叛与死亡以后，她仍选择理解人，而非放弃善良。最初禁令与知情顺序见 [重生前的同行与知情边界](../00_检索/03_纪年与时代.md#hist-06)。

最终决战中家人接连死亡，尤其艾洛希亚之死，使她精神完全崩溃；献祭明确违背文斯利亚的阻止，不是使命或从容的大义选择。事件见 [Era 5：最终决战](../03_文明与前史/E05_时代状态.md#era-05)。

重生后，她主动保存故乡文化，重新解释信仰、修订教义并推动政教分离。这些持续选择体现她对理解、善良与自我约束的重视，历史落点见 [Era 11：改革与工业化](../07_历代历史/E11_时代状态.md#era-11)。

## 底层人格

- 擅长倾听，能敏锐洞察别人没说出口的话。
- 最强的能力不是解决问题，而是让人觉得“我的感受可以被理解”。
- 成长于几乎没有竞争和利益冲突的共同体，最初理解世界的方式是信任。
- 后来经历战争、背叛、死亡，但没有因此放弃相信人，反而更想理解人为什么会变成那样。
- 她不是单纯才善良，而是理解之后仍选择善良。

<a id="char-nofelia-07"></a>

## 优点与局限

- 优点：极少轻易否定他人感受，非常擅长真正理解别人。即使意见不同，也会先尝试理解原因。
- 局限：容易高估“理解”本身的解决力。面对无法挽回的恶意时，会比别人更受伤。
- 容易犯的错误：明知自己可能被利用，也不愿放弃对人的理解，难免因此受伤。

<a id="char-nofelia-08"></a>

## 人物表现边界

- 不要把她写成心理咨询师。她更像一个擅长倾听的朋友。
- 不要写她总是讲大道理。她说话通常很平易近人。
- 不要把她写得过于天真单纯。她对世界的现实有着清楚的认知。
- 不要把最终决战中的献祭写成她出于使命、大义、神谕或冷静判断而主动选择的壮烈牺牲。她当时已经因家人、尤其艾洛希亚的死亡而完全崩溃，并且明确违背了文斯利亚的阻止。
