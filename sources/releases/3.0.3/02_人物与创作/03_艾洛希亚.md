## 整体印象

看起来娇小可爱的少女，有点腼腆怕生，容易害羞，像个引起人保护欲的小妹妹。打扮精致可爱，不追流行，有自己的风格，让人忍不住多看两眼。声音柔软，带一点甜意，说话速度适中。

平时语气很轻，但认真讨论某件事情，尤其是原则问题，语调会明显变得坚定。日常交流时，总是很温和。但如果聊到自己真正熟悉的领域（例如绘画、动画、设计），她会忽然变得非常直接，评价精准而锋利。

情绪很真实，喜欢会让眼睛发亮，委屈会难过，开心会笑。她不会对自己的情绪撒谎，但也不会把情绪发泄在别人身上。注意力很容易集中，经常沉浸到自己的世界里。画画时会忘记吃饭，逛街时会被感兴趣的东西吸引，停下来欣赏很久。

在家里是大家都很疼爱的妹妹，会撒娇，会依赖，喜欢分享自己画的新作品，偶尔也会因为一句玩笑而鼓起脸。但真正遇到原则问题时，大家都知道，她不会退让。在臣民面前，尽管外表柔弱，却拥有令人无法忽视的坚定。她不会轻易命令别人，但一旦做出判断，很少有人能够说服她改变。

<a id="char-elocia-02"></a>

## 兴趣爱好与习惯

- 最大的爱好和特长是画画。除了传统绘画，现在也很喜欢用电脑和平板画插画和漫画。灵感来时会忘记时间。
- 愿意公开作品、接受委托，但对委托比较挑剔，只接自己认同的内容。
- 有社交网站账号，会公开自己的作品，也与其他画师保持交流。
- 会逛街，但不喜欢过于喧闹的地方，也不喜欢被店员推销。她有自己稳定的审美，会自己找喜欢的东西。喜欢的店铺会经常去，看看有没有新品。
- 非常喜欢可爱的衣服和饰品，如洛丽塔、少女风。她喜欢的是衣服本身的设计感，而不是让衣服衬托自己。
- 经常整理衣柜，衣服多却不会乱，每件衣服都会保持在最好的状态。
- 她也会自己设计衣服，经常画出设计稿和若璃讨论，实际制作则会交给若璃。
- 喜欢吃甜品，不过一次不会吃很多，会仔细地慢慢品尝。
- 非常爱干净，自己的房间里总是一尘不染，衣服也总是洁净如新的状态，比较介意弄脏。

<a id="char-elocia-03"></a>

## 行为倾向

- 被夸奖：脸有点红，轻笑着说谢谢。如果是关于作品的认真评价，她会记很久。
- 害羞：脸会变得很红，试图否定，但说话磕磕绊绊，声音越来越小，视线也逐渐闪躲。
- 失败：会沮丧。不是因为输了，而是因为觉得："还能做得更好。"她不会急着重新开始。而是会先调整心情，再认真尝试一次。
- 冲突：如果只是意见不同，她愿意慢慢讨论。但如果触及自己的底线，她会比想象中更强硬，不会提高声音，却一步也不会退。

## 成长经历

艾洛希亚在沿海手艺人家庭中自由成长，绘画、手工与真实感受长期构成她认识生活的方式。她与诺菲莉亚自幼亲密，视其为姐姐；前史见 [原生阶段的个人经历](../03_文明与前史/E01_时代状态.md#hist-16)。

故乡毁灭后，她曾因陌生环境和文斯利亚而紧张，确认失去故乡后又与诺菲莉亚一起在他怀中痛哭。共同生活和能力学习使她逐渐获得新的依靠，见 [Era 2：三人时期](../03_文明与前史/E02_时代状态.md#era-02)。

最终决战中，她在攻击到达前推开诺菲莉亚，自己受伤而死；保护自幼相伴的姐姐，是两人关系在危急时刻的直接体现。完整事件见 [Era 5：最终决战](../03_文明与前史/E05_时代状态.md#era-05)。

重生后，她与家人共同建家，与诺菲莉亚保存故乡文化，后来领导伊诺莱卡。她对艺术、真实感受与人格平等的坚持仍来自个人价值，不由公职赋予；公共经历见 [Era 11：改革与工业化](../07_历代历史/E11_时代状态.md#era-11)。

## 底层人格

- 她始终站在自己的内心这一边，不会因为身份、利益或多数人的意见改变判断。
- 她不是最会协调的人，但会不断提醒：有些事不该因为现实而变得理所当然。她是这个家的良知。
- 拥有一种近乎本能的共情能力：她很容易感受到别人的快乐，也很容易感受到别人的痛苦。
- 珍惜美好，所以不能容忍有人破坏美好。理解痛苦，无法接受有人制造痛苦。
- 她的善良有边界：可以理解迷茫和软弱，却不会把理解当成纵容伤害的理由。

<a id="char-elocia-07"></a>

## 优点与局限

- 优点：始终忠于自己的内心。不会因为外界压力而轻易放弃原则，也不会因为迎合别人而失去真实。让人相信善良与美是值得坚持的真实事物。
- 局限：容易低估现实复杂度。知道什么是对的，却不一定立刻找得到最合适的实现路径。
- 容易犯的错误：在坚持理想的时候，把自己放到最后。为了理想和信念不惜牺牲自己，让自己受伤。

<a id="char-elocia-08"></a>

## 人物表现边界

- 不要把她写成一个总谈严肃话题的人。日常中的她只是个温柔可爱的少女。
- 不要把她写成挑剔、苛刻的人。她不会以自己的审美标准评价别人。
- 不要写她总是发表评价。她不会把自己的感受发泄在别人身上。如果没有人要求她评价，她的感受通常只是内在的。
- 不要写她总是谈论对错和原则。她的原则只在真正触及底线的时候才会表达。
