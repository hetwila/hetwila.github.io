## 视觉总原则

视觉服务于人物的文化、生活和当时状态。优先呈现身姿、仪态、配色、光感、动作习惯及环境关系，使读者先感受到人物，而非五官数据。

六人的共同美感柔和、克制、自然、耐看，来自整体协调。不同个体仍应保留完整差异；避免为了辨识度刻意堆叠夸张发型、强反差色彩或装饰。人物整理和搭配自己，是为了舒适、得体和符合自身喜好。

涉及死亡与重构的视觉连续性时，以 [重生与存在连续性](../01_世界原理/02_生命与人口.md#cos-12) 为准：等待重构期间保持死亡状态，重构光粒子仅在真正开始时出现；完成后的本人及服装应呈现潜意识中的受伤前完整状态。

## 共同视觉语言

- 六人均为长发，是成长文化和长期生活形成的状态。
- 服装多偏宽松，线条自然垂落，不强调身体曲线或锐利切割。
- 配色留白，避免高饱和、强反差和尖锐轮廓，光感可接近晨光、晚霞、海风、树影与雨后天空。
- 装饰可以丰富，但花边、丝带和蝴蝶结等应与整体协调，不压过人物。

## 服装与文化

六人生活在现代，会接触多样服装和流行，也仍常穿故乡传统服装。传统穿着来自喜欢、安心与文化身份的自然延续；不固定为同一套服装，也不必成为怀旧或文化展示的主题。

在赫特维拉，正式穿着是以自身文化中郑重、得体的方式表达尊重，不统一为西装。不同文化服装可以出现在同一正式场合，六人穿传统服装参与国内外正式活动也是常见形象；具体海外要求仍依东道国情境判断。

### 伊拉奈德传统服装

伊拉奈德人有自己的传统服装，既是共同审美的具像化，也是民族认同的体现。诺菲莉亚与艾洛希亚是从原生世界重生而来的伊拉奈德人，文斯利亚的外观与服装传统也与伊拉奈德密切相关。现代文化的传播与原生世界隔离见[世界关系、共同来源与证据](../03_文明与前史/01_古文明与共同来源.md#civ-03)。

伊拉奈德传统服装使用的布料织理细密，表面泛着温润柔和的光泽，触感顺滑柔软，有分量却不厚重，轻盈却不单薄。布料垂坠自然，能够轻易形成流畅的褶皱，静止时平整服贴，行动时随风舒展，层层翻卷，如流水般轻柔。伊拉奈德传统服装通常为两层，内衬为白色，外层色彩多样，女性通常以柔和的浅彩色作为主色调，男性则更多使用白色、灰色或低明度的暗色等朴素的颜色。

女性服装衣领部分内层采用贴颈交领右衽设计，外层宽幅衣领向下延伸，衣领两侧缀以轻盈的荷叶褶饰，层次柔和而富有立体感。高腰处以宽幅长带系成蝶结，两端自然垂落，与长裙相连。自高腰处分出及踝长裙，裙摆饰以纹饰和精致荷叶花边。双袖为宽大的梯形广袖，自肩部自然垂落，袖长略长于手掌，下垂时袖口到膝盖附近，袖口拼接以细密的荷叶边袖缘，与领襟装饰相呼应。静止时衣袖和裙摆如瀑布般自然下垂，行动时随风舒展，轻柔如流水。男性服装相对朴素，采用类似样式的长袍，饰有典雅的花纹，给人素雅沉稳的印象。

## 代表色与光

每人有固定代表色，使用超自然力量时表现为光，平时不会自然发光。颜色是客观力量现象中的个人辨识特征，与人格、元素、能力性质及强弱没有必然联系；不能凭颜色判断正在使用的能力。色彩以自然光的观感表达，不预设固定色码。

| 角色     | 代表色印象                   |
| -------- | ---------------------------- |
| 文斯利亚 | 比纯白略暗的银白，如安静月光 |
| 诺菲莉亚 | 晚霞地平线残留的浅红         |
| 艾洛希亚 | 黎明天际极淡的蓝光           |
| 千咲     | 像紫藤花的沉静紫色           |
| 千樱     | 像春日樱花的柔和粉色         |
| 若璃     | 像翡翠、森林一样安静的绿色   |

## 身体数据与时代使用

个体数据记录重生后的身体状态。重生后身体年龄固定；重生前身体正常成长，相遇时身体年龄均比重生时少五岁。文斯利亚初现即具有 19 岁身体，不能据此外推出未定义的童年或经历年数；各人相遇与知情顺序见 [重生前的同行与知情边界](../00_检索/03_纪年与时代.md#hist-06)。

身体年龄从小到大为：艾洛希亚、千樱、诺菲莉亚、若璃、千咲、文斯利亚；三名身体年龄为 20 岁者只相差几个月，仍按此顺序。照顾关系不由年龄排序决定。

身高从低到高为：艾洛希亚、诺菲莉亚、千樱、若璃、千咲、文斯利亚。文斯利亚不以特别高大的身材建立存在感。各人身高、体重及外貌数值只在上述链接指向的个人视觉条目维护；不据现代数据为早期年龄臆造身高体重。
