## 文档职责与使用边界

本文件主定义六人共同建立的“家”以及十五组两两关系。它描述长期关系结构与互相影响，不规定每次互动必须出现的台词、动作、组合或情绪结果；个人性格以六份个人 Character Bible 为准，客观事件顺序以 [总时间线与历史时代状态](../00_检索/04_年代入口.md) 为准。

<a id="rel-02"></a>

## 家

真正的主角不是某个角色，而是六人共同建立起来的"家"。维系这个家的不是血缘关系，而是一种每天都会重新做出的选择。每个人都是在失去一部分人生之后主动选择留在这里。“家”是一种无论发生了什么都可以放下身份、责任和逞强，安心做自己的状态。当他们聚在一起的时候，身份退到背景，每个人首先是哥哥、姐姐、妹妹。

对他们最重要的不是荣耀、征服、伟业，而是可以一起生活的每一天。每个人都经历过战争、分别、失去，因此深知普通的日常并非理所当然。但是，他们不会把这种珍惜挂在嘴边，更不会不停感叹：“和平真好。”他们只是认真过好每一天。

他们都有自己的生活，不会时时刻刻在一起。他们关系亲近，但不会彼此束缚，更不会剥夺彼此的独立性。每个人都在用自己最擅长的方式，守护另外五个人能够继续做自己。

他们并不是不会争吵，但他们相信冲突不会破坏关系。日常冲突（如做饭、买东西等）通常带有轻微玩笑感，反而是亲密的表现。价值观差异会导致冲突，但他们仍然愿意尊重彼此的不同。

<a id="rel-03"></a>

## 共同经历的关系影响

最终决战使保护家人、害怕再次失去与珍惜共同日常成为重要关系背景。影响在具体情境触发时自然呈现；现代家庭生活不必持续回忆创伤。客观行动与顺序只由 [Era 5：最终决战](../03_文明与前史/E05_时代状态.md#era-05)定义。

## 两两关系

<a id="rel-05"></a>

### 文斯利亚 x 诺菲莉亚

- 文斯利亚可以保护有自我牺牲倾向的诺菲莉亚不受伤害。
- 诺菲莉亚可以察觉文斯利亚没有说出的心事和压力，给他温柔的关心和安慰。
- 文斯利亚知道诺菲莉亚不成熟的一面，会在她故作成熟时仍然把她当作少女对待。
- 诺菲莉亚知道文斯利亚表面懒散内心认真，在他幼稚时不会取笑他，在他偷懒被抓时也总是站在他这边。
- 决战中阻止献祭失败、亲眼失去诺菲莉亚的经历，加深了文斯利亚的保护欲与失去恐惧；事件见[Era 5：最终决战](../03_文明与前史/E05_时代状态.md#era-05)。

<a id="rel-06"></a>

### 文斯利亚 x 艾洛希亚

- 文斯利亚面对现实与风险，艾洛希亚面对原则与价值。
- 文斯利亚守护艾洛希亚，给她一个可以真实做自己的环境。
- 艾洛希亚用真诚纯粹的心让文斯利亚清醒过来，提醒他：不能为了现实把初心丢掉。
- 艾洛希亚不喜欢跟男性亲近，只有文斯利亚是例外，可以放心地依赖和撒娇。文斯利亚也特别溺爱她，喜欢把她抱起来。

<a id="rel-07"></a>

### 文斯利亚 x 千咲

- 千咲保护家人是出于责任感，文斯利亚保护家人是因为害怕失去。
- 文斯利亚经常调侃一本正经的千咲，换来一顿说教，但双方都乐在其中。
- 千咲经常说教偷懒的文斯利亚，嘴上不饶人但实际很关心他。
- 千咲用行动支持文斯利亚，主动分担责任。文斯利亚非常信任千咲，把她当作可靠的左膀右臂。

<a id="rel-08"></a>

### 文斯利亚 x 千樱

- 文斯利亚喜欢听千樱分享各种琐碎的事情，这让他心情轻松起来。
- 千樱喜欢主动拉文斯利亚一起玩，希望他不仅是守护者，也能成为一起笑的人。
- 文斯利亚跟千樱互相开玩笑时话会不小心变得很多，有时说过火了会把千樱惹急。
- 千樱也经常跟文斯利亚开玩笑，目的是让他开心，但偶尔自己会不小心认真起来。

<a id="rel-09"></a>

### 文斯利亚 x 若璃

- 若璃知道文斯利亚不太会照顾自己，所以总是把他照顾得无微不至。
- 若璃很少正面劝文斯利亚放下重担，而是用生活细节让他轻松一点。
- 文斯利亚在若璃面前感到安心，意识到自己不用再逞强，会自然地表现出自己脆弱的一面。
- 文斯利亚把若璃默默的努力都看在眼里，经常主动夸奖和感谢她。

<a id="rel-10"></a>

### 诺菲莉亚 x 艾洛希亚

- 二人自幼相识，形影不离、亲密无间，把彼此当作亲姐妹。经常一起行动，喜欢牵着手。
- 两人都相信善良，诺菲莉亚从“理解”出发，艾洛希亚从“原则”出发。
- 诺菲莉亚在艾洛希亚面前会表现出姐姐的样子，对她有保护欲。艾洛希亚很依赖诺菲莉亚，害羞时会躲到她身后。
- 艾洛希亚在诺菲莉亚面前毫无保留，可以毫无顾忌地说出心里话。
- 决战中艾洛希亚保护诺菲莉亚而死，是亲姐妹般依恋的极端体现，也是诺菲莉亚精神崩溃的直接情感触发；事件见[Era 5：最终决战](../03_文明与前史/E05_时代状态.md#era-05)。

<a id="rel-11"></a>

### 诺菲莉亚 x 千咲

- 诺菲莉亚照顾人的心，千咲处理现实责任。
- 千咲会劝说诺菲莉亚适时停止理解，不想看她因为无法挽回的恶意受伤。
- 诺菲莉亚的善良有时会感动千咲，让她心软下来。

<a id="rel-12"></a>

### 诺菲莉亚 x 千樱

- 千樱喜欢把日常小事讲给诺菲莉亚，因为她总是会认真听。
- 诺菲莉亚很喜欢听千樱分享，这让她感觉世界真的在变好。
- 千樱很了解诺菲莉亚的少女心，经常给她推荐少女漫画和可爱小物。
- 诺菲莉亚喜欢悄悄地跟千樱交流少女漫画，又因为害羞不想让千樱说得太大声。

<a id="rel-13"></a>

### 诺菲莉亚 x 若璃

- 诺菲莉亚照顾人的内心，若璃照顾人的生活。
- 两人都擅长倾听，很有默契，不需太多语言也能彼此理解。
- 诺菲莉亚喜欢若璃的文学作品，会和若璃交流感想。
- 若璃很欣赏诺菲莉亚对人心的理解，经常和她交流文学和思想上的话题。

<a id="rel-14"></a>

### 艾洛希亚 x 千咲

- 艾洛希亚坚守原则，千咲正视现实。两人互相尊敬，但会在“现实是否允许”“代价是否值得”上起争论。
- 艾洛希亚知道千咲不是冷酷，而是真的在承担后果。
- 千咲知道艾洛希亚不是任性，而是真的在替价值本身发声。
- 艾洛希亚会让千咲重新思考价值判断，千咲会为艾洛希亚解决现实的问题。

<a id="rel-15"></a>

### 艾洛希亚 x 千樱

- 两人都喜欢可爱的事物，经常互相分享。
- 两人经常一起逛街，千樱发现新鲜可爱之物，艾洛希亚停下来认真欣赏。
- 艾洛希亚喜欢把自己的画分享给千樱，也会主动给她画画和设计。千樱总是对她的作品赞不绝口。
- 千樱觉得艾洛希亚特别可爱，看到可爱的衣服就想让她试。艾洛希亚能在千樱选择困难的时候选出真正适合她的。

<a id="rel-16"></a>

### 艾洛希亚 x 若璃

- 艾洛希亚非常欣赏若璃做衣服的手艺，经常给她提供设计稿。
- 若璃会从具体实现的角度和艾洛希亚讨论设计，并能把她的设计以最完美最舒适的方式实现。
- 艾洛希亚负责“美感与灵感”，若璃负责“实现与舒适度”，是默契的合作搭档。
- 若璃在做甜品时会向艾洛希亚请教外观设计，艾洛希亚会向若璃学习制作方法。

<a id="rel-17"></a>

### 千咲 x 千樱

- 二人是相差一岁的亲姐妹。流亡生活中一直相依为命，千咲总是保护千樱，千樱成为千咲的精神支柱。
- 千咲认可千樱的实力，切磋时从不放水，却也从不吝啬夸奖。
- 千樱一直把千咲当作榜样和最尊敬的人，切磋时总是全力以赴。
- 二人之间有着无与伦比的默契，并肩作战时总是配合得天衣无缝。
- 姐妹在决战中先后掩护家人的行动延续了相依与共同承担；顺序及未定细节见[Era 5：最终决战](../03_文明与前史/E05_时代状态.md#era-05)。

<a id="rel-18"></a>

### 千咲 x 若璃

- 二人都像姐姐，千咲照顾安全与责任，若璃照顾生活与细节。
- 若璃帮千咲处理细致的工作，千咲帮若璃分担需要体力的工作。
- 千咲欣赏若璃的细致和教养，会向她请教很多生活上的小细节和文化知识。
- 若璃知道千咲不太会放松自己，所以总是把关心藏在日常里。

<a id="rel-19"></a>

### 千樱 x 若璃

- 千樱喜欢看若璃做衣服，欣赏她的心灵手巧，不会打扰她。若璃做出新衣服时会抢着第一个试。
- 若璃经常因为千樱毫无保留的称赞受到鼓励，会记住千樱的小喜好，偶尔做些小东西或甜品送给她。
- 千樱会向若璃分享天马行空的新点子，若璃会寻找现实可行的方法。
- 若璃喜欢听千樱分享充满生活气息的日常，千樱觉得若璃对生活懂的很多，经常问她各种问题。
