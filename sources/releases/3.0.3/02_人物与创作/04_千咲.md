## 整体印象

站姿挺拔，坐姿端正，一看就是经过多年训练。女性的阴柔之美和落落大方的凛然之气兼备。干练、自信，有武家出身的气质。声音听起来比较成熟，语速平稳，音高适中，不尖锐刺耳，却很有存在感，让人会自然地认真听。

表达直接，不拐弯抹角。初见时会觉得不好接近。但真正交流后，会发现她其实很坦率。有时说话比较凌厉，但熟悉后就会发现她没有恶意。和亲近的人在一起时，反而没那么坦率，有时有点傲娇，会说“才不是为了你”之类的话。

外冷内热，看起来没什么表情，有点冷冰冰的，实际上很热心肠，看到有困难的人会主动出手帮助。她把帮助别人当作自己的责任，被感谢了反而会有些不好意思。

在家里是个可靠的姐姐。在臣民面前，是个有威信、值得信赖的领导者。赏罚分明，不会因为身份而偏袒任何人。很少说漂亮话，但承诺的事一定会兑现。

<a id="char-chisaki-02"></a>

## 兴趣爱好与习惯

- 几乎每天早起练武、锻炼，她觉得这样可以改善一天的状态。
- 她会教别人练武，有点严格，但会悄悄记住每个人的努力和进步。
- 喜欢推理小说和历史小说，也喜欢看动作电影，不太喜欢恋爱作品。
- 喜欢旅行，比起都市更喜欢自然风光。喜欢拍自然风景和动物的照片。
- 喜欢猫狗等小动物，和小动物在一起时会变得温柔很多，能很快和小动物变得亲近。
- 很懂茶道，对茶叶和泡法都很讲究，能敏锐地品尝出区别。
- 自己并不热衷于打扮，却很喜欢看家人们打扮，看到适合家人的会说。有时会被家人拉着打扮，她会害羞但并不讨厌。
- 更希望别人对自己外表的评价是“帅气”（但不会主动要求），被说“可爱”会害羞。
- 做饭快、刀工好，重效率和营养，不追求花哨。
- 有时因为说出一本正经的话引人发笑，自己却不知道别人为什么笑。

<a id="char-chisaki-03"></a>

## 行为倾向

- 被夸奖：第一反应会否认："还有很多不足。"但如果对别人有帮助，或者是家人或尊敬的人的认可，她会默默高兴很久。
- 害羞：一本正经地否定，但语速明显变快，变得嘴硬，说话口是心非，有点傲娇感。
- 失败：不会找借口。会分析原因，然后重新开始训练。她相信：努力未必一定成功，但放弃一定不会成功。
- 冲突：不会逃避，也不会提高音量。她喜欢把问题摆到桌面上，一个一个讨论。如果最后必须有人承担，她通常会主动承担。

<a id="char-chisaki-04"></a>

## 能力与战斗倾向

她把能力融入既有身体训练与刀法，更习惯用自己的刀而非圣剑。正面迎击、力量与攻守兼备是她的相对优势；持刀是个人选择和武艺延续，能力不依赖刀的材料，也不限制她采用远距离或其他方式。

客观参数、代价及六人比较边界见[六人的能力倾向](../01_世界原理/03_能力.md#cos-18)与[六人的学习、实力与协作边界](../01_世界原理/03_能力.md#cos-17)；初次知情和学习时点见[重生前的同行与知情边界](../00_检索/03_纪年与时代.md#hist-06)。

<a id="char-chisaki-05"></a>

## 成长经历

千咲自幼接受武学与文化教育，父母遇害后与千樱流亡。教育使她重视责任与做人，流亡又使她理解现实代价；作为姐姐，她很早习惯成为依靠。前史见 [原生阶段的个人经历](../03_文明与前史/E01_时代状态.md#hist-16)。

樱花林相遇时，她先保持警惕，确认三人并非恶人后，实际承担带路和保护。在随后知情、学习能力与共同旅途中，责任逐渐与家人的依恋结合。相遇及学习时点见 [Era 3：千咲、千樱加入后的五人时期](../03_文明与前史/E03_时代状态.md#era-03)。

最终决战中她为掩护家人最先战死，这一选择延续了主动承担和保护的倾向。重生后与家人建家，后来和千樱共同治理千世；事件分别见 [Era 5：最终决战](../03_文明与前史/E05_时代状态.md#era-05)、[Era 11：改革与工业化](../07_历代历史/E11_时代状态.md#era-11)。

<a id="char-chisaki-06"></a>

## 底层人格

- 从小接受武家教育，学到的不只是刀法，更是做人。
- 流亡经历让她早早学会面对现实，明白只靠理想活不下去。
- 作为姐姐，她习惯了成为依靠和承担责任。
- 面对问题不会先抱怨，而是先解决。她不会把责任推给环境，而是主动站出来。

<a id="char-chisaki-07"></a>

## 优点与局限

- 优点：强大执行力和责任感。别人还在犹豫时，她已经开始行动。让人觉得：只要她还在，就不会失去方向。
- 局限：容易把责任揽到自己身上，难以轻易接受“这不是你的错”。
- 容易犯的错误：在别人本来希望自己做时过快地承担本该属于别人的责任。

<a id="char-chisaki-08"></a>

## 人物表现边界

- 不要把她写成冷酷机器或情绪稀薄的人。她有感情，只是习惯把情绪放到事后处理。
- 不要把她写得总是很严格。除了在面对真正严肃的问题时以外，她很随和。
- 不要写她总是在工作或帮助别人。她有自己的爱好和生活。
