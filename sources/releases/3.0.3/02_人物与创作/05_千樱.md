## 整体印象

活泼开朗的元气少女。走路轻快，看起来蹦蹦跳跳的，打扮时尚可爱。声音清脆、明亮，说话速度偏快。情绪很好猜，开心的时候，声音都会跟着轻快起来。

想到什么就说什么，很少藏感受。在别人开心时会一起开心，在别人难过时也会马上察觉，然后开始想办法让气氛轻松一点。像邻家女孩，很容易亲近，第一次见面就能聊起来。

坏情绪来得快，去得也快。不是因为不在意，而是因为她有很强的自我恢复力，总能重新找到值得开心的东西。

是家里的开心果，经常拉着大家一起出去玩、拍照片，擅长活跃家里的气氛。在臣民面前，充满亲和力，不会因为身份差异而摆架子，能把严肃的话题讲得很轻松。

<a id="char-chio-02"></a>

## 兴趣爱好与习惯

- 不太喜欢一个人待着，常主动问大家要不要一起出去。
- 看到有趣的东西会第一时间跟大家分享。
- 喜欢尝试新鲜事物，新的流行、新开的店、没吃过的食物，她都愿意主动尝试。
- 特别喜欢探店：咖啡馆、甜品店、文具店、杂货店都会认真收藏。
- 喜欢热闹的地方，如商业街、节日庆典等，很容易被气氛感染。
- 喜欢拍照，不追求构图，而是为了记录与分享。
- 喜欢恐怖电影，每次都会被吓得抱住旁边的人，还要继续看。
- 做饭时很容易提议“今天出去吃吧”，收藏夹里餐厅很多。
- 喜欢吃甜品、喝奶茶，也喜欢挑战辣的食物。
- 房间里会摆很多旅行时买回来的小摆件，每一个都记得在哪里买的。
- 如果大家都很安静，她会忍不住找一个话题，让客厅重新热闹起来。

<a id="char-chio-03"></a>

## 行为倾向

- 被夸奖：会立刻笑出来，然后开心地问："真的吗？"如果继续夸，她会越来越高兴。
- 害羞：脸一下红起来，慌慌张张、语速很快地否定，然后自己笑出来。
- 失败：第一反应："再来一次！"她不喜欢输，但比起失败本身。她更在意：还有没有机会继续努力。
- 冲突：不会一直生闷气。如果觉得委屈，会马上说出来。吵完以后，通常也是第一个主动恢复正常的人。

## 能力与战斗倾向

她把能力融入身体训练与刀法，更习惯用自己的刀而非圣剑。相比千咲，她更依靠机动、位置变化和出其不意的近距离行动；灵活近战不排除正面战斗，也不意味着固定突袭职责或较低综合实力。

客观参数、代价及六人比较边界见[六人的能力倾向](../01_世界原理/03_能力.md#cos-18)与[六人的学习、实力与协作边界](../01_世界原理/03_能力.md#cos-17)；初次知情和学习时点见[重生前的同行与知情边界](../00_检索/03_纪年与时代.md#hist-06)。

## 成长经历

千樱与千咲一同接受教育和训练，家庭变故后相依流亡。她学会用一顿饭、一次笑出来的交谈等小小的今天，让自己和姐姐重新回到生活；这成为她珍惜共同快乐的基础。前史见 [原生阶段的个人经历](../03_文明与前史/E01_时代状态.md#hist-16)。

樱花林相遇时，她与姐姐一样警惕；交流后接受暂时同行，起初确实保护着被视为普通旅人的三人。后来才知情、开始能力学习，见 [Era 3：千咲、千樱加入后的五人时期](../03_文明与前史/E03_时代状态.md#era-03)。

最终决战中，她在千咲之后继续掩护家人，并成为第二位死者。重生后与家人建家，后来和千咲共同治理千世；完整事件见 [Era 5：最终决战](../03_文明与前史/E05_时代状态.md#era-05)、[Era 11：改革与工业化](../07_历代历史/E11_时代状态.md#era-11)。这些经历不会使她失去轻快的日常，也不要求她始终负责让别人开心。

<a id="char-chio-06"></a>

## 底层人格

- 流亡经历让她明白，真正把人拉回来的常常不是宏大信念，而是小小的今天：一顿饭、一次笑出来的聊天，都能把人一点点从恐惧中拉回现实。到了摄影出现后的年代，一张照片也能承载这种心情。因此她特别珍惜“可以一起开心的时间”。
- 她不是天生乐观，而是在认清绝望的同时不让绝望赢。她的乐观是一种反抗。
- 不一定永远不难过，但总会努力把光带给别人。她是家里的阳光。
- 最大的能力，不是鼓励别人，而是让人不知不觉开始期待明天。

<a id="char-chio-07"></a>

## 优点与局限

- 优点：能够把快乐变成一种会传递的东西。跟她待在一起，生活会变得轻松一点。
- 局限：容易低估困难和复杂度。需要别人提醒自己停下来，想一想这件事是不是所有人都会开心。
- 容易犯的错误：相信快乐天然可以被所有人共享。因热情跑得太快，来不及先问别人是否愿意、是否舒服。

<a id="char-chio-08"></a>

## 人物表现边界

- 不要把她写得幼稚。她有成熟的价值观。
- 不要把她写得过于吵闹、不安分。她不会打扰别人，她会安静地做自己的事情。

## 神奈千樱的个人视觉与身体数据

- 基础数据：身体年龄19岁，身高160cm，体重50kg。
- 关键词：轻快、流行、分享、活力、今天。
