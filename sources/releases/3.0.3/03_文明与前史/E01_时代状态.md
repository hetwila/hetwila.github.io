# Era 1：伊拉奈德及各自原生文明时期

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

人物所知与尚不可用的条件；具体历史事件另查H年表。

<a id="hist-09"></a>

## 起止标志

- 起点：各原生文明的早期历史均为 `[OPEN]`，不设共同宇宙纪年。
- 伊拉奈德线的终点：秩序意志崩坏，伊拉奈德世界发生结构性毁灭；15岁的诺菲莉亚与13岁的艾洛希亚重伤昏迷，后来在一间有石床的房间醒来并已痊愈。具体转移与治愈机制尚未固定。
- 千咲、千樱与若璃的原生阶段分别在其离开原有生活、加入同行时结束；这些事件与伊拉奈德毁灭之间没有可换算的同步关系。

<a id="hist-10"></a>

## 世界与社会状态

- 伊拉奈德所在世界是日常生活没有公开超自然能力的普通世界；普通人不知道超自然力量真实存在。伊拉奈德是其中的封闭岛屿文明，以秩序意志为神，祭司神谕属于极少数例外。
- 扶桑与现实日本镰仓时代具有明显相似性，是农业与武家社会；东华与现实南宋时期中国具有明显相似性，是成熟文官文明。二者处于同一世界并有正常海上交通，但与现实世界没有历史联系；该世界的普通日常同样没有公开超自然能力，普通人不知道超自然力量存在。
- 伊拉奈德所在世界、扶桑与东华共同所在世界、现居世界三者彼此独立。现居世界不保有六人原生世界的遗迹、遗留物品、后裔或直接文化传承。
- 现居世界在秩序重构前曾存在独立古代文明。秩序意志崩坏时，该世界因结构上与秩序意志过于接近而经历持续的底层失稳；自然规律异常、空间破裂、能力失控、魔物激增、地质和气候灾害共同摧毁文明，并非单一瞬间的“神罚”。
- 现居世界古代文明在毁灭前已出现异常观测与保存行动，但最终未能阻止世界级灾难；其知识形态、遗存类型和毁灭过程由 [重构前古代文明](01_古文明与共同来源.md#civ-02)；“文明毁灭、遗存与历史空白”主定义。

<a id="hist-11"></a>

## 六人所处状态

- 六人尚未作为共同体存在。
- 诺菲莉亚与艾洛希亚生活于伊拉奈德文明；文斯利亚在本 Era 末段以前尚未被创造。
- 千咲、千樱出身扶桑的没落武家并处于流亡状态；若璃出身东华官宦世家。这里只保留背景事实，不展开个人经历与心理。
- 六人在重生前都按普通年龄成长；其初遇年龄分别为文斯利亚19岁、诺菲莉亚15岁、艾洛希亚13岁、千咲15岁、千樱14岁、若璃15岁。

<a id="hist-12"></a>

## 已知信息

- 伊拉奈德社会以宗教语言理解秩序意志，并通过祭司神谕获得信息；这不等于社会掌握客观宇宙机制。
- 现居世界古代文明可能知道世界稳定度正在下降，并能保存部分研究资料；这不代表所有地区或个人都拥有同样的知识。

<a id="hist-13"></a>

## 尚未知信息

- `[OPEN]` 各原生文明的绝对年代、彼此时间对应、六人的完整出生经历及原生阶段事件顺序。
- 原生阶段的五位少女尚未学习主动使用特殊力量；文斯利亚尚未被创造。其后同行阶段的知识边界见[重生前的同行与知情边界](../00_检索/03_纪年与时代.md#hist-06)。
- 现居世界古代文明的具体灭亡年表、政体、国家名单与保存行动仍未定义。

<a id="hist-14"></a>

## 尚不存在

- 六人共同体、赫特维拉国家、重构后的现居世界社会、公共禁制及其纪元体系均尚未形成。
- 特殊个体之间的意义层交流即使存在，也不等于自动掌握陌生语言或文字；不能提前写成通用翻译技术。

## 原生阶段的个人经历

| 人物 | 已确认的个人前史 |
|---|---|
| 文斯利亚 | 由秩序意志的残余力量创造，初次出现即具有 19 岁身体；不存在据此反推的普通童年。他初现时已知诺菲莉亚、艾洛希亚的身份、保护与讨伐职责及诺菲莉亚特殊作用的危险。 |
| 诺菲莉亚 | 出生于伊拉奈德中央高地祭司宅邸，是祭司最小的女儿，有多个疼爱她的哥哥姐姐；接受信仰与文化教育，原本不在继承人候选之列。幼年与艾洛希亚相识、共同成长。 |
| 艾洛希亚 | 出生于伊拉奈德东部沿海，是独生女；父亲以绘画与手工为生，家庭较为放任，童年无拘无束。幼年偶遇诺菲莉亚，两人成为最初也是最好的朋友，视彼此为亲姐妹。 |
| 千咲、千樱 | 出生于扶桑没落武家，千樱比千咲小一岁；自幼接受武学与文化教育。父亲因刚正、触怒上级而被处刑，全家受牵连；母亲为保护姐妹丧生。姐妹此后流亡、相依为命。 |
| 若璃 | 东华文官之女，自幼接受大小姐的教育，琴棋书画均有修养，尤其擅长写作与裁缝。父亲是贪官，少有关心且不向她讲官场之事；她已察觉家产来源不洁，却无力阻止。家中缺少可真心相待的同龄人，佣人受身份束缚；她预见自己可能成为政治婚姻筹码，通过阅读向往外面的生活。其父后来的政治斗争与她离家见 Era 3。 |

文斯利亚从未在伊拉奈德原生文明中生活；被创造时获赋与该文明密切相关的知识，使用伊拉奈德语言并懂部分古典语，理解不及诺菲莉亚与艾洛希亚深入。这不是童年或原生生活的亲历记忆。
