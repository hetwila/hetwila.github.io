# Era 3：千咲、千樱加入后的五人时期

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

人物所知与尚不可用的条件；具体历史事件另查H年表。

<a id="hist-21"></a>

## 樱花林相遇与最初同行

三人刚被传送至扶桑不久，15 岁的千咲和 14 岁的千樱在樱花林中前后持刀拦住他们。流亡中的姐妹警惕来历不明者；文斯利亚试图用尚显拙劣的玩笑蒙混来历，反而加深怀疑。诺菲莉亚尝试交涉，艾洛希亚鼓起勇气解释；双方坐下交换身份与经历后，姐妹才相信三人并非恶人。

三人没有展示或完整说明特殊力量和使命。姐妹因此把三人视为没有武器、缺乏当地常识的普通旅人，主动暂时同行，在最初一段时间里实际为他们带路和保护。后来途中发生三人不得不使用能力的事件，姐妹才第一次知情；进一步交谈后，开始向三人学习主动使用自己的特殊力量，并逐渐融入原有武艺。该事件的地点、危险、由谁出手及表现方式尚未确定。

<a id="hist-22"></a>

## 东华相识与宅邸暂住

五人从扶桑乘船抵达同一世界的东华。由于未及时避让若璃随父亲乘坐的马车而险些被捉，15 岁的若璃意外听懂他们的话，命下人将五人带回宅邸。她是在当地这次相遇中唯一能够同时与五人交流、理解本地语言文字及身份规则的人。

若璃回到宅邸后与五人正式介绍身份，并邀请他们参加庭院月下茶会。六人由日常话题谈到经历与私人秘密，若璃第一次向同龄人坦白孤独与真心话，五人讲述旅行见闻和外面的生活。五人仍未说明特殊力量与讨伐使命；茶会后她邀请他们暂住。

<a id="hist-23"></a>

## 家庭变故与同行决定

若璃的父亲后来因政治斗争被处刑，家中其他人受牵连，五人救下若璃。这些事实已确定；政治斗争、牵连和救援的具体过程仍开放。

若璃决定离开原有生活、随五人同行，并在离家后弃用原姓，以表示与原生家庭决裂。五人在她作出同行决定以后才告诉她特殊力量与讨伐使命；信息披露不是劝她离家的条件。若璃正式加入，构成本阶段终点与 Era 4 起点。

<a id="hist-24"></a>

## 时代与认知

扶桑与东华同属一个世界，有正常海上交通和长期文化影响，口语不互通，书面语言也不等同。五人能理解若璃的实时表达，却不能自动读懂东华文字、文书或制度；若璃的本地知识不可省略。

各人知情与学习先后见 [重生前的同行与知情边界](../00_检索/03_纪年与时代.md#hist-06)。本阶段尚无重构后社会与公共禁制；具体时长、途中事件及变故过程见 [O-04](../90_维护/02_开放问题.md#o-04)。
