# Era 2：三人时期

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

人物所知与尚不可用的条件；具体历史事件另查H年表。

<a id="hist-18"></a>

## 起止与事件

伊拉奈德毁灭后，15 岁的诺菲莉亚与 13 岁的艾洛希亚重伤倒在神殿外墙、失去意识，当时已做好死亡准备。后来二人在一间有石床的房间醒来，伤势已痊愈；19 岁的文斯利亚已在那里等候。房间的位置、转移与治愈的具体过程未定。

文斯利亚知道两人的身份。她们确认故乡与亲人已经失去后，扑在他怀里痛哭；艾洛希亚起初对陌生环境和陌生人感到紧张。文斯利亚知道应当关心她们，却还无法真正理解或妥善安慰她们的悲伤。

三人此后一起旅行与讨伐，文斯利亚引导二人第一次主动学习能力，三人共同成长。本阶段止于自动转移至扶桑并在樱花林遇见千咲、千樱。

<a id="hist-19"></a>

## 时代与认知

伊拉奈德原生世界已毁灭，多世界与魔物问题仍存在。三人单位属于叙事分期，不代表其他世界同时处于某种状态；五人、六人单位和赫特维拉尚未形成。

具体知识与保密边界见 [重生前的同行与知情边界](../00_检索/03_纪年与时代.md#hist-06)；持续时间、途经世界及其间事件见 [O-04](../90_维护/02_开放问题.md#o-04)。
