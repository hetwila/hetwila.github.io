# Era 5：最终决战

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

人物所知与尚不可用的条件；具体历史事件另查H年表。

<a id="hist-29"></a>

## 地点、时长与事件顺序

最终决战发生在完整混乱意志所在的夹缝世界，三日以内结束，各人死亡之间不存在长时间空白。现场只有六人，没有外部参战者、旁观者或见证者，也未向后世留下遗留物品。

| 顺序 | 已确定的行动与结局 |
|---|---|
| 1 | 千咲为掩护其他人战死。 |
| 2 | 千樱继续掩护其他人，随后战死。 |
| 3 | 若璃继续掩护其他人，随后战死。 |
| 4 | 诺菲莉亚受到攻击前，艾洛希亚将她推开，自己受伤而死。 |
| 5 | 面对家人、尤其艾洛希亚的死亡，诺菲莉亚精神完全崩溃；她不顾文斯利亚阻止，以力量具现圣剑并刺入胸口，完成献祭。文斯利亚接住她，她死在他怀中。 |
| 收束 | 混乱意志溃散；失去五位妹妹的文斯利亚感受不到胜利喜悦，在极度悲痛中失去意识。正文至此留白，不确认他是否真正死亡或死亡方式。 |

诺菲莉亚的献祭源于当时的精神崩溃，不是使命、大义、接受宿命或冷静从容的英雄主义选择。千咲、千樱和若璃的具体死亡方式、未固定的战术与三日内准确时长仍未决定；文斯利亚失去意识后的真实结局继续留白。

<a id="hist-30"></a>

## 机制与当时知识

六人知道眼前敌人须被讨伐，也知道诺菲莉亚的特殊作用与禁令，但不知道混乱聚合和献祭的完整宇宙机制。客观结果是混乱意志统一结构失稳；在秩序意志此前已崩坏的条件下，两种力量均失去高位统一意识，多世界体系开始寻找新的动态平衡。

不存在战后由秩序意志主动奖赏六人的过程；它是否预见重生仍未证实。重生后的六人生活与赫特维拉尚未出现。机制见 [最终决战的机制意义](../01_世界原理/01_世界结构.md#cos-09)及[秩序重构](../01_世界原理/02_生命与人口.md#cos-11)。

<a id="hist-31"></a>

## 物品与后世证据

六人重生前所持武器、装备及其他物品不会随重生进入现居世界。圣剑的能力仍可使用，不代表决战时的实体原物被保留。后世只能依六人的记忆证言、可交叉核对的经历和机制研究重建事件，史料边界见 [历史亲历者、史料与历史教育](../06_现代生活/09_公共历史.md#memory-02)。
