# Era 4：若璃加入后的六人旅途

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

人物所知与尚不可用的条件；具体历史事件另查H年表。

<a id="hist-26"></a>

## 起止与事件

若璃获知五人的真实情况并加入后，第一次向他们学习主动使用力量。六人持续练习、交流和讨伐；世界转移仍自动发生。旅途中可按具体情境协作，能力倾向不形成固定战斗岗位。

六人讨伐魔物保护了具体世界，也客观推动混乱力量在夹缝中聚合。完整混乱意志形成、六人进入最终决战，构成本阶段终点。聚合机制见 [混乱意志的形成](../01_世界原理/01_世界结构.md#cos-08)。

<a id="hist-27"></a>

## 时代与认知

六人知道力量的实际用法、讨伐任务与诺菲莉亚特殊作用的危险，仍不了解行动的宇宙意义。赫特维拉、重生后的共同生活、纪元体系与现代禁制均未形成。途经世界、事件顺序、休息期、临时战术和决战的直接触发事件见 [O-04](../90_维护/02_开放问题.md#o-04)；献祭的既定动机与行动见 Era 5，不属于待定内容。
