# 千世：政治发展与职权年表

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

<a id="t07-section-032"></a>

## 文化传习与共同责任：前2953—前1501年

早期扶桑文化的保存涉及语言、书写、农事、工艺、训练及公共责任。千咲、千樱分别参与传授，也共同解决聚落间需要长期合作的事务。已有文化背景提供知识和理解方式，具体制度仍须适应现居世界的材料、人口、气候和共同生活条件。

东部主河一侧的灌溉、渡运、堤渠、道路和修造，使单个聚落难以独自承担全部公共工程。每年投入多少劳动、下游怎样获得水源、损坏由谁修理，都需要居民、工匠与不同地点反复协商。两人在其中逐渐建立持续责任。

前1864年的记录确认两人共同承担地区公共事务，反映此前已形成的实际关系。当地分别与她们合作，也共同请求两人参与，并没有把千樱的意见视为千咲的转述。文斯利亚希望五个妹妹独立参与国家管理的意见，同样包含千樱本人。

人口稀少、参与者能够彼此认识时，分歧常靠面对面调整解决。随着普通居民代际增长和聚落扩大，“姐妹之间能够谈好”逐渐不足以保障第三方知道决定究竟是什么。共同领导开始需要记录与责任区分。

## 组织能力怎样转变为统治权：前1500—823年

前1500年前后的国家形成将当地供给、防卫与中央更紧密地连接。两人对公共劳动、人员和重要设施具有较强影响，也参与地区防卫。这个时期不能倒用现代独立司法、普遍选举和责任政府的概念。

长期动荡使地区管理者把供给责任写成可反复征用的义务。水利与工坊登记原本有助于合作，也可能让土地管理者更容易施加负担。强调责任的语言既能要求官员可靠履职，也可能被有权者用来要求普通居民无限忍耐。

仓税叛乱时期，千世地区的农户、运输者和工坊同样受到长期征收影响。姐妹曾支持校核公共义务与额外索取，但地方代理者的利益、中央战争需求与信息迟滞，使清理远比一纸命令困难。公共责任并不是她们与居民之间始终一致、从无争议的观念。

纪元0年以后，公共禁制使基础安全日渐制度化。374年自治和议及后续地方文书实践又提高了共同负担的可预期性。对千世而言，这意味着可靠治理越来越需要公开记录、稳定工程责任与可以质疑上级的程序，而不只是领导者亲自到场纠正问题。

## 两项平等公职与国家军事体系：827—1649年

827年，千世公国及两位“千世共治大公”的职位得到联邦确认。两人都可以处理公共事务、任用官员并参与地区政策，重大共同事务应协商决定。职称从一开始就没有设“正大公”和“副大公”，也不因千咲年长而产生最终裁决票。

872年军事统辖归中央后，千世境内的军队逐渐进入共同国家指挥。两人作为国家层面参与者可能承担军事与安全责任，但这与作为千世领导人的地方职权不同。不能把后来国防产业集中、军事设施较多理解为千世保有自己的军队。

976年，共同决定记录程序经历一次成文改革：涉及共同财政、土地负担和主要工程的命令应分别记载两人的意见与执行机关；一人代表共同决定时须有可核查授权。改革针对下属选择性转述、声称已经取得“另一位也同意”等现实弊端。

1064年司法独立后，两人退出个人最终裁判。地方工程、财产和行政争议可以进入法院，不能因为某项水利或工坊工程得到两位大公支持就免于诉讼。她们仍能提出一般制度改革，但不得决定具体当事人应胜诉还是败诉。

1417年的公共堤渠章程扩大了城市、农户与工程维护组织的意见记录，要求征地、公共劳动和维护费用分别说明。它仍有代表不平等的问题，却削弱了以工程紧迫为理由随意转嫁负担的空间。此后农业与工坊社会积累的文书、预算和技术组织，成为工业化的基础。

## 工业社会中的秩序与代表权：1650—1835年

交通、机械生产和公共服务扩大，使千世的管理问题从季节供给转为持续雇佣、城市卫生、厂区安全与长期资本投入。1640年代劳动争议及1647年劳动安全底线在这里具有直接影响；大公与技术官员能够推动建设，却不能以效率替代劳动者自身的判断。

1690年代财政压力使地方政治出现两种相反要求：产业经营者希望集中调度、减少争论，农户和劳动组织则希望检查费用、风险和补偿。千咲、千樱并不永久代表其中任何一方，也没有固定由一人发展工业、另一人安抚居民的分工。她们会就具体工程提出不同判断，并随新资料调整。

1768年预算章程将地方新增税负和年度公共支出进一步交由代表机构审议。两位大公不能用各自名义建立平行财政；共同签署也不能绕过已经形成的预算程序。这是共同领导从“两个人都能下令”转向“两个人都须在公共机关中负责”的关键变化。

1821年责任政府章程规定行政首席须获得地方代表机构信任，负责统一的日常行政。两人仍可以推动重要政策、参与组阁磋商，但不再各自拥有一条日常官僚指挥链。普通公务员以本部门的合法职责为依据，无须猜测究竟应先服从姐姐还是妹妹。

## 民选政治使共同领导制度化：1836—1930年

1836年改革扩大地方平等选举，旧有工坊、土地与职位资格逐渐退出普通代表选任。城市劳动者、农业合作组织和新兴职业群体进入公开政治，公共权利不再只通过大公与熟悉的行业领袖谈判取得。

国家建设派、社会劳动组织、法政和自治力量都在千世发展。制造业和技术职业并非天然属于一个政党；同一工厂的经营者、工程人员、雇员和周边居民也可能持不同立场。两位大公的中央参选更不会使整个邦国成为某人的稳定票仓。

1889年共同执政会议制度确立，以明确议程、集体表决和负责政府承接双人领导。两位大公各有一票，政府拥有独立多数基础，城市与乡村联络代表也进入重要协商。没有一致意见的方案可以继续修改，不能靠不发会议纪要使分歧消失。

1908年的程序补订区分普通行政和长期保留事项。大公对少数长期安排的反对具有正式复议效力，但议会在更广泛支持下可以采用另一方案。这既保留了长期领导者的政治分量，也避免其中一人的不同意见冻结整个邦国。

<a id="t07-section-037"></a>

## 战争动员与战后权力归位：1931—2023年

航路战争期间，千世的制造、运输和训练设施承担重要任务。中央决定军队和战略生产方向，地方政府处理劳动力服务、疏散、住房、交通及依法授权的供给。千咲和千樱参与重要协调，不能据此把中央军令视为千世邦令。

战争使快速动员容易压过劳动安全、社区补偿和程序参与。姐妹曾支持高强度生产，同时也面对工人家庭与地方代表提出的限度要求。后来的调查承认，有些项目过分依靠临时征用和漫长工时；不能因为战争结果有利就认为当时所有办法都合理。

1942—1946年中央议长空缺期间，地方也存在代表延续和临时行政。两位大公继续履职，但没有因此取代所有地方民选机关。1948年地方选举恢复，1950年对战争授权进行清理，恢复正常预算、劳动监督和政府问责。

1972年的跨届公共工程程序改革进一步要求，影响多个市镇、长期财政和公共服务的方案必须列明替代路径。1980年代环境与工业转型争议又证明，工程技术上可行的方案未必在政治上已经获得足够授权。

2012年暴风灾害暴露设施维护与跨邦水系协调中的不足。两人参与公开协调和现场公务，政府依法负责救灾；这次灾害没有成为国家存亡级皇权危机，也没有产生千世独立的军事指挥权。2014年后对公共系统冗余和日常维护的投入逐步扩大。

## 职权变化与专题节点

| 时段 | 两人的共同领导方式 | 实际权力变化 |
|---|---|---|
| 前1864年前后 | 两人分别及共同承担持续公共责任 | 地方合作承认两人，尚无现代职名 |
| 827—975年 | 两项平等的共治大公公职 | 较强行政、供给与任用权；872年后军事统辖归中央 |
| 976—1767年 | 共同决定留痕，公共机关逐步分立 | 授权须能核查，司法退出个人裁判，地方工程议事发展 |
| 1768—1888年 | 共同财政约束与责任政府 | 新增税负及预算受代表审议；首席承担统一日常行政 |
| 1889—1948年 | 共同执政会议与民选政治 | 每人一票，无个人决定票，重要事项须与政府议会协商 |
| 1949—2026年 | 两位持续参与政治的共治大公 | 同等提案、政策表决和有限复议；中央兼任不改变地方平等地位 |
