# 四邦提案、组阁、复议、问责及失能程序

## 五人可以主动做什么

<a id="t07-section-006"></a>

### 提案、议程与资料

每人均可直接向本邦政府提出政策准备要求，取得与其公职事项相关的说明、预算测算和执行评估。政府应在30日内提交初步报告，或说明更长调查所需的范围与日期。个人兴趣、家人私事与无关机密不在这项权限内。

每人每年度可提出两项必须列入邦议会正式审议的重点提案；提案应有目标、成本、权限依据和利益影响说明。千世两人各有额度，不能由一人替另一人使用。提出更多普通建议仍然可以，但不自动取得优先排期。议会可以修改或否决重点提案，须留下理由。

五人能够主持协商、提出政府原案之外的方案，并通过上述政策机关参与表决。她们提出的政策不需要先取得皇帝同意；邦国公务须进入正式记录，不能以家庭私下谈妥代替制度程序。

<a id="t07-section-007"></a>

### 组阁中的不同角色

四邦的行政首席都须取得邦议会全体过半数信任；部长向议会负责。皇族不能仅凭私人信任保住一个已经失去议会信任的政府。

| 邦国 | 皇族在组阁中的实际作用 | 僵局如何结束 |
|---|---|---|
| 伊拉奈德 | 执政与各党及地方代表磋商，从获得至少30名议员公开支持的候选人中提出一人，交议会信任表决 | 两次提名失败或30日未能完成提名后，由议会直接提名、以61票选出首席，执政无权无限重复指定少数人选 |
| 伊诺莱卡 | 各党先在议会形成多数并选出首席；大公与当选首席共同讨论施政纲领，可另提公开的重点政策附件 | 大公对纲领的不同意见不阻止已经合法选出的首席就职；争议分别进入政策、预算程序 |
| 千世 | 两位大公共同主持各党磋商，分别公布对候选方案的意见；首席由邦民议会以81票选出 | 两人意见不一致不阻断议会选择；不得由姐姐、妹妹或皇帝私下指定最终人选 |
| 尚华 | 大公召集议会党团与自治区的施政协商，使地方财政条件进入组阁谈判；首席仍由邦民议会以91票选出 | 自治区和大公不能以未达协议取消议会结果；未解决的支出或项目另行审议 |

政府每届的财政、教育、卫生、警务等部长由行政首席提名，接受公开听证和邦议会普通多数确认。皇族可提出意见、要求就重大利益冲突补充材料，不能单独任免全部部长、警察负责人或职业公务员。

<a id="t07-section-008"></a>

### 长期保留事项的共同决策

以下三类事项要求正式取得本邦皇族领导人的政策意见并进行共同协商：跨届综合发展纲要；改变主要公共服务供给结构的整体方案；持续六年以上且需跨年度新增财政承诺的大型跨市镇建设方案。依法可由议会取消或调整的计划，不因此获得凌驾于以后议会预算权之上的效力。

通常路径为：政府及政策机关提出方案，皇族明确同意或提出修改，随后由邦议会以普通多数审议法律与预算。千世须分别记录两位大公的意见，通常路径要求两人均同意。皇族的赞成不能代替议会赞成。

皇族不同意时，可以在15日内一次提出书面复议理由。至少30日公开协商后，议会仍可用全体三分之二以上通过不同方案：伊拉奈德80票、伊诺莱卡86票、千世107票、尚华120票。该决定可克服政策分歧，不需要皇族再次同意；对违法内容的司法审查另行保留。没有取得特别多数的，继续现行制度或形成新的折中方案。

这项权力使五人的不同意见具有真实谈判分量，同时给明确、广泛的民意保留最终选择。年度普通预算、一般税率、常规人事、个案行政和普通立法不因某位皇族宣称“重要”便进入特别程序。

<a id="t07-section-009"></a>

## 议会、政府和法院怎样约束皇族权力

普通法律与预算由邦议会全体过半数通过；开会须有全体过半数出席。特别门槛始终以法定总席数计算，空缺不降低票数。四邦普通代表任期四年，2026年现届为2024—2028年；不与中央五年议长周期绑定。

邦国层级选民须具有帝国及本邦国籍、达到法定成年标准，并在当地建立实际主要生活联系。四邦采用主要居住满六个月的登记规则；正常短期出差、就学或服役不直接注销既有登记。多重邦国籍者在四邦之间只登记一个有效邦级选籍，不能在同一时期对数邦最高民选机构重复投票。此为四邦之间的现行安排，不擅自规定其他所有邦国。没有本邦国籍的居民仍有基本权利，并可参加听证、结社、请愿和公共服务申诉。

议会可以调查、审计、调整预算，并以全体过半数通过同时指定新首席的建设性不信任案；新首席获得信任后，原首席必须交接。皇族没有任意解散议会、另开一家政府或自行征税的权限。政府如整体辞职，继续限于既有必要事务；超过45日仍无新首席，由独立选务机关依法组织提前选举，不能以皇族临时亲政替代。

普通法的公布属于法定责任。皇族可在十日内提出具体合法性疑问，请独立法院快速审查；不以政策喜好无限拒签。逾期无合法暂缓依据，或法院已确认可以公布时，由议会主持人与行政首席依法共同公布。政策机关表决失利和法律公布责任是两件事。

司法任用由依法设置的司法任用程序处理，皇族不直接挑选审理自己争议的法官，不指挥个案裁判，也不以历史见证取代证据。审计机关向邦议会及公众报告；皇族办公室的公共经费同样接受审计。

五人每年向本邦议会提交一次履职报告并接受专题答询。需要保密的内容交具备资格的监督机构；私生活不因此成为无边界公开对象。政府须说明最终采用和未采用皇族意见的理由，皇族也须说明自己反对某项方案的政策依据。

## 共同领导、兼任与回避

千世每人一票，无额外决定票；任何一人都能提案、取得材料、要求记录异议。两人主持会议可以依议题和时间安排轮换，不将政治军事、民生文化永久分给某一人。两人的分歧首先由政策机关继续讨论，长期保留事项再按[长期保留事项程序](18_邦国决策与约束.md#t07-section-008)办理；文斯利亚不因兄长身份成为地方终审者。

担任中央议长时，地方职名和实质政策权保留。地方办公室和行政首席承接资料准备、日程及日常执行；皇家领导人可以远程参加重要会议，亲自决定应由本人表达的意见，并继续提出重点政策。中央公务繁忙可以减少项目数量，不把签名和表决无条件交给私人助理。千世也不因其中一人赴中央履职而自动转为另一人独治。

涉及仅向本人领导的邦国、关联宗教机构或私人关联方给予特殊利益的中央事项，按[皇家议政会制度与选举](07_选举.md#t05-council-rules)披露并回避；中央普遍规则仍可正常参加。邦国谈判由行政首席及依法授权的政府代表承担，不能利用中央议长身份在双方各签一次。她们在本邦也应对具体私人关联项目回避，诺菲莉亚尤其要区分教会作为公共政策讨论者与教会作为合同、补助申请人。

中央议长职务与邦国首席职务不合并。2026年千樱领导中央政府，千世政府仍由当地议会支持的行政首席负责；中央合作党团与地方执政联盟可以不同。

<a id="t07-section-011"></a>

## 失能、责任追究与紧急事务

短期缺席期间，政府继续依法行政，政策机关由行政首席代为组织会务；代为主持不取得皇族公职、重点提案额度或个人表决票。缺席者可以在条件允许时远程参与。千世一人缺席时，另一人保留自己的一票与权力，不能代投两票。

连续90日确实无法履职，经独立专业评估及邦议会三分之二表决，可以启动部分职能暂代安排。三名暂代委员由首席、议会主持人和议会以三分之二选出的无行政职务委员组成；仅共同完成必要的制度连续性事务，至少两人同意，不继承皇族个人的政策复议权。长期保留事项如不能等候，直接采用议会三分之二程序。每90日复核；本人恢复且经独立确认后退出。无法预测重生者重构延迟，不得伪造永久死亡结论或自行设定复活日期。

严重违法由独立司法处理；议会可以依据法院的临时决定，以三分之二票暂停相关职能，接受定期复核。永久免除某人的邦国公职须有严重违宪违法的最终司法认定、本人答辩机会、议会三分之二支持和本邦公民投票确认。公投同意须超过有效同意／不同意票的一半，且同意票不少于登记选民四分之一。地方程序不自动撤销其中央席位、宗教身份或皇族家庭身份。

修改或取消整个皇族领导制度，则属于邦国根本章程变化：两次相隔至少30日的三分之二议会表决与上述公投，同时涉及帝国根本结构时还须按[皇家议政会制度与选举](07_选举.md#t05-council-rules)完成中央特别程序及皇帝明确确认。不能用普通地方多数绕过现行帝国制度。免职或空缺不自动产生皇帝指定替代者的权力；具体后续机构通过合法修制确定，其间必要行政持续运行。

普通灾害由行政首席依据现有灾害法启动处置，皇族参与政治协调、物资和跨地区协商；紧急限制须有法源、时限及司法救济。新增紧急授权七日内交议会审议，延续每30日复核。五人没有各自复制皇帝国家存亡级权限的“邦国危机大权”。邦国没有独立军队，军事、外交、禁制及超自然专业监管继续属于中央权限。研究机构所在地的邦国可讨论土地、交通、一般公共服务和依法公开的社区影响，不控制研究安全许可或秘密操作。

<a id="t07-section-012"></a>

## 权力现实与继续争论的问题

长期任职带来议程经验、持续关系和很高的公共能见度，也容易使公务员预先揣测皇族意见，使反对者承受社会压力。因此，公开不同意见、平等质询、独立媒体、党派自主及依法保护批评都属于制度运行的一部分。各邦政治史应记录皇族改变意见、方案被削减、政府坚持不同路线的实际结果。

2026年四邦仍争论皇族保留事项是否太宽、同一人物数千年影响政策是否公平、地方成员资格与长期居民参与如何协调，以及中央和四邦的长期关系是否让其他邦国处于不利地位。制度保留这些可公开提出的问题。已确定的是五人的实际参与、重要作用与非绝对权威；具体政治安排见前述流程。
