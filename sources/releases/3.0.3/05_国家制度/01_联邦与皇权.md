# 联邦权限、中央公职与皇权危机

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

<a id="gov-01"></a>

## 适用边界

- 法定权限与人物价值判断分开维护。法律规定某人“可以”或“必须”做什么，不等于人物必然采取某种具体行动。
- 帝国共同底线与邦国自治差异必须同时保留；不能把联邦写成中央无限集权，也不能把自治写成邦国主权独立。
- 已确定的制度原则不等于所有程序、比例、机关名称和人员产生方式均已确定。
- 皇权危机权限只限国家存亡级危机，不得外推为经济困难、支持率下降、议政争论、社会抗议或一般政治僵局中的常态个人统治。
- 帝国基本权利原则上保护帝国管辖范围内所有人；公民政治成员资格才与帝国或邦国国籍分别相连。
- 超自然事务高度中央化不等于监管机关不受法律、司法与政治监督。

<a id="gov-02"></a>

## 现代国家性质与联邦原则

现代国家全名为“神圣赫特维拉联邦帝国”。“神圣”来自早期政教合一传统；现代国家以世俗法律为治理依据，宗教组织与国家行政制度已经分离。国家不是单一民族国家，而是由多来源居民长期共同生活形成的联邦共同体。

帝国社会的长期核心不是要求居民拥有共同血缘、共同语言或共同信仰，而是寻找让不同来源的人能够长期安全共同生活的最低公共规则。早期答案是伊拉奈德戒律，现代答案是共同法律与制度。制度演化见 [总时间线与历史时代状态](../00_检索/04_年代入口.md)。

现代联邦制度以“帝国保证整个国家必须共同的部分，邦国决定地方可以不同的部分”为基本逻辑。中央权力并非天然无限；中央介入地方事务需要帝国法律授权、事务本身具有跨邦性质，或涉及帝国基本权利与共同秩序。其余事务原则上保留给邦国自治。

## 皇族公职、皇家议政会与中央决策

<a id="gov-04"></a>

### 皇族的法定公职

六位皇族至今仍处于现代国家制度中，但角色已与早期直接统治时期明显不同。现代行政体系足够成熟，皇族主要参与最高层级的重要决策、制度性确认、重大危机处理与具有历史连续性的领导职责，不需要亲自处理所有日常行政。

- 文斯利亚：帝国皇帝，负责中央层面最重要的制度性决定，并保留国家根本性事项和重大危机中的最终责任。
- 诺菲莉亚：伊拉奈德教国执政，同时为伊拉奈德教大祭司；政教两职的法源、预算、人员与命令分开。
- 艾洛希亚：伊诺莱卡大公。
- 神奈千咲、神奈千樱：分别担任同等的千世共治大公，无首席之分。
- 若璃：尚华大公。
- 六人同时都是皇家议政会成员。

四个主要邦国的政治制度都已现代化，但因历史连续性仍保留皇族领导结构，没有全部转化为完全由选举产生的最高领导制度。皇族领导人通常不参与所有行政事务，邦国政府可以独立完成日常治理；他们不需要每天驻留邦国政府，可长期留在首都皇宫，在重大决策、特定公共职责或需要本人到场时前往相关邦国。

这一结构不是所有邦国的统一模板。帝国内其他邦国可以拥有完全不同的政治制度，包括最高领导机构完全由民选产生的现代政府，只要不违反帝国共同法律与基本权利框架。

公职权限与履职动机分别维护：本节定义法律，个人选择见相应人物文档。文斯利亚在改革中保留君主制的既定立场与历史行动见 [Era 11：改革与工业化](../07_历代历史/E11_时代状态.md#era-11)，不得外推为日常行政或司法的任意否决权。

五人至2026年具有主动提案、重要政策会议表决、长期事项复议及公开协商等真实权力；地方议会、责任政府、独立司法和社会组织能够改变或否决其主张。可执行的共同流程见[四邦皇族职权](17_邦国领导与机关.md#t07-royal-state-powers)。

<a id="gov-05"></a>

### 皇家议政会

现代皇家议政会不再是六位家人之间的内部讨论，而是帝国最高层级的重要公开政治平台之一。不同政治力量的代表在其中交换意见、辩论并参与表决；六位皇族保留历史形成的制度席位和特殊责任，但不是唯一成员。

现代制度为600名民选代表加六位皇族制度席位，共606席。完整选任、门槛和流程见[议政会操作](07_选举.md#t05-council-rules)。

议政会议长由帝国公民在除皇帝外的五名皇族成员中直接选举产生，任期五年，不得连续任职；议长在日常中央政治中承担近似政府首脑的协调与政治领导角色。该选举属于帝国中央政治权利，外籍居民不能参加。

<a id="gov-06"></a>

### 中央政治的最小决策流程

现代中央政治在正常状态下以公开、集体、可审查的制度程序运行，整体表现出成熟民主国家的特征。皇家议政会是中央层面的主要立法、预算审议和重要政治决策平台；议政会议长承担日常中央政治与行政协调职责，但不能以个人意志取代议政会、法律或皇帝在根本事项上的法定责任。

正常状态下的重要中央决策流程为：

**提案与行政准备 → 皇家议政会公开审议、辩论和表决 → 依法需要时由皇帝最终确认 → 中央政府执行 → 独立法院在具体争议中进行法律审查。**

- 皇家议政会负责帝国法律、国家预算、重大中央政策、重要国际条约及其他依法需要集体决定的事项。重要事项原则上必须经过集体表决，议长无权单独决定。
- 议长可以提出或推动政策、协调中央行政机构、组织议政议程并代表日常中央政治方向，但不得独自修改法律、改变联邦根本结构、宣战、启动国家级危机权力、长期限制基本权利或干预具体司法裁判。
- 帝国法律经皇家议政会通过后，原则上需要皇帝最终确认才能生效。皇帝的确认权是制度性关口，不是日常政策偏好上的普遍否决权；拒绝确认时应提出公开且可审查的制度性理由。
- 涉及帝国基本权利、联邦结构、皇权与皇家议政会基本制度、帝国国籍、军队最高统辖、国家主权与领土根本变化等事项，可以要求高于普通法律的议政会表决门槛，并必须得到皇帝明确确认。现行特别多数和民选票双重门槛见[议政会表决流程](07_选举.md#t05-council-rules)。
- 宣战、结束战争、国家主权重大变化、联邦结构根本改变及其他直接涉及国家存续的事项，不得由议长或普通行政机关单独决定。

<a id="gov-07"></a>

### 皇权危机权限

皇权危机权限只适用于**国家存亡级危机**，不能因为经济困难、政府支持率下降、议政会争论、社会抗议或一般政治僵局而启动。

基本判断标准是：现有常规制度已经明显不足以维持国家主权、基本秩序或制度连续性，而且延迟最高层级决策可能造成不可逆后果。典型情形包括大规模外敌入侵、中央国家机构因战争或灾难无法正常履职、全国性禁制或世界结构灾难，以及其他足以造成帝国实际解体的极端事件。

危机状态下，皇帝取得的是**必要范围内的最高战略决策与协调权**，而不是对全部法律和私人生活的无限统治权。皇帝可以：

- 统一最高军事与国家安全行动；
- 协调中央与邦国应急体系；
- 临时调整战略资源；
- 在正常机构失去行动能力时发布必要的临时紧急命令或建立代理行政安排。

其他五名皇族构成危机决策核心的重要成员。在时间允许时，皇帝应听取其意见；涉及长期全国紧急状态、最高等级战略措施或其他具有巨大不可逆后果的决定，可以要求皇族内部进一步共同确认。具体共同确认范围和表决方式为 `[OPEN]`。

即使处于危机状态，皇权也不得：

- 永久取消帝国基本权利；
- 任意处决或拘禁个人；
- 清除政治反对者；
- 永久废除邦国自治；
- 使与危机无关的临时措施无限持续。

法院、议政会及其他制度在能够正常履职的范围内继续存在，危机措施应接受必要监督。

危机权限具有明确临时性。当议政会、中央行政体系和正常国家安全机制恢复到能够处理局势的程度，超出常规制度的集中权限应当退出；相关紧急命令停止、失效或转入正常立法程序，并在事后接受政治、财政和司法审查。

皇帝暂时无法履职时，应由其他皇族依预先设定的法定代理或集体决定机制承担必要职责；具体代理顺位为 `[OPEN]`。

这种制度的历史逻辑是：现代民主与法治制度负责国家在正常状态下如何治理，而皇族仍对“国家本身能否继续存在”承担不可完全转移的最终责任。它延续六人最初建立赫特维拉以保护共同生活空间的目的，但不赋予皇族在和平时期重新进行日常直接统治的理由。

<a id="gov-17"></a>

## 帝国—邦国权限边界

<a id="gov-18"></a>

### 帝国专属权限

帝国专属权限主要包括：

- 帝国国籍；
- 外交与国防；
- 跨邦迁徙与共同市场的基本规则；
- 帝国基本权利；
- 全国性司法与安全框架；
- 禁制、跨世界到达感知等必须以全国尺度运行的基础制度。

具体专属权限清单仍可在后续宪制设定中细化。

<a id="gov-19"></a>

### 邦国自治权限

邦国专属或主要自治领域包括地方官方语言、文化与宗教政策、地方教育特色、婚姻和家庭制度的具体形式、地方行政组织、地方节日，以及高于帝国最低线的增量福利。

<a id="gov-20"></a>

### 共同权限

医疗、教育、劳动、环境、交通、社会保障、公共安全和经济监管等大量事务属于共同权限：帝国制定最低标准、跨邦规则或全国协调框架，邦国负责更具体的制度设计与多数实际执行。

<a id="gov-21"></a>

### 法律优先与权限争议

- 帝国法律只有在帝国合法权限范围内才具有优先效力。中央规定超越帝国授权范围时，邦国可以依法提出异议；邦国制度违反帝国基本权利或帝国专属法律时，也不能以地方自治为由排除帝国法。
- 跨邦事务由中央建立必要的协调与最低互认规则。各邦国不必采用完全相同的制度，但人员、家庭、学历、合同、企业等法律关系不能仅因跨越邦界而失去基本连续性。
- 中央与邦国之间的权限争议首先可通过行政协调和法定协商机制处理；无法解决时，由独立帝国级司法机关作出法律裁判。皇家议政会和皇帝不作为普通中央—邦国权限争议的日常最终裁判者。
