## 跨世界到达者的法定接应

<a id="gov-09"></a>

### 制度术语

| 名词／概念 | 定义 | 状态 |
|---|---|---|
| 跨世界到达者 | 通过自然转移、召唤、异常卷入、重生等方式从其他世界进入当前世界或帝国的人；具体法律后果取决于到达方式和所在地制度 | 通用描述 |
| 非自愿跨世界到达 | 并非基于本人自由意志而进入帝国领土的跨世界到达；国籍效力见 [帝国国籍与邦国国籍](02_身份与接应.md#gov-11) | 正式制度判断 |
| 跨世界到达感知系统 | 识别跨越世界边界产生的异常并定位大致时间、地点与规模，以便启动接应；不用于持续读取个人身份、记忆或思想 | `[WORKING]` 名称 |

现代赫特维拉已经建立跨世界到达感知系统；其他具备相应技术与治理能力的成熟国家也可能拥有类似系统。其功能是发现到达事件并启动救助；禁制负责稳定本世界的力量环境。

- 一次到达感知不能自动确定具体来源世界；个人身份、记忆和思想也不在持续监测范围内。
- 发现新的外来者后，相关公共机构依规范流程接应，通常包括现场安全确认、必要医疗、临时住宿与生活保障、身份登记、语言能力与文明背景评估，以及后续教育和社会适应支持。
- 默认原则是先保证外来者能够安全生活，再处理一般行政事务；只要没有即时危险，不以军事化或审讯式方式作为默认接触模式。
- 现代帝国每年确认的非自愿跨世界到达者通常约为 3000～8000 人，多数为单人或小规模事件。该数量足以使感知、接应、语言和社会适应机构保持常设运行，但相对于帝国总人口仍是很小的年度流入。

接应后的语言教育、既有能力评估、学校或职业衔接由 [转移者、成人与继续教育](../06_现代生活/01_生活基础.md#soc-10)主定义；[非自愿到达者的适应支持](../01_世界原理/05_跨世界旅行.md#travel-07)只提供跨世界适应入口。所有支持都以恢复独立生活能力为目标，不建立特殊公民等级。

## 国籍、身份登记、基本权利与跨邦流动

<a id="gov-11"></a>

### 帝国国籍与邦国国籍

赫特维拉实行帝国国籍与邦国国籍并行的双层国籍制度。帝国国籍确认一个人属于整个赫特维拉共同体；邦国国籍确认其正式加入某一地方共同体。二者性质不同，可以并存，但邦国国籍不是帝国公民身份的必要条件。

- 任何并非基于自身自由意志而出现在帝国领土内的跨世界到达者，自确认属于非自愿到达起自动取得帝国国籍，包括自然转移、被召唤、因异常卷入、重生及其他类似情形。国籍取得原则上从到达帝国领土时成立，而不是从完成申请时成立。
- 自动取得帝国国籍不要求放弃原有世界、国家、文化、宗教、姓名或其他身份。来源世界与寿命差异不构成不同公民等级；本地出生者、重生者、转移者及其他帝国公民在法律人格和基本权利上没有区别。
- 邦国国籍不会因抵达帝国或取得帝国国籍而自动产生。帝国公民可以根据生活选择向某一邦国申请入籍；各邦国保留语言、法律、文化理解、长期生活意愿等审查制度。
- 公民可以长期只拥有帝国国籍而不取得任何邦国国籍，仍享有完整帝国基本权利与跨邦生活资格。

<a id="gov-12"></a>

### 四个主要邦国的入籍方式

以下条件用于取得相应邦国国籍，不是帝国公民跨邦居住、就业、学习或享有基本权利的前提。它们均须在帝国基本权利和程序公正底线内实施；具体评分、复核、申诉和行政机关列入 O-11。

| 邦国 | 已确定的地方入籍方式 |
|---|---|
| 伊拉奈德教国 | 包含伊拉奈德文化与语言考试；申请人在入籍前须于教会完成公民性宣誓。宣誓不是宗教皈依或对统治者的忠诚誓词，而是向自己和共同体表明今后愿以善良与自我约束参与共同生活。 |
| 伊诺莱卡公国 | 完成三轮综合面试；不设统一题库，更重视申请者的价值判断、对社会问题的理解与处理方式。在以重生者为主要人口的早期阶段，三轮中曾有一轮必须由艾洛希亚本人参与；这是历史制度，不表示现代普通行政仍须由她亲自面试。 |
| 千世公国 | 以地方语言能力考试和法律知识考试为主要条件。考试确认申请者具备参与当地公共生活所需的沟通能力与基本规则理解，不建立出身或文化优劣等级。 |
| 尚华公国 | 在帝国统一框架内进行资格审查，重点评估申请者在当地长期生活与就业的实际能力。审查针对邦国政治成员资格，不得反向限制帝国公民正常迁入、求职或经商。 |

四邦的文化意义、社会环境和地理条件见 [赫特维拉地理、城市与邦国](../04_帝国与邦国/00_目录.md)；精确程序仍按 [开放项与设定开发](../90_维护/00_目录.md) 的 O-11 管理。

外国人的长期居留、永久居留与申请入籍属于国际移民制度，详见 [长期居留、永久居留与入籍](../06_现代生活/08_留学移民与国际城市.md#intl-23)。永久居留不自动等同帝国国籍，也不自动产生中央政治权利。

<a id="gov-13"></a>

### 多重邦国国籍与跨邦流动

- 帝国国籍保障跨邦国迁徙、居住、一般就业、学习、旅游与探亲等自由。邦国不能通过要求取得本邦国籍，变相阻止帝国公民正常迁入与生活。
- 邦国国籍主要影响地方政治成员资格以及部分由邦国财政和制度额外提供的权利与公共服务，例如邦国选举、公职资格、地方专项福利、长期住房计划或其他增量项目。
- 帝国保障的基础教育、必要医疗、人身安全、司法保护和最低生活救助等基本权利，不得仅因个人没有当地邦国国籍而拒绝提供。
- 帝国允许一名公民同时取得多个邦国国籍。多重邦国籍本身不被禁止。四邦采用主要居住满六个月、同时只登记一个有效邦级选籍的规则；不把四邦安排自动推广至其他邦国。其他邦国及跨邦增量福利、财政等协调细则仍开放。
- 帝国公民搬到另一个邦国居住不需要取得迁入许可，但需要办理主要居住地变更，并按实际情况衔接税务、保险、公共服务、学校、车辆登记及其他地方行政关系。原邦国依法保存已经形成的历史地方记录，新居住邦国建立新的当地业务关系。

<a id="gov-14"></a>

### 身份登记、身份证件与年龄记录

帝国建立统一基本信息登记体系，用于确认个人身份、帝国国籍、法定姓名、基础年龄信息与主要居住地等全国共同信息；与邦国成员资格、地方税务、保险、福利及其他地方事务有关的记录，仍由相应邦国系统保存。

不同邦国机关可在具有合法理由并完成规定手续后取得必要信息，而不是把全部地方档案集中为一套无限共享的数据库。

- 本世界正常出生的儿童原则上应在出生后三个月内完成基础身份登记。超过正常期限不意味着失去人格或身份，可以依法补登记。
- 帝国使用统一 ID 卡作为主要国内身份证件。卡片记录或关联姓名、照片、个人识别编号、帝国身份及邦国国籍等必要信息；多重邦国国籍的完整状态可由电子系统记录，不要求全部直接印在卡面。
- 有效驾驶证在多数普通身份确认场合可以作为替代身份证件；对外旅行与涉外身份确认主要使用帝国护照。
- 邦国可以发行居民证、公民证或其他地方身份证件，但普通公共和私人机构在法律仅要求一般身份证明时必须接受有效帝国身份证件，不能以没有本邦证件为由限制帝国公民正常生活。

年龄是重要法律事实，但帝国制度允许个人年龄信息存在不同精度。法律与行政机关不得仅凭外表推断法定年龄，也不要求所有人都拥有精确到具体日期的出生记录。

- 本世界正常出生者通常登记精确出生日期。
- 对来自其他世界的转移者，接应和登记过程中向本人确认其自认年龄、原世界出生信息和当地计龄方式；能够可靠换算时保存对应信息，无法换算时允许登记大致年龄或年龄区间。
- 对形成或出生时期已经无法考据的永恒存在，可以记录“时间不详”、最早可确认活动年代及其他必要说明，不人为编造精确出生日期。
- 帝国承认存在无法确定精确年龄者。除确实与生理成熟、意思能力或公共安全直接相关的事项外，公共政策不应把单一年龄数字作为个人资格的唯一判断依据；职业能力、专业资格、实际身体状态和意思能力可在相应制度中单独判断。
