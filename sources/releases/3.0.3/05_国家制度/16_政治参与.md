## 政党为什么在五位皇族之外仍有实际作用

议长候选范围特殊，不等于普通人只能在五个人之间表达喜爱。现代议政会600席由公民选择，政党可以赢得这些席位、提出法律、修改预算、参加政府、调查行政，并在邦国与城市获得真实治理责任。普通人可以成为部长、会务主持人和多数地方政府领导；五位皇族无法凭自身六个制度席位完成这些工作。

政党有四种彼此独立的决定：推荐谁竞选议长；派哪些人竞选议政代表；是否与当选议长合作组成行政团队；对某一项法律投什么票。这四者可以不同。支持某人参选不等于支持她的一切政策，未支持胜者也不妨碍以后签署公开施政协议。

2026年，五位皇族不登记党籍，各自公开纲领并与多个政治力量合作。民间党由党员和自身章程决定领导、财务与推荐，不接受皇族私下任命。皇族可谢绝推荐附带的条件，党也可撤回支持。撤回推荐是政治表达，不能撤销议长已获的直接选举授权。

## 从请愿网络到大众组织

| 阶段 | 组织形态 | 能做什么与主要限制 |
|---|---|---|
| 824—1299年 | 地方代表之间的合作、城市与行会请愿、宗教与公共法争论 | 围绕税收、通行、法院和地方协议协作；身份不平等，不能称为现代全民政党 |
| 1300—1667年 | 出版、学习、职业互助与公共工程意见网络 | 传播文章、提交共同请求；组织常依赖少数出资者和地方关系 |
| 1668—1746年 | 预算改革团体、劳动互助、自治与君主制改革网络 | 1682年后结社空间扩大，出现跨地区持续组织；尚无统一成熟的党员制度 |
| 1747—1826年 | 为议长直选提供公报、地方集会和推荐的政治联合 | 对候选人有影响，但普通代表仍混合产生，组织影响与居民平等投票尚不一致 |
| 1827—1891年 | 随代表直选扩展，形成有会费、地方分支和议政团体的党 | 提名、政策协调与议员问责持续化；1862年取消保留席后，旧行会也须争取选票 |
| 1892—1945年 | 比例代表与廉价报刊、广播支持的大众政党 | 能组织全国施政与地方竞选；战争又压缩其活动和监督条件 |
| 1946—2026年 | 专业党组织、成员投票、社会运动及数字参与并存 | 政治参与扩展，职业化、金钱、平台传播与党内代表性成为持续争点 |

组织前身不是几百年完全不变的同一个党。名称、组织成员、财政来源和纲领会改变；长期延续的是一些问题、社群与文书联系，不是某位通常寿命领袖一直执掌党务。

## 政党怎样决定支持谁

各党自行制定章程，但必须公开由谁决定、党员如何参与、利益冲突如何处理。典型流程为地方提出政策要求，党内委员会比较候选纲领，举行成员或代表投票，公布推荐理由及反对意见。候选人退出或第二轮名单改变时，可以重新表决，不把第一次推荐当成永远有效的誓约。

| 案例 | 采取的政治选择 | 说明 |
|---|---|---|
| 法政党长期多次支持若璃 | 在她符合资格且当期方案接近时优先合作 | 长期倾向不等于每次必选；1912、1937等已有不同选择 |
| 公民协和党1937年 | 从惯常倾向诺菲莉亚转为支持艾洛希亚 | 配给与疏散家庭方案成为当期更重要的判断 |
| 公民共和党1946年 | 不推荐任何皇族，同时积极参加恢复后的代表选举 | 不推荐不等于抵制制度内所有政治参与 |
| 开放权利党2006年 | 不推荐，公布逐项比较并允许党员自由投票 | 认为所有方案不足时仍能通过议员与地方政策行动 |
| 生态共同党2026年 | 首轮支持艾洛希亚，第二轮改荐千樱 | 两阶段选举允许基于剩余方案重新判断 |
| 法政党2026年 | 两轮支持若璃，选后与千樱签署议政协作协议 | 推荐候选人与选择立法、预算合作对象是不同决定 |

全国党不应把地方分支不同推荐一概解释为背叛。地方分支有公开自治的，须如实标明其立场；需要统一推荐的党，也应允许成员投秘密选票。任何党都不能检查党员实际投给谁。

## 2026年的议政会格局

2026年9月完成交接。以下为项目暂定的**600个民选席**分布，六位皇族席位单列，不计入任何党。

| 党派或类别 | 民选席 | 2026年议长推荐 | 选后参与 |
|---|---:|---|---|
| 社会劳动党 | 142 | 千樱 | 参加公开施政协作，推动劳动、照护与公共服务 |
| 联邦自治联盟 | 100 | 全国推荐若璃；部分支部支持千樱 | 不参加整体协作，按地方财政和权限事项分别支持或反对 |
| 法政党 | 96 | 若璃 | 选后加入有限施政协作，要求预算测算、公开采购与资料边界 |
| 国家建设党 | 78 | 首轮诺菲莉亚；第二轮不统一推荐 | 主要在野，对基础设施和国防案可跨党合作 |
| 田园合作党 | 54 | 若璃 | 主要在野，按乡村服务、水利和地区补偿议题合作 |
| 公民协和党 | 42 | 首轮诺菲莉亚；第二轮不统一推荐 | 主要在野，参与照护、服务准入及公共信任议题 |
| 生态共同党 | 40 | 首轮艾洛希亚；第二轮千樱 | 参加施政协作，监督污染责任与转型分担 |
| 开放权利党 | 28 | 千樱 | 参加施政协作，推动信息责任与可及性 |
| 公民共和党 | 12 | 不正式推荐 | 以议员和地方政治推动公职资格改革，逐案决定合作 |
| 独立代表及地方名单 | 8 | 各自公开决定或不推荐 | 无统一全国立场，不视为自动支持政府 |
| 合计 | 600 | 另有六位皇族制度席位 | 议政会法定总数606席 |

千樱在第二轮与若璃竞争并获选。选后社会劳动党、法政党、生态共同党和开放权利党形成306席的公开协作，超过普通法律与预算所需的304票，也满足至少301名民选代表赞成的要求；每次表决仍需实际到场和投票，不能把联盟名义当成永久有效的票数。

协作范围包括照护和流动就业保障、公共服务资金、污染转型与公开预算。法政党没有因为加入协作就追认自己在选举中支持了千樱；生态党也保留对不符合约定的项目投反对票的权利。306席不足以独自通过364票的战争授权或404票的根本事项，相关决定仍须更广支持。

民间政治人物可以在不成为议长的情况下承担重要工作。两位具有通常寿命的本世界出生居民参与了2026年的谈判：哈维尔的米蕾·阿登为社会劳动党议政团体负责人，尚华的韩知远为法政党施政协作谈判代表。两人对支出规模与资金来源有实质分歧，通过公开文件形成协议，不被写成分别替某位皇族复述意见的随从。

以上仅固定2026年现状及已经公开的协作方向，不预写2031年结果，也不保证306席合作在整个任期内永不改变。

## 选举以外的政治参与

| 渠道 | 具体参与 | 公共边界 |
|---|---|---|
| 提案与预算 | 提交法案、修正支出、要求成本说明、提出地方分担方案 | 不能以支持议长为交换取得秘密专属拨款 |
| 政府工作 | 提名普通公民担任部门负责人，参加公开施政协作 | 任职者依法服务全体居民，不能只向党员提供服务 |
| 调查监督 | 质询、审计、调查委员会、推动公开资料 | 党派调查不能直接判定具体个人刑事有罪 |
| 邦国与城市 | 参加地方选举、进入政府、协商语言和增量福利等事务 | 四邦皇族领导身份保留，民选机构仍有真实预算与治理职责 |
| 社会组织 | 与工会、合作社、宗教及非宗教互助组织合作 | 社会组织保有独立性，成员不得被自动编入党籍 |
| 公众行动 | 请愿、集会、罢工支持、诉讼援助、研究和出版 | 依法保障表达与集体活动，具体暴力或胁迫不因政治目标而免除责任 |

党派在中央的合作和在地方的合作不必完全相同。例如自治联盟与社会劳动党可以共同治理一处工业城镇，同时在全国财政问题上相互反对；田园合作党与生态共同党可以共同反对上游污染，却对新保护区范围存在争执。

## 组织自由、经费与竞争条件

普通政治结社不以取得政党注册为表达前提。登记参选及接受公共补助时，须公开章程、负责人、会计与成员决策规则；地方组织不必为了合法存在先在全国建立支部。外国居民可以参加法律允许的公共讨论和社会组织，但不能借党内程序取得其本来没有的帝国中央选举权。

现代竞选经费采用公开限额、自然人捐款及适度公共支持。企业、宗教机构、行政机关与外国政治组织不得直接购买党派或候选人的竞选支出；工会和公益组织独立提出政策意见，不得把成员缴费未经同意转作某一候选人的竞选资金。自然人捐款累计有上限并须记录，防止把同一资助拆到党、候选人及外围团体绕过限制。

五位候选人取得相等的基本公共竞选资源，公共媒体提供可比较的纲领与辩论机会。私人媒体保有立场与批评自由，受资助的竞选广告须明确标示。皇族不能用邦国政府预算、宗教服务或私人财产无限追加竞选优势，也不能把官方工作账号变成不计费的排他竞选渠道。

公共补助兼顾基础组织费用与实际得票，不把已经取得议席作为唯一入口。审计针对资金和具体违法，不能因党主张共和、反对当前战争政策或批评皇族而取消其资格。是否解散组织或限制特定行为须有严格法律依据及独立司法程序，行政机关不能以“不忠诚”作普遍理由。

## 党派、候选人与社会利益

党与候选人的关系来自具体政策、组织利益、公共记录和当期判断，不由人格标签自动产生。善于倾听的人仍可能提出有争议的财政方案，重视执行的人也可能主动限制危机权力，亲近民众不等于所有群体都会受益。

政治参与者既有普通住户，也有组织者、工会成员、专业人员、企业经营者和地方公职人员。他们有不同寿命、家庭、语言、工作与迁居经历；不能把每次政治改革都写成五人先形成正确答案、社会随后表示赞同。制度之所以改变，也因为居民让原来没有被看见的代价进入了公共议程。
