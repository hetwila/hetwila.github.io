### 1942—1946年的单独记录

| 事项 | 安排 |
|---|---|
| 正式议长 | 空缺，不编届次 |
| 日常政务 | 在职中央行政负责人组成有限看守政务会议，由政务总秘书莱娅·索伦组织行政衔接；她不是议长，也不取得五年直选授权 |
| 议事程序 | 民选会务主持人沈知衡负责召集、记录及监督议程；他不统辖中央政府 |
| 皇族 | 六人保有原公职及议政席位；存亡危机范围内依法履责。艾洛希亚卸任后不再指挥普通中央行政 |
| 议政代表 | 以当时临时法有限延续监督资格，处理必要事项；其欠缺新授权的问题被持续批评，并在战后接受审查 |
| 恢复 | 1946年重新举行议长及民选代表选举，9月1日交接，新五年周期从此起算 |

莱娅·索伦为弥岚出身、具有通常寿命的本世界出生文官；沈知衡为尚华城市代表、具有通常寿命的本世界出生居民。二人的家族经历与皇族私人关系尚未设定。完整对策、争议与责任见[皇家议政会制度与选举](12_战时连续性.md#t05-wartime-continuity)。

## 任期与政治路线的变化

五人都曾处理福利、财政、公共权利、国家安全和行政执行，没有一人永远代表一个部门。支持者也会改变：同一位若璃可以得到市场经营者的支持，也可以因重建和污染治理得到劳动与合作社支持；千咲可以因限制危机权力而获得法政支持，不能仅凭其武学背景推断她代表军事集权。

非连续再次当选并不等于每次施政立场相同。候选人会从此前的失误、社会变化、专业意见和民间压力中调整具体方案。选民也可能因为对另几位当期方案不满意而作选择，不必把每次胜选理解为人格认同。

这是一份完整的任期和主要矛盾表，不是逐届完整选举数据库。这里不虚构每届投票率、逐区票数和所有第二轮组合。只有[民间政党与政治参与](16_政治参与.md#t06-party-history)明确写出的推荐、改推和不推荐案例固定在本史，其余党派当届立场仍可继续展开。
