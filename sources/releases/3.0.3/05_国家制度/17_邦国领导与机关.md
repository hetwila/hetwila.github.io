# 五位皇族的地方职称、权力变迁与决策机关

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

本页记录职称、职权演变与机关。提案、组阁、复议、问责和失能的具体程序见[邦国决策与约束](18_邦国决策与约束.md)。

<a id="t07-section-002"></a>

## 五人的正式职称

| 人物 | 2026年邦国法定职称 | 其他身份的区分 | 地方职务的连续性 |
|---|---|---|---|
| 诺菲莉亚·薇尔希·伊拉奈德 | 伊拉奈德教国执政；简称教国执政 | 伊拉奈德教大祭司为宗教职务；两职由同一人担任，但法律依据、预算、人员和命令分别处理 | 827年以“执政大祭司”确认合一地位；1042年起分立为教国执政与大祭司 |
| 艾洛希亚·优莉耶·伊诺莱卡 | 伊诺莱卡大公 | 同时是中央皇家议政会成员；中央议长为另行直选、限期承担的职务 | 827年确认为邦国公职；其后逐步限制直接任免、财政及裁判权 |
| 神奈千咲 | 千世共治大公 | 与千樱分别持有同等地方公职；没有“首席大公” | 827年将既有共同领导确认为两项平等公职 |
| 神奈千樱 | 千世共治大公 | 与千咲同等；2026年9月起兼任中央议政会议长，不因此撤销地方职务 | 与千咲分别履职、分别记录意见；一人的中央任期不改变另一人的等级 |
| 若璃 | 尚华大公 | 邦国领导身份不等于全国财政职务，也不等于任何政党领导人 | 827年确认公职，后来与城市自治、民选财政及责任政府重新划界 |

“大公”是沿用历史的邦国领导职称，不表示拥有土地、居民或国家财产。三公国都是帝国内部邦国，不具有独立国家的外交与军事主权。“共治”明确千世有两位同等领导者，不按年龄、先后签名或家中关系排列政治高低。

五人的这些地方职务没有五年任期，也不因某次中央议长选举落选或中央任期届满而终止。地方选举更换的是民选议会和相应政府。她们作为永恒存在长期任职，制度并不以皇族生育、后裔继承或王朝世系维持；长期任职仍受法律、监督与失能处置约束。

本文使用职称处理公文和制度问题，不另行改写现行称呼、礼仪与私人家庭关系。

<a id="t07-section-003"></a>

## 权力变化的共同阶段

| 时段 | 领导身份与主要权力 | 当时实际制约及变化 |
|---|---|---|
| 前2953—前1901年 | 文化传授、公共事务参与和长期合作逐渐形成；尚无现代四邦职务 | 人口稀少，地方组织依靠熟人合作；六人提出建国时尚不知道转移者和本地出生居民存在 |
| 前1900—前1501年 | 五人与地方共同体形成持续领导关系；千世两人的共同责任在前1864年已有记录 | 文化保存、水利、仓储、教学与争端见证需要当地参与；文斯利亚支持五人独立承担公共事业 |
| 前1500—199年 | 国家边界形成后，地方领导兼有较强的征收、任用、裁决与防卫职责 | 中央军事征发、地方领主和团体势力反复改变实际控制；并非四块始终稳定的个人领地 |
| 200—823年 | 公共法律、自治和议及旧约整理增强地方制度性 | 地方居民开始援引税额、契约与共同程序约束权势 |
| 824—1063年 | 827年确认四邦及五人的法定领导职务；地方任免和行政权仍强 | 872年军事统辖归中央；1042年政教分离启动教国宗教、行政权分立 |
| 1064—1649年 | 地方领导保留政务、预算倡议与重要任用，逐步退出个人裁判 | 独立司法、职业官员、城市和行业议事增长；不同地方推进速度不一 |
| 1650—1899年 | 工业社会推动财政议会化、责任政府和普遍地方选举 | 五人的直接用人、征税和行政命令收缩；形成受约束的高层政治领导 |
| 1900—1948年 | 成熟党派与行政制度运作，战争迫使临时集中资源 | 战争中的征用、疏散和代表延任存在争议；战后恢复地方选举与预算监督 |
| 1949—2026年 | 保留政策提案、重要会议、长期事项复议及公开协商权 | 民选议会、责任政府、司法、审计、地方自治与社会组织均能改变或阻止皇族主张 |

这里概括的是权限趋势，不表示同一年一次撤去全部旧权。各邦的节点、反复和利益冲突分别见四邦政治史。

<a id="t07-section-004"></a>

## 2026年的机关与决策结构

下列邦议会均由普通选举产生，不给皇族另设地方议员席位。五人可以依法在邦议会陈述、答询和提出议案，但不参加邦议会投票；她们在各自高层政策会议中有独立表决权。中央606席及六人的中央席位继续按[皇家议政会制度与选举](07_选举.md#t05-council-rules)处理，二者不能相加。

| 邦国 | 邦议会与普通通过票数 | 日常行政负责人 | 皇族参与的重要政策机关 | 机关构成与通过要求 |
|---|---|---|---|---|
| 伊拉奈德 | 公民议会120席；61票 | 行政首席 | 邦政会议，教国执政主持 | 9人：执政1、首席及4名部长共5、地方自治代表3；至少7人出席且含3名政府成员，决定须5票且含3名政府成员 |
| 伊诺莱卡 | 公民议会128席；65票 | 行政首席 | 联席施政会议，大公主持 | 10人：大公1、首席及8名部长共9；至少7人出席，决定须6票且含5名政府成员 |
| 千世 | 邦民议会160席；81票 | 行政首席 | 共同执政会议，两位大公共同参与 | 11人：两位大公2、首席及6名部长共7、地方自治联络代表2；至少8人出席且含5名政府成员，决定须6票且含4名政府成员 |
| 尚华 | 邦民议会180席；91票 | 行政首席 | 邦务协调院，大公主持 | 13人：大公1、首席及5名部长共6、六个自治协商区代表6；至少9人出席且含4名政府、3名地区代表，决定须7票且含3名政府、2名地区代表 |

伊拉奈德的三名地方代表分别由首府、其他城市、乡村自治机关的民选议事机构推选；千世的两名代表分别由城市与乡村自治机关推选。尚华六区是跨市镇协商分区，不是新邦国或六个固定文化等级；各区由其中民选地方议会按公开程序选出代表。地方代表按四年任期履职，皇族不任命这些席位。

这四个机关讨论跨部门的重要施政，不能自行立法、增税、追加预算或命令法院。日常行政会议由行政首席主持。重要政策会议原则上每季度召开一次，另可为特定议题加开；其常设办公室负责准备和跟进，不要求皇族逐日驻守。议程涉及中央专属权限时，只形成邦国意见，不能代替中央决定。

会议的法定总席数固定，缺席、回避或空缺不降低赞成票门槛。皇族不是开会的必要法定人数；不能通过拒绝出席冻结全部邦政。重要会议无法达到通过条件时，现行法律继续执行，争议方案连同各方意见提交邦议会审议。邦议会可在权限内作出政策授权；涉及[长期保留事项](18_邦国决策与约束.md#t07-section-008)，适用相应特别程序。
