# 皇家议政会的组成、代表选举与议长直选

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

本页记录议政会组成及两类选举。完整操作流程还包括[提案、审议与表决](08_议事决策.md)、[监督、问责与任职中断](09_监督问责.md)和[战时连续性](12_战时连续性.md)。

<a id="t05-section-002"></a>

## 机关、席位与实际分工

皇家议政会采用单一议事机构。2026年共606席：600席由帝国公民选举产生，六位皇族各有一个制度席位。六人不是600席之外的另一个上院。千咲与千樱各有一席，不因共同领导千世而合并；四邦及其他邦国也没有由地方领导私人支配的额外票。

| 职位或组织 | 产生与职责 | 权限边界 |
|---|---|---|
| 皇帝 | 文斯利亚；参加重大中央决定，依法确认法律、预算及根本事项 | 在议政会中只有一票，无平票加票；确认须依据制度理由 |
| 议长 | 公民从另外五位皇族中直选；五年，不得连续任职 | 负责中央政治方向、行政协调与政策责任；不能独自立法或宣战 |
| 其他皇族成员 | 保有制度席位、相应邦国或宗教公职 | 可提案、质询、投票和公开持不同意见，不共同构成日常行政否决小组 |
| 600名民选议政代表 | 公民直选，正常任期五年，原则上与议长选举同期 | 表决法律预算、监督政府、提出政策；不受所属党依法强制投票 |
| 会务主持人及两名副主持人 | 从民选代表中选出，需304票且至少301票来自民选代表 | 主持辩论、维护程序、执行既定议程；不是另一位政府首脑 |
| 中央行政负责人 | 议长提名，经公开听证及议政会确认；普通公民可以担任 | 依法管理部门、执行预算；接受议政监督及法院审查 |
| 政务总秘书与专业文官 | 按专业公职制度产生；不随议长自动去职 | 组织跨部门行政、档案与执行，不自行改定全国政治纲领 |
| 常设委员会、议事秘书局 | 委员会按代表力量及独立代表情况组成；秘书局为专业机关 | 审查、调查、记录和支持议事，无权以技术意见替代全体决定 |

“议长”沿用历史职名，现代功能近似政府首脑。日常逐项点名、分配发言和主持表决主要由会务主持人承担。这样可以让议长积极提出政策，而不同时裁判自己的政策应否被讨论。主持人若参与某项实质辩论，应暂由副主持人主持。

皇族席位不要求六人出席每场例行会议。专业行政能够持续运行；必须由本人作出的决定通过公务系统安排。私人家庭讨论可以影响想法，但不能替代提案、会议记录、表决及依法确认。

<a id="t05-section-003"></a>

## 民选代表怎样产生

600席按帝国公民人口配置于多席选区，以5—15席的选区为通常规模。行政边界和既有共同生活圈优先保持；人口很少的地区可组成联合选区，人口很大的邦国分设数区。联合选区不合并邦国身份，不改变自治权限。人口统计与分区每十年公开复核，调整不得在投票前一年临时为执政力量改画边界。

选民投一张议政代表票，可选择政党名单或独立名单，并在该名单中标记偏好人选。席位按各名单票数采用最大余数法分配：有效名单票总数除以本区席位得配额，先分整数席，再按余数从大到小分剩余席；余数相同先比较总票，再按公开抽签处理。名单内部按个人偏好票排序，未标个人的票仍计入名单。单人独立名单最多取得一席；名单候选人数不足的余席按相同规则在仍有候选人的名单间重算。

不设全国统一得票门槛。多席选区本身存在取得一席所需的实际票数，地区小党不必先成为全国性党组织。共同提名名单须在选前公开内部排序和党派关系，不能在选后把同一张选票拆成几个党各自的全国授权。

名单提名需本区选民联署，门槛为本区登记选民的0.1%，最高3000人；党与独立名单适用同一规则。议员离任时优先由原名单下一位未当选者递补；无候选人可递补时，在90日内举行本区缺额补选，新代表只完成本届剩余任期。民选议员任期规则可以处理补缺，不改变议长完整五年任期的规则。

现代代表选举与议长直选相互独立：投票对象、选票和计票分别进行，不能把某党得票自动转作它所支持皇族的票。首都居民拥有同等中央选票，不因中央直辖而失去代表。

## 议长选举的完整流程

<a id="t05-section-005"></a>

### 资格与选务机构

中央选举权属于达到法定成年条件的帝国公民；2026年通常年龄门槛为18岁。跨世界到达者按实际身份和既定成年认定登记，不凭外表判定。帝国国籍与某邦国籍分开，不能以缺少本邦国籍、财产、宗教、特定母语或识字能力排除中央选民。外籍居民不参加中央选举，依法享有的其他权利继续成立。

全国选举委员会为独立选务机关，设11名委员，任期六年、不得续任，分批更替。地方选务人员、法律与统计专业组织及公民可公开推荐人选；议政会经听证，以404票且至少400名民选代表赞成确认。皇帝、议长和政党不能自行任免委员。委员不得兼任候选人的竞选职务、党领导或行政部门负责人。

选举委员会负责名册、投票点、候选资格的形式审查和结果公告；具体争议由独立法院审理。它不能以“不适合执政”为由排除一位符合制度资格的皇族，也不能因为不喜欢某党的主张取消名单。

<a id="t05-section-006"></a>

### 候选与任期

候选范围为诺菲莉亚、艾洛希亚、千咲、千樱与若璃。本人应书面确认参加并公布纲领，不要求五人全部参选。现任议长不得竞选下一届；曾任者以拟就任日为准，须已隔过一届由他人完整完成的五年任期。可以在这届任期正常结束前参加选举，若任期发生中断，应重新核验资格。空缺、看守行政、短期代办和本人提前辞职都不视为已经隔过一届，不能借此绕过不连续任职。

政党可以公开推荐、支持或批评，但没有决定皇族候选资格的权力。候选人可以拒绝附带条件的支持；一个党不支持任何人，并不影响它参选议政代表。

正常任期自交接年9月1日起至第五年9月1日前结束。现行周期为1946、1951……2021、2026年，下一次正常交接预定2031年；2031年仅为制度排期，不属于已经发生的历史。1946年恢复选举时重新起算，旧1747—1942周期不再继续。

<a id="t05-section-007"></a>

### 通常选举日程

| 时间 | 事项 |
|---|---|
| 交接前一年9月 | 公布选务计划、经费、名册纠错与异地投票办法 |
| 交接年1—3月 | 候选人确认、利益及竞选经费申报；政党分别决定推荐 |
| 4—5月 | 公共辩论、纲领质询、统一格式选举公报；偏远地区提前安排交通 |
| 6月1日 | 第一轮投票；必要的异地、境外与提前票依同一截止规则封存 |
| 7月1日 | 第一轮无人超过候选人有效票一半时，由前两名进行第二轮 |
| 7—8月 | 汇总、复核、争议裁判与依法认证；不允许尚有实质未计票时提前宣布最终结果 |
| 9月1日 | 正式交接；行政职责、在途事项与公款使用记录共同移交 |

上述月日为现行统一日程；十八世纪各地可在更长投票窗口内完成投递，以指定截止日汇总，不把现代交通速度前推。正常第一轮取得候选人有效票绝对多数者当选，否则第二轮较多票者当选。普通选举不设最低投票率，主动弃权不能阻止其他公民作出选择。

空白票及明确“均不支持”票单独统计公布，不分配给任何候选人，也不计入候选人多数分母。它们表达政治态度，不自动取消一次可以公平举行的选举。战时大量公民事实上不能投票则是另一类问题，依[皇家议政会制度与选举](12_战时连续性.md#t05-wartime-continuity)审查，不能用低投票率规则掩盖剥夺投票机会。

若只有一位候选人，改用同意／不同意确认票，须同意超过两者合计的一半；未通过则重新开放候选登记。第二轮平票时14日内重投；仍平票，或两名决选者均退出，则重新开放登记、重办选举。不能抽签产生议长，也不能由皇帝指定胜者。交接日届满仍无合法结果时采用有限看守行政；政治僵局本身不能启动皇权危机权限。

<a id="t05-section-008"></a>

### 秘密投票与争议

默认采用可逐张复核的秘密纸票；数字系统用于登记核验、辅助发布和比对，不以手机或网络接入作为投票必要条件。异地公民使用一次性登记转移，防止重复投票。军人、疏散居民、住院者及残障选民通过专门投票点或受监督的流动服务参加，投票选择不向指挥官、雇主、照护者公开。

投票区遵守公共禁制及能力使用限制。不得读取思想、追踪个人选择，或以能力强迫“核验真实意愿”；也不能宣称能力可以保证绝无舞弊。多方见证、名册与票数核对、保管记录和独立复核承担证明责任。

候选人、名单或受影响选民可在初步结果公布后7日内提出异议；证据保全立即进行。票差低于有效候选票0.3%的选区自动复核，发现系统性错误时不限于这个比例。法院可命令重计、局部重投或撤销受污染的全国结果，不因皇族身份而降低证明标准。已发现的问题须先判断是否影响结果及选举机会，不能只用全国领先票数掩盖整片地区被排除。
