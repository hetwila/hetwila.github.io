# 历代议长：制度前身与第1—30届

[总入口](../00_开始阅读.md) · [本主题目录](00_目录.md)

本页为制度前身及第1—30届；后续见[第31—56届、战争空缺与2026年](11_议长年表_1897至2026.md)。

<a id="t05-section-018"></a>

## 1747年以前为什么不列连续的“历届议长”

现代议长是一项有独立民意授权、任期和职责的职位。此前召集、主持与最终决定经常属于不同人，没有一个能够从建国起连续编号的同名官职。把文斯利亚历次主持会议都编成五年任期，会抹去制度变化。

| 阶段 | 实际召集与主持 | 与现代议长的区别 |
|---|---|---|
| 前2953—前1501年 | 六人及地方参与者按具体事务会面；前1580年已有较集中的协议整理 | 无常设皇家议政会，更无议长职位 |
| 前1500—前1383年 | 中央召集供给、防卫与地方协议会商，文斯利亚处理最高共同决定 | 会商尚未成为有完整连续记录的独立常设机构 |
| 前1382—前1342年 | 持续军需会商由文斯利亚召集，其他皇族与承担任务者主持不同场次 | 职责跟随战争与任务，不产生定期领导任期 |
| 前1341—前201年 | 常设议政安排形成；皇帝主持重大统治决定，五人及受委托者办理专项会商 | 议政会是直接统治中枢，主持权主要来自身份和委托 |
| 前200—823年 | 工程、财务与地方议事增多，会议主持逐渐专业化 | 不具普遍直选，地方代表也未获得同等资格 |
| 824—1667年 | 联邦化后，常设文书人员安排会务，皇族、地方和政治力量分别参与 | 召集、会务及行政统筹尚未归为一种现代议长授权 |
| 1668—1733年 | 预算讨论和民间参与扩大，特定会期采用经议事者认可的会务主持 | 普通人可承担程序工作，但不是公众选出的中央政治首脑 |
| 1734—1746年 | 中央职责成文，行政负责人集体准备政策，文斯利亚承担尚未分出的最高协调；五人参与制度谈判 | 1746年建立新职位，1747年才产生首位正式民选议长 |

本表已经覆盖前身制度，但不把数千年间没有固定任期的主持者虚构成一份完整个人名单。具体古代会期若将来需要展开，可以新增召集者及文书负责人，不改变现代第1届从1747年起算。

<a id="t05-section-019"></a>

## 任期记法与战争空缺

“1747—1752年”表示1747年9月1日至1752年9月1日前，两届在交接时点相接而不重叠。选举发生在交接年前段；同一交接年内的其他历史事件，不能仅凭年份一概归给新任或旧任，应在细化月份时再决定。

第1—39届连续覆盖1747—1942年。1942年9月1日至1946年9月1日前，议长职位空缺，由有限看守行政衔接，**不编造第40届战时议长**。1946年恢复直选产生第40届，此后每五年轮替，2026年产生第56届。1942年的延期不让艾洛希亚连续执政到1946年，也不让她因空缺已经过去四年就取得1946年参选资格。

第56届在本篇截止时已经就任，2031年只是预定届满年。本文不写2026年之后已经完成的政绩。

## 第1—16届：公共授权与工业社会的磨合

| <a id="chair-05"></a>5 |1767—1772年 | 千樱 | 城镇住户、工坊家庭及青年读写团体支持更容易接触的公共政治 | 扩展通俗选举公报、地方说明会与居民申诉渠道；参与热情增加，意见如何转化为可执行决定仍需改进 |

| <a id="chair-09"></a>9 |1787—1792年 | 若璃 | 港口经营者、自治联盟与关心就业的互助团体支持航运稳定和清楚的采购责任 | 处理军备、航运与公共服务争夺预算；对海外据点收益的乐观估计受到批评，国内受益不抵销当地居民损失 |

| <a id="chair-11"></a>11 |1797—1802年 | 若璃 | 新整合的法政党及自治联盟部分力量支持预算透明与稳定生产 | 推进1798年采购和交通动员安排；为防卫保留的支出空间引发劳动组织对住房和救助经费的反对 |

| <a id="chair-13"></a>13 |1807—1812年 | 千樱 | 工业城镇、成人学习和跨邦就业团体支持更便利的行政 | 改进工伤与救助资料转接、公共说明及学习机会；部分地方认为中央过早要求文书统一，需增加培训和经费 |
