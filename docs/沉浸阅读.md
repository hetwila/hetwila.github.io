# 沉浸阅读与本机记录

故事正文和楼内每篇同人文都有“沉浸阅读”入口。阅读器占满浏览器视口，保留作品排版、章节与链接，提供章节目录、上一屏／下一屏及从头阅读。浏览器支持时，还可在设置中进入系统全屏。退出或按 Escape 返回普通正文，并保留当前阅读位置。楼层中的篇前、篇后聊天和故事的评论、来源、关联资料留在普通页面。

## 阅读设置

设置包含衬线体／无衬线体、16–28 号字及三档行距。默认使用衬线体、20 号字、标准行距；调整后立即生效，并在当前浏览器中自动保存。色彩模式复用全站 Nuxt UI 的系统／浅色／深色选择与持久化，同样影响普通页面。字体和行距只作用于沉浸阅读。

## 进度和首页

普通阅读和沉浸阅读均记录位置，最多保留最近50项。进度包含段落指纹、段落次序、段内比例及全文比例；字号、行距或视口变化时优先恢复同一段落，正文更新后找不到原段落时回退到段落次序。记录不保存正文片段。

重新打开故事时自动恢复位置；显式章节链接优先于旧进度。论坛包含多篇同人文与聊天，整帖打开时不擅自滚到其中一篇；从篇目链接或沉浸阅读入口继续对应作品。首页“最近读过”可直接恢复对应作品的沉浸阅读；只看楼主和完整讨论共用同一篇目的进度。

“移除阅读记录”同时删除该项进度，其他标签页尚未提交的滚动记录不会立即把它恢复。再次主动打开作品可建立新记录。清除浏览器站点数据也会清除全部记录；无登录要求，不在设备间同步。存储不可用或空间不足时仍能阅读，界面提示保存失败；无 JavaScript 时普通正文完整保留。

## 私有内容与预览

私有故事、私有论坛内的同人文沿用同一阅读器；必须先完成现有登录、权限和年龄确认，正文才能进入阅读器。退出账号、撤权检查或页面隐藏导致原阅读正文清除时，沉浸视图也会清除。阅读器不会在本机缓存正文，也不会增加 Supabase 请求。

私有进度以账号 UUID 分隔。本机首页用“私有故事／私有同人文”代替私有篇名，并链接到需重新验证权限的通用阅读页；记录只包含身份、位置和时间，不存私有篇名。网页编辑器和投稿预览不创建阅读记录。

## 实现与数据

- `ImmersiveReader` 接收作品身份和正文 slot。Vue Teleport 在普通正文和 Nuxt UI 全屏 Modal 之间移动同一个正文节点，不复制标题 ID；服务端与无脚本阅读保持正文在原位。
- `RecentReading` 从本地记录与现有公开目录解析标题和当前路径。公开 UID 稳定时改名不丢失进度；已移除的内容保留可删除的提示，不生成失效链接。
- `useReadingLibrary` 处理校验、按项写入、最近50项上限、跨标签页更新及删除优先。
- `hetwila-reading:v1:settings` 保存字体、字号、行距；`hetwila-reading:v1:record:<身份>` 按项保存版本1记录；`hetwila-color-mode` 由 Nuxt Color Mode 管理。
- `shared/reading.ts` 定义格式与校验。未知版本、损坏记录或越界值被忽略，不影响正文阅读。浏览器存储为本地偏好，不能用作授权判断。

验证覆盖段落恢复、设置持久化、章节导航、同人文独立进度、首页继续阅读与跨标签页删除、存储失败、私有阅读边界、无脚本阅读，以及桌面／手机、浅色／深色和键盘可访问性。
